# Participant packet

This folder contains six consecutive original manuscript scans in their release order, with neutral filenames and no page numbers. The first four scans are the region under investigation; the final two are included as neighboring original context. All six JPEGs are unmodified full-resolution source bytes (2400×3600 pixels), with no cropping, resizing, or recompression.

Read `instructions.md` first. `historical-context.md` gives an optional, date-bounded list of public Cicada sources. `image-sha256.txt` lets you verify the image bytes.

This packet intentionally contains no transcription, page mapping, candidate key, cipher hypothesis, or modern research. Do not seek or use organizer-only materials.
