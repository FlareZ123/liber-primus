# Participant packet

This folder contains the complete 58-image LP2 manuscript sequence in its original release order. The scans have neutral three-digit filenames and no physical page numbers. All JPEGs are unmodified full-resolution source bytes (2400×3600 pixels); no cropping, resizing, or recompression was performed.

Read `instructions.md` first. `historical-context.md` gives an optional, date-bounded list of public Cicada sources. `image-sha256.txt` lets you verify every image.

This packet intentionally contains no transcription, page mapping, known plaintext interpretation, candidate key, cipher hypothesis, or modern research. Do not seek or use organizer-only materials.
