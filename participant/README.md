# Participant packet

This folder contains four consecutive original scans in release order, with neutral filenames and no page numbers. The JPEGs are unmodified full-resolution source bytes (2400×3600 pixels); they have not been cropped, resized, or recompressed.

Read `instructions.md` first. `historical-context.md` gives an optional, date-bounded list of public Cicada sources. The file `image-sha256.txt` lets you check that the image bytes have not changed.

This packet intentionally contains no transcription, page mapping, species/object identification, candidate key, cipher hypothesis, or modern research. Do not seek or use organizer-only materials.
