## New result B: exact secret-independent skip-history consistency graph

[Full-source read-only CJS SFT](../../sims/lp2_h2_fulltable_keyless_union_constraints_sft.cjs) executed successfully in source-backed V8. For any 29×29 secret row-permutation H2 model and any hypothesized clock:
- Define unknown inverse-cell plaintext variable V(row,cipher).
- Each skipped candidate row r at runic position i must have emitted the preceding actual C[i−1] for the **same current plaintext** finally accepted by row a as C[i]. Therefore **V(r,C[i−1]) = V(a,C[i])**.
- Union-find merges the forced identical-plaintext variables over a global 841-cell table. A graph component containing two *different ciphertext symbols of the same permutation row* is immediately impossible, independent of all secret table values, language or key.
- Four native-GP full-length planted **true** secret clocks produce **zero conflicts** over respectively **375, 384, 352 and 379 authentic skipped edges**. Independent wrong clocks produce **44–71 contradictions**. Original fixed skip each~35 rune produces 196 conflicts on 333 edges, one p=.028 random clock 50 conflicts on345. No-skip (zero edges) is always trivially feasible.
- **Critical degeneracy:** Ten different source-only adaptive schedules on original real LP2 that veto only illegal unions produce **354–396 extra row advances each, with ZERO graph contradictions**. Thus source-real skip count and permutation graph consistency alone cannot select a true secret key or even discriminate many candidate paths. Use as a **necessary filter** only, paired with historically motivated key/clock and genuinely heldout plaintext.

The graph includes **no** assumption of cyclic/Latin secret table or plaintext/English. It is a theoretically useful operand for a future exact constrained path + table inverse, although without authentic key clues such a search is combinatorially underdetermined.
