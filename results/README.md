## 4. What changes the solution frontier

A successful next contribution must supply independently selected key/state information, a meaningful original plaintext interval with a frozen independent continuation, a source-supported change of representation that opens an executable inverse, or original external bytes satisfying the target under justified digest semantics. Other tests earn priority when they decide between those routes.

For an unknown-page inverse, publish the original input coordinates, alphabet, key and state provenance, exact clock, plaintext and forward replay. Compare against genuinely independent rival keys and ciphertext held out from that fit; p40–55 and other familiar LP2 splits have already been examined collectively and cannot be called fresh manuscript-level holdouts. Lock new rules before scoring, record prior exposures, and seek independent source selectors or authentic external corroboration. Exact synthetic inversion is an implementation control only. A conditional statistical exclusion must name its plaintext register, fixed positions and state assumptions. A new computational architecture should predict a discriminating original-source feature before language fitting.
