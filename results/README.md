# Liber Primus: established state and research frontier

**Current status (14 November 2026).** All 56 unresolved LP2 physical pages p0–p55 remain undeciphered. The 55 rune-bearing pages contain **12,956 original ciphertext runes** across **2,896 authentic printed words**, of which **32** continue across physical page boundaries; p50 contains no runes. No authenticated unknown-page plaintext, recovered creator key, complete original-cipher inverse, or verified final Cicada destination has been found. An exact numerical fit, decoded synthetic control, or self-consistent round trip is not a decipherment.

This is the **authoritative, decision-focused research entry point**. It consolidates the strongest findings and their limits, rather than reprinting each past experiment. The prior full-length synthesis is preserved as a [dated research archive](../im-results/archive-results-readme-20261113-before-critic-consolidation.md); its older claims must be read through the corrected conclusions here. Exact tests and raw evidence remain in linked reports, source files and [the active inversion challenge](../workplace/integrated-original-inversion-challenge.md).

## 2. Cryptanalytic constraints that affect the next attack

**The ciphertext is strikingly unlike ordinary GP-native prose.** Its 12,956 rune values are nearly uniform; only **86 of 12,901 same-physical-page adjacent positions** repeat the preceding rune. Original-source inspection has now localized all **86 adjacent doublets** and all **83 one-rune printed words** with no image-supported transcription corrections. This anti-repeat pattern spans word boundaries, although neither a no-repeat encoder nor a plaintext language is authenticated. A separate **original-source-conditioned** analysis refines an independently reported doublet-placement anomaly: the Pearson lag-one correlation of the 85 doublet-site gaps is **+0.3800**. Holding the nine visible chapter counts fixed leaves the original in the exploratory upper **0.000075** of source-valid random placements, while holding exact per-page counts raises the null mean to **+0.2300** but leaves an upper tail near **0.0050**. Physical-page heterogeneity explains much of the effect, and separately preserving the printed **upper/lower page-half** counts raises the null mean to **+0.3119** (upper tail **0.0383**). Conditioning on the event counts on each actual printed line raises it to **+0.3730**, with unexceptional original upper-tail **0.232**; that line-conditioned model is highly saturated (594 strata, 86 events), so it locates the pattern in *line occupancy* without proving a line-state cipher. Fixed page×printed-word-boundary counts leave the same residual as page counts alone. This remains an exploratory generator-model constraint without a source-selected key or decrypted rune.
