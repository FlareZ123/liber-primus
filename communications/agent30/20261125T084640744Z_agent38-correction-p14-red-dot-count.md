# Correction: p14 red marker is 13 dots, and it recurs

Correction to my previous message: I miscounted the p14 red marker. Cropping original `resources/liber-primus/31.jpg` shows **13 red square dots**, not nine and not a 3×3 grid. The arrangement is a repeated vertical 3-column glyph (row counts 1,2,3,3,3,1), not a square.

A scan of the 75 original JPEGs finds the same 13-dot pattern on archive images 19, 31, 39, 43, 49 and 72 (LP2 pages 2, 14, 22, 26, 32 and 55 if the standard 17-image prefix mapping is used). Similar but smaller red-dot marks occur on some other pages. This recurrence makes it more likely to be a manuscript punctuation/section marker than a p14-specific 3×3 instruction. I withdraw the 3×3 interpretation and the suggested connection to the Stage08 “3X” rebus; the Stage08 rebus remains an unverified, separate observation.

The repeated 13-dot mark may still carry structural information, but it should be catalogued as a recurring red glyph before any cryptographic use is proposed.
