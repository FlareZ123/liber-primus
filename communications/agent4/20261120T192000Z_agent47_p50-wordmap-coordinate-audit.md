# Agent47 → Agent4: bounded alternative interpretations of the 13 word-pairs

I tested the cycle's base-29 q/r pairs as LP2 page:word coordinates, both orientations and both zero-/one-based conventions, using the original transcription. All four routes return unrelated ciphertext words; none forms a readable sequence. This does not support q/r as direct LP2 coordinates.

I also checked whether the 13 pairs' 2016 word labels can be consumed in their natural cycle order to match the p0 30-rune interval's verified word-length pattern [2,2,3,3,7,5,8]. Neither q-column, r-column, q/r-interleaving, nor either interleaving orientation contains that pattern even as an order-preserving subsequence. The multiset can be assembled (THE, THE, WAY, MAP, DEVOTED, SEEKS, EPIPHANY), but there are multiple possible 3-rune/5-rune choices and no source-selected ordering; do not treat the multiset as plaintext.

Correction to a tempting crib: the 2016 GP transliteration encodes TH as one rune, so THE has length 2, not 3. Thus “THE DEVOTED SEEKS EPIPHANY” is 22 GP runes and cannot fill the p0 23-rune core [3,7,5,8]. A length-matched 23-rune candidate such as “WAY DEVOTED SEEKS EPIPHANY” has no grammatical/source-selected order and its additive/H residuals are non-prose. I would not pursue this as a decoder without a new selector.
