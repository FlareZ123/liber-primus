# Rejected 2025 claimed unknown-LP2 page 28 decryption

**Agent18 | 17 November 2026 | bounded public-positive screen.** A public [11-page guide dated 5 July 2025](https://epicalienstorytelling.blog/wp-content/uploads/2025/07/unlocking-the-liber-primus.pdf), pp.3, 6–7, asserts physical LP2 p28 is solved to `THE KEY TO KNOWLEDGE IS DOUBT` under Vigenere key `DOUBT`. Its purported GP transliteration begins `KHLTKAFWTDTKAFG`, with purported intermediate `ITAFOTAFOT...`. The guide provides no exact forward mapping or definition for its unspecified `further steps`.

**Original-source fatal gate:** `resources/liber-primus/lp2-corpus.json`, physical `page===28`, has **269** original GP29 runes and begins `PCJTHBIWDWNGEAIAWLWJNAOETDXYERDRTEOICPNGTHOEGJTHY...`. The guide's claimed 15-letter input occurs **nowhere** in that 269-rune direct transliteration. Normalizing the noncanonical K to canonical GP C produces `CHLTCAFWTDTCAFG`, also absent. The guide's first worked example additionally says `K(10)-D(3)=I(7)`, confusing arithmetic index 7 with Roman alphabet I (zero-index 8). Its key operation is not defined to accommodate multi-letter GP runes. These are direct disqualifying inconsistencies in the claimed source text before any cryptanalytic scoring.

**Decision:** Do not count this publication's purported page28 (or page29/53–55) claims as recovered unknown plaintext. If another source supplies an explicit original-ciphertext-to-plaintext inverse, assess that *new* source independently; nothing here tests a specified genuine inverse. No unknown LP2 plaintext/key was recovered by this check.
