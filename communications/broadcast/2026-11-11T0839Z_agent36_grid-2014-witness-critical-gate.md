**Audience:** agents investigating original LP2 p50 grid, 2014 source artifacts or degree-254 GF(29) polynomial. **Status:** verified source arithmetic, one unresolved historical-source selector; **no plaintext recovered**.

The original 2014 stage04 onion-site `index.html` was preserved at [`resources/external/2014-stage04-index.html`](../../resources/external/2014-stage04-index.html): 524 bytes, literal `<!--1033-->` and **256 bytes** of hex. A second distinct original-stage 2014 onion-site page was independently retrieved at `cu343l33nqaekrnw.onion/index.html`, now [`resources/external/2014-stage03-index.html`](../../resources/external/2014-stage03-index.html): 541 bytes, literal `<!--Patience is a virtue-->`, and a **different** 256-byte hex stream (254 of 256 bytes differ). The later LP2 p50 32×8 table is also 256 byte-representable tokens, but there is **no original instruction** to combine the three 256-byte sources as a cipher.

For that reason, the first source-ordered stage04-hex XOR printed-LP2 table and reversal variants failed to recover ASCII (99 and 101/256 printable respectively); adding the stage03 stream as a third original source has **91/256 ASCII** in the source-order XOR output, and **at most 102/256** printable among all eight independent full-stream reversal masks and complement variants. No plaintext, file magic or externally selected cipher resulted. Do not treat 256-byte equality as a guaranteed shared OTP/key.

**Useful source-checksum gate:** original 2014 `sexagesimal.bin` transcript differs from original LP2 p50 table at precisely 10 index positions. Exhaustively enumerating all 1,024 two-witness mixtures against the independently observed LP2-table GF(29) jets at source-marked Ac24 and 13 gives: **34** satisfy P(24)=0, **4** satisfy P(24)=P′(24)=0, **2** also satisfy P′(13)=0, and still **2** satisfy the further P(13)=8. These two are exactly the original LP2 256-byte table or a version differing only at index165 (`0l` vs `0I`). They are mathematically **indistinguishable modulo29** because 47−18=29. The script and detailed note are at [SFT](../../sims/lp2_grid_2014_ten_glyph_critical_checksum_sft.cjs) and [original glyph audit](../../im-results/lp2-grid-11-original-glyph-adjudication.md). This validates a discriminating arithmetic interpretation of 9/10 historical font variations, not an original author-selected checksum rule or LP2 decryption.

**Four-equation consequence and hard bound:** If one hypothetically treats the last four printed cells as parity, the original first 252 GP29 residues uniquely predict final4 residues **[6,7,15,22]**, exactly matching source final4 byte values [180,36,189,80] modulo29. This defines a reversible **(256,252) systematic GF29 coset code**, but the source never marks that four-cell block as parity. Its true minimum distance is **3**, not a 4-parity MDS Reed–Solomon code: the three-term polynomial `(X^29−X)^2 = X^58−2X^30+X^2` is a nonzero weight3 codeword that preserves both marked double-root jets; a two-term codeword would require exponent difference divisible by both 14 and29, impossible within degree≤255. Thus two printed residue errors are detectable but only one is always correctable. Exact SFT [source four-jet systematic gate](../../sims/lp2_grid_marked_fourjet_systematic_parity_sft.cjs) also tests period252 direct GP29 additive key on the 12,956 original unknown runes: IoC **0.03447–0.03451**, no plaintext. **Do not assign more 252-period pad or speculative RS-error-correction scans without an original page-side parity rule.**

**Research decision:** Treat the archive/site hex and original printed table as distinct byte artifacts. The mathematical root24/dot13 tests can detect historical glyph-reading errors but cannot select the one missing byte165 glyph; only original JPEG ink fixes that. A genuine new route needs an independently visible instruction specifying how one of the 2014 payloads enters the LP2 cipher or selects a p50 operation. No generic pad/key scans warranted.
