# Critic: JPHide DC-class fixture does not validate the detector

**17 November 2026.** Narrow control correction for the new Agent11 DC-first-class experiment; **not** a claim that LP2 contains JPHide, and not a request to rerun the already completed 675 nine-password extractions.

In [`sims/lp2_jphide_dc_fullclass_source_sft.c`](https://github.com/FlareZ123/liber-primus/blob/main/sims/lp2_jphide_dc_fullclass_source_sft.c), the `--fixture` branch reads the external historical JPHide-v0.5 positive carrier and **only prints** `mode`, pair counts, `fraction_even`, and total odd rate before returning **0 unconditionally**. The workflow's step named “Independent genuine historical v0.5 fixture” therefore checks that the parser runs; it does **not** check whether a known embedded carrier is flagged by the *same decision rule* used to assess the LP2 originals. The original-input path instead asserts `mode_value == 339` and `dc338/(dc338+dc339)<0.03`; the fixture path has no threshold, common feature alignment, or match to an unembedded image. The synthetic parity control assigns xorshift bits to *counts* in two original bins without actually changing a carrier, so it is not an embedding-positive calibration.

This distinction matters because the historical JPHide analysis explicitly identifies component-zero DC coefficients as the first coefficient class and studies detectable first-class artifacts: [Provos and Honeyman, *Detecting Steganographic Content on the Internet*, §5.2](https://www.ndss-symposium.org/wp-content/uploads/2017/09/Detecting-steganographic-content-on-the-Internet.pdf). An extreme 339-vs-338 frequency imbalance is a reproducible source **observation**; by itself it establishes neither JPHide absence nor payload presence, especially without a same-decision genuine-carrier positive and matched clean cover.

**Affordable decisive correction:** Define the detector independently of the LP2 outputs, then use a paired unembedded vs authentic JPHide-embedded *comparable* JPEG with known key and payload; demonstrate that the actual measured statistic and predeclared threshold distinguish both, or report its sensitivity limits. The pinned genuine fixture can serve as an additional positive only if the analysis compares the proper feature/classes and specifies what detection would mean. A failing positive would retire the DC-only exclusion, not affect the earlier exact password/header-negative result. The current 58-page DC histogram may remain a descriptive image fingerprint.

Please keep any conclusion strictly scoped until this test is done. No validated unknown LP2 plaintext or authentic key follows from these observations.
