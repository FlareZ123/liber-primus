# Agent26 follow-up: nine authentic first-release seeds retire LP1 04.jpg as an ordinary OutGuess key candidate

**15 November 2026, new source-native decision.** Calibrated unchanged OutGuess 0.4 reader on **all 17 source JPEGs** identifies **nine** recognizable actual historical messages with seed pairs `00=163, 01=115, 02=94, 03=127, 08=38, 10=99, 11=166, 12=150, 13=129`. Every recognizable signed/text message lies in the pinned default embedding search range **0..255**. Original `04.jpg` yields **7,524 high-entropy bytes** with default-key decoded header seed **38,370**, which **cannot** be an ordinary default-setting embedding using pinned OutGuess0.4 `DEFAULT_ITER=256`. No contemporary Cicada clue selects a non-default `-i/-s` parameter, signed payload or LP2 consumer for that binary.

More importantly, the original `04.jpg` has **1,164,245 usable coefficient bits**, or **145,531** bitmap bytes, whereas the OutGuess0.4 header length is 16-bit. Its maximum value **65,535** is always below the decoder's explicit `length > bitmap.bytes` rejection condition; a successful header-length check provides **zero discrimination** between a deliberate and accidental 04 payload. Later iterator behavior can still reject arbitrary data.

**Independent contemporary eyewitness:** In original 2014 `#cicadasolvers` log, Jan18 L55111 explicitly says `Steg retrieve: seed: 38370, len: 7524` and calls the data garbage; Jan15 L45633 notes false-garbage wrong-key extracts. On Jan29 L85869–85903 a participant suggests combining **three 58,152-byte** false-header/template dumps with the 7,524-byte output using XOR; another participant points out identical headers simply cancel. No independent decrypted message or author instruction survives in that context.

**Decision:** Treat `04.jpg` 7,524-byte object as an **unauthenticated header-consistent artifact**, not as a new LP2 key, plaintext, pad or 99×76 row tape. Deliberate unusual embedding is logically possible, but any successor needs a source-selected `-i` instruction, recognized payload format or selected consumer.
