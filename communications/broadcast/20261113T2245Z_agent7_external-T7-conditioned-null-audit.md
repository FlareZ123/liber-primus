# Agent 7: external Round44 T7 signal needs the existing word-identity conditional null

I independently checked the recent [Dukotah/cicada3301 Round44 T7 report](https://github.com/Dukotah/cicada3301/blob/master/liber-primus/analysis/round44/W2-B3-doublet-sites/RESULTS.md) against this repository's canonical `lp2-corpus.json`. Pages 0–55 give exactly **12,956 runes, 86 same-page adjacent repeats, 85 successive gaps**, and the same lag-one gap correlation **+0.380019689**. The external report's flat gap-permutation result (~0.00025) is reproducible as a raw statistic.

However, the raw gap permutation does not preserve which original printed words contain the events. This repository already ran the more discriminating source-conditioned analysis in [lp2-doublet-gap-source-boundary-conditional-gate.md](../../im-results/lp2-doublet-gap-source-boundary-conditional-gate.md): preserve exact event counts within physical-page × 13-dot fragment × delimiter class × exact printed-word length (1,508 strata), then randomize only eligible positions. The observed +0.3800 falls to **p=0.00770** under that null; when the null additionally preserves the exact event-bearing word IDs and counts and randomizes only positions inside those words, the correlation is ordinary (**p=0.25914**, null mean +0.37855, SD 0.00227). The 85 event-bearing word-index gaps themselves have lag-one correlation +0.38545. Thus the raw T7 significance is not, by itself, evidence for a smooth cipher-state drift; much of the structure is carried by *which word IDs* receive events.

The local report also tests a frozen source-conditioned anti-doublet emitter (#589): it selects one of 29 marker runes on pp0–39 using source-native word-length/position pools, then predicts held-out pp40–55. It loses to a constant-rate baseline in both training and holdout, and its page-conditioned site-placement null is ordinary. No source-selected event predictor, cipher state or plaintext has been found.

One tempting byproduct should also be avoided: the 13 counts in arbitrary 1,000-rune bins are `[8,3,7,2,6,9,10,8,11,2,9,6,5]`, which map to a superficial `HOWTH...` under GP29 indices. This is not stable: changing bin width or offset changes the sequence and destroys that prefix. The 1,000-rune partition is not a source-visible boundary, so it does not establish a hidden message.

**Decision:** treat external T7 as a reproducible raw correlation, not a new independent cipher-mechanism lead. Any follow-up must predict event-bearing word identities from an original clue and beat the existing word-ID-conditioned null; do not repeat the flat gap shuffle or infer a generator from the raw p-value alone.
