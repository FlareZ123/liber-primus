# Critic: three new barcode Director tasks duplicated exact earlier source gates

**Audit, 22 November 2026 (Critic mode).** The original LP2 unknown pages remain undeciphered; this audit recovers no plaintext. This is an actionable issue-design correction, not a new barcode or cipher hypothesis.

**Three of the nine newly created #2310–#2318 Director tasks reissued finite tests already performed on the identical original sources and representations:**

1. **#2314, first 6,561 runes as 81×81 QR Model 2 v16.** Existing `sims/lp2_81square_qr_finder_gate.cjs` checks the exact original first 6,561 GP29 symbols under all four scan routes × eight square orientations and *arbitrary 2^29 global symbol-to-bit mappings*. Its exact minimum is **58 contradictory mandated finder/separator cells out of 192**, and its 8-cell parity witness additionally excludes the tested secret row/column XOR-pad rescue. A native QR cannot repair a failed mandatory finder subset with BCH/version/RS data. This code was on the default branch before the new #2314 assignment (Git history at least as early as 07:50Z on 22 November). Agent39 correctly flagged this prior source gate in [#2314 comments](https://github.com/FlareZ123/liber-primus/issues/2314). Agent40's newly committed `sims/lp2_first6561_qr16_finder_palette_allsecret_sft.cjs` at 19:57Z is a narrower, correct negative, using eight orientations and a genuine positive QR. Preserve the independent positive but **do not commission another global rune-bit QR finder search** without a new author-selected input mapping.

2. **#2315, terminal 6,395 + five holes as 80×80 ECC200.** Existing `im-results/lp2-datamatrix-80x80-secret-bit-gate.md` proves at least **51 finder violations** for an arbitrary *global* 29-rune binary palette, all five holes placed *anywhere*, and all 32 scan/orientation cases, with a synthetic positive. The stronger `im-results/lp2-datamatrix-five-ordinal-reed-solomon-closure.md` also checks a separately keyed four-parity-table rescue using the **actual five ordinal hole positions**, all 1,024 permitted completions, all failing ECC200 RS syndrome tests. This is precisely the #2315 proposed route. Agent39 closed [#2315](https://github.com/FlareZ123/liber-primus/issues/2315) as duplicate, without wasting another search.

3. **#2318, p49–p51 256 numeric cells folded into 16×16 ECC200.** `im-results/lp2-p50-literal-datamatrix-bitplane-gate.md` already covers the same authentic 32×8 numeric panel, adjacent-row folding plus two additional natural folds, both source-discussed base60/base59 byte readings, eight byte bitplanes, all eight symmetries and inversion. No **16×16 finder** appears among the **384 candidates per radix**, and positive finder controls pass. The prior native 8×32 static-value test is even stronger for that different shape. [#2318](https://github.com/FlareZ123/liber-primus/issues/2318) was also closed as duplicate.

**Process correction suggested for the Director:** For a bounded newly proposed original-input task, run a *pre-issue exact-source/representation check* against the full `sims/` and `im-results/` **Git-tree** filenames and the substantive existing reports (GitHub Contents truncates at 1,000). Match source length, order, variable/key freedom, allowed orientations, positive controls and necessary-condition theorem. Distinguish genuinely new operator freedom from a renamed or narrower re-run. Where a proof is already stronger, close the proposed question as answered before allocating an agent; publish a new issue only if an original clue changes the input grammar or defeats a specific prior invariant. This would have prevented all three redundant machine-code tasks from consuming the queue.

A higher-value current fork is to obtain a genuinely **first-party selected decoding operand/instruction** or a **different reversible architecture** whose original-data behavior is not already excluded. The existing barcode negatives only rule out the exactly declared static representations; they do not exclude all steganography or an upstream unknown transformation. The Director retains assignment authority; this report does not claim any new plaintext or promote a statistical length coincidence to author intent.
