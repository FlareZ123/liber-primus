# Agent15 public claim triage: October 2026 "five new pages solved" post gives no new plaintext

**22 November 2026.** Public Reddit post [r/mystery/1x0432x](https://www.reddit.com/r/mystery/comments/1x0432x/proof_5_new_liber_primus_pages_solved/) (original timestamp **7 October 2026**, contrary to newer search indexing) advertises five newly solved Liber Primus pages, a 256-byte "RSA cryptographic block", 10 allegedly fatal case mistakes, 2014 p56 Skip-F, primitive root11 mod29 and an invertible p32 11×11 matrix determinant8. Its proposed GitLab proof site was not accessible to the public search tool; do not assume the scripts were examined.

**Substantive triage, no new decode:** The three grid pages p49–51 contain 256 printed radix60 tokens and have already been completely transcribed; 2014 participant discrepancies are documented separately in [the historical table comparison](../../im-results/lp2-2014-stage11-sexagesimal-byte-comparison.md), with **nine** byte disagreements against the original image-adjudicated source for that archival witness, not a universal count of all transcriptions. P56's F-interruption prime-totient decipherment was previously established; a reproduction does not decipher unknown p0–55. Original p32 has exactly 121 runes; its row-major GP0 11×11 determinant is **8**, already independently verified by [the source matrix/Hill gate](../../im-results/p32-tree-11x11-hill-original-gate.md), where 176 exact source-matrix operators produce no unknown plaintext. An arbitrary invertible 11×11 matrix is itself encrypted corpus, not a decryption key.

The claim's phrase “complete 256-byte, 2048-bit RSA cryptographic block” is **ambiguous**: a 256-byte arbitrary RSA ciphertext can be composite as an integer. If intended as an RSA **prime modulus factor**, the original full source table cannot qualify in any byte permutation: its original base60 byte sum **33006** is divisible by3, so the big-endian 256-byte integer is always 0 mod3, a previously recorded Agent15 original-cell invariant (source `sims/lp2_p50_rsa4096_factor_allorder_sft.cjs`). The post does not supply a new >=150-rune original ciphertext→plaintext forward replay or a novel original address.

**Decision:** no basis to update the authoritative “56 unknown pages” count or pivot source-selection efforts on this post. If a complete externally checkable novel plaintext / explicit key emerges from the linked repository, reassess that *specific cipher result*; otherwise do not duplicate the publicly established matrix determinant, known p56 rule, or ambiguous original table-byte correction.
