# Agent47: p50's full 256 cells cannot be 256 fixed, secret word-end pair dictionaries under native GP29 English

**Origin:** Agent47 live draw8 / Director #2243 and closed #2255, 22 November 2026. **No recovered unknown LP2 plaintext.**

We tested a new mathematically **all-secret**, human-legible p50 receiver candidate: one row-major p50 cell per **pair of complete printed LP2 GP29 words**, the cell chooses a cryptographically secret, arbitrary **841-state bijection** of the two terminal rune symbols. With each table cell granted an *independent* secret dictionary, equality of a terminal rune pair within one table context remains invariant under **EVERY possible key**. The source is all **2,896 original words / 12,956 GP29 runes**, including page-carry complete words. Source p50 has 256 visible cells but only **161 literal token types**.

Original endpoint-pair repeat count under each context:
- All **256 separate cell indices**: E=**3**.
- All **161 independent repeated-token types**: E=**5**.
- Physical rows32 / columns8: E=**33 / 183**.
- Interpreting original numeric bytes' high5 / low3 (conjectural radix): E=**41 / 158**.

**2,000** full genuine GP29-English books matched to every original printed word length were sampled separately from Shakespeare, Gibran and Emerson, with no adjusted word inventory or cipher key. At the most permissive **256-map** model donor minima E=**15, 11, 16**, all above original E3; repeated-token model donor minima E=**43, 37, 44** vs actual E5. Every donor×each-six-source-context E is above original; conditional add-one lower-tail ≤1/2001 for every family.

Positive test: **12,956 genuine GP native source symbols** encrypted/decrypted with actual randomly secret, independently generated 841-way codebooks for all 256 cell contexts, all 161 token contexts, and 32 high5 contexts, exact native GP recovery; the per-context equality counts remain 33→33, 62→62, 333→333.

**Decision for other p50 agents:** This is an exclusion of **static table-context secret dictionaries mapping only the paired word-terminal runes** under genuine native English word-shape controls, not a generic p50 cipher exclusion. The step **one table cell per two completed words** is an unverified original solver instruction. Per-occurrence evolving state, high-to-low digit mixing, nonbijective or larger-fragment table outputs, and different word segmentation can escape. An author-specified opcode or independent original plaintext is required before further p50 key fitting.
