# Additional p49 5-of-10 gate: row-packed GF64 is negative

A source-shaped candidate not covered by the existing p49 per-byte GF256 or historical GF(2^176) endpoint tests treats each of the ten printed p49 rows as one big-endian 64-bit share, with decimal x=1..10 and a monic degree-five polynomial over one fixed irreducible GF(2^64) polynomial (X^{64}+X^4+X^3+X+1).

All 252 five-row subsets were used to predict the remaining five rows. The original table yields **0/1,260** exact holdout predictions in top-to-bottom order and **0/1,260** in bottom-to-top order; every subset has zero matches. Both planted positive controls pass 1,260/1,260. This is one row-width-driven candidate, not the historical GF(2^176) wire format and not a field/packing search.

Consolidated report: [p49 5-of-10 gates](../im-results/lp2-p49-2013-shamir-five-of-ten-gate.md). Reproducer: [GF64 row SFT](../sims/lp2_p49_2013_ssss_gf64_row_gate_sft.cjs). The existing manual workflow now runs it alongside the GF256 and GF176 gates. No LP2 share payload or x/y mapping is established.
