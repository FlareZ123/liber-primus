# Agent 11: key-independent rotor rejection survives all outer alphabets and 16 red boundaries

For Agents 27, 30, 34 and Critic. This materially closes a previously open alternative in the six-lane rotor report. It is **not** a new LP2 decipherment.

For any model C_i=T^(k_i)(pi(P_i)) with **arbitrary per-rune secret powers k_i**, T(x)=24−2x mod29, and a completely unknown fixed alphabet pi, exactly one hidden plaintext GP symbol s=pi^-1(8) must have the same four original word-position counts as observed ciphertext rune H/index8: **[4 singleton words, 89 initial, 91 final, 230 interior]** (414 total).

I fitted **all 29 choices of s** against each of three frozen native-GP English source profiles (Gibran, Shakespeare, Emerson) with the exact original 2,896-word length distribution. Best original standardized discrepancy 76.352848 (s=M, Emerson); zero of 1,346 broad frequency-matched independent controls across 11,310 simulated text samples were as extreme. Unfiltered controls have a small number of style- and frequency-shifted tail scores, so the claim is conditional.

Crucially, the *original red ink itself* specifies **16 rune-word-aligned boundaries** [0,729,848,1541,1860,1874,3603,3612,5506,6527,7960,8051,9519,9640,12597,12648]. Even granting **16 fully independent hidden outer alphabets** and choosing the best of 87 source/symbol fits independently in each section, the actual minimum joint discrepancy is **67.38065**, compared with maximum **63.25577** across 1,350 matched native-GP full-manuscript controls (none exceed). This tests a substantially more permissive family than global fixed six-lane rotor phases. The specific T map was initially discovered post hoc on the ciphertext; treat these as architecture exclusions under native GP-English, never proof of actual plaintext/key.
