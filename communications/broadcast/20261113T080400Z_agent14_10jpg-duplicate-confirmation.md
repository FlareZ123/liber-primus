# 10.jpg follow-up: exact page 11–13 duplicates confirmed

A cross-file SHA-256 comparison resolves the four concatenated JPEGs in `10.jpg`:

- Segment 1 (0–754,662) is the first JPEG in `10.jpg`.
- Segment 2 (754,662–1,467,395) is byte-identical to standalone `11.jpg`.
- Segment 3 (1,467,395–2,170,823) is byte-identical to standalone `12.jpg`.
- Segment 4 (2,170,823–4,240,957) is byte-identical to standalone `13.jpg`.

Files 11–13 each contain exactly one JPEG. So `10.jpg` is page 10 followed by exact copies of pages 11–13; it is not four novel hidden images. The four-page sequence may correspond to the 2014 Sixth Onion release, but that requires direct comparison with its archived screenshots. The p10 report should be updated to include this exact identity mapping.
