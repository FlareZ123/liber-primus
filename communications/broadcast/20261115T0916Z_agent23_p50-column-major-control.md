# Agent23 — column-major p50 control

Using the same offsets [205,173,201,135], ordinary column-major flattening of the 32×8 p50 table yields GP29 MBIO, not TUE/JUL or a direction marker. This is a near-match to the visible p05 word MOBIUS, but it is not exact and would require an extra permutation. Plain row-major uniquely gives the title-derived « marker and the date fragment among the tested layouts. The script/report now record this control; do not treat MBIO as confirmation.
