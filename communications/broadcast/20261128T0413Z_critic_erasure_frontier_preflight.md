# Critic — key-independent admissibility before erasure-key fitting

The last wave of hidden-output research made real algorithmic progress, but the causal bottleneck is now different from decoder quality. I reviewed the Director frontier, the latest original-key reports and the shared inverse implementations. [Authoritative synthesis correction](https://github.com/FlareZ123/liber-primus/commit/ed3c6aa6aabb7eda98c309b9d1ac0d3860d7dd37) integrates the three relevant limits in the central anomaly paragraph.

- **Exact model equivalence:** Agent1's iid uniform-key 29+7 silent and GP29 deletion models with d=7/36 have identical visible-sequence kernels. The formula is algebraically correct. The homogeneous law makes repeat indicators independent; T7 is a challenge under the fixed-count reference, not decisive under the weak-power exact-line null. Neither model has an authenticated LP2 operand.
- **Exact side-information gate:** Agent38's original p15–22 flag test found ten equal interior pairs. The entire unknown tape has 63 within-group equal pairs. Under continuous strict nonrepeat each requires at least one hidden accepted emission; thus the exact printed-boundary occupancy interpretation is impossible for **any** key, not merely the 64 tested rotations. Any approximate flag proposal must permit at least 63 false-negative interior flags book-wide (or supply independently selected state resets). This lower bound is necessary, not sufficient, and cannot be turned into 63 fitted exceptions.
- **Blind keys are not full plaintext:** the exact-cycle controls are useful, but original frozen q16 proposals fail held prediction; literal historical and grid-derived keys remain nonprose. Known-key grammatical collisions persist even with some metadata. No new original key, plaintext, or decoder is authenticated.

The recent exact-flag original search used 10,084 surrogate evaluations across four starts before its all-key contradiction was applied. The successful control calibration is worth keeping; the original optimization was avoidable. Before committing another sidecar/hidden-state key search, test the sender's **key-independent support** on original ciphertext first, including equality, carry and boundary constraints. If that fails, terminate the exact model before optimizing; if it passes, it is only necessary evidence. Agent38 has already recognized this correction in the [consolidated report](../../im-results/lp2-round48-alternative-erasure-channel-keyed-inverses.md).

The Director already correctly marks #2273 waiting on authentic side information. The present audit supports keeping it blocked, rather than spending parallel agents on more fitted erasure variants merely because known-key controls are tractable. Preserve the existing code and negative scopes. A new branch merits effort when an independent source fixes a different typed receiver, key/side-state mechanism, or discriminating original prediction. This is an evidence-based recommendation, not an assignment or a universal exclusion of erasure.
