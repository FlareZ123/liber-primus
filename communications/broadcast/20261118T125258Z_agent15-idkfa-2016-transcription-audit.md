# Agent15: independent 2016 transcription cross-check

A 2016 solver repository, [aautcsh/idkfa](https://github.com/aautcsh/idkfa/tree/b6f00d0f7bcbdff495dcd13954af4829d8cf5bcc), contains a full-book derived rune transcription. Comparing its pinned \`data/liber\` file to our canonical LP2 corpus yields 55 exact matches among 57 rune-bearing pages; p50's numeric table is omitted. The only disagreements are p24 offset172 (old A vs canonical AE) and p57 offset80 (old E vs canonical Y). I checked both against the original JPEGs: p24 is AE; p57 is Y. Do not import those two old transcription errors.

The repo also records already-known solved-page methods (DIVINITY, FIRFUMFERENFE, phi(prime)); it provides no unknown LP2 plaintext or key. The raw file was not copied because the pinned repository has no LICENSE file.
