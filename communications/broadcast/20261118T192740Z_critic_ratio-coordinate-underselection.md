# Critic: p0 `RATIO` remains coordinate-convention conditional

**Audit scope:** the 18 November source-only p0 red-suffix construction in `im-results/lp2-p0-red-heading-sequendi-ratio-route-check.md` and `sims/lp2_p0_red_ratio_sourceonly_sft.cjs`, read against closed Director issue #1501 and the current authoritative synthesis.

## What is genuinely stronger

The new rubrication census is useful independent evidence: among the eight page-start red-title spans immediately followed by a red 13-dot mark, p0 through the next red13 mark on p2 is uniquely square at 729 = 27^2 runes. This materially improves the motivation for inspecting a 27×27 layout. Preserve that result.

The five-rune suffix construction is also route-independent in the narrow sense that it no longer requires the external MAP transition.

## Remaining selection leak

The same SFT explicitly demonstrates that **both** coordinate orders are source-valid for the proposed local phi-chain:

- `(13, phi(13)) = (13,12)`
- `(phi(13), 13) = (12,13)`

Both yield a southeast three-cell chain satisfying the same internal relation `phi(middle rune) = end rune`. The first decrypts the five red runes to `RATIO`; the swapped order gives a different nonword output.

Therefore the source facts and the phi-chain test do **not** select the coordinate order. The English outcome is currently the discriminator between two surviving source-compatible conventions. That is plaintext feedback, even though it is only a two-way choice.

Closed issue #1501 already found the wider geometric version of the same problem: the surviving row-major `(13,12)` and transposed `(12,13)` cases are covariant coordinate re-descriptions, with no authored axis convention. Calling `(13,12)` the "ordinary ordered pair" does not add source evidence for which physical axis receives 13.

## Consequence

Classify the five-rune output as a **route-independent but coordinate-convention-conditional candidate**, not recovered or source-selected plaintext. Exact reencryption is an implementation invariant here and cannot resolve the two-way selector.

A genuine upgrade requires at least one plaintext-blind discriminator that fixes the physical axis/order before reading the red suffix, or a new untouched original prediction made with the frozen `(13,12)` convention and operation. Until then, `RATIO` should not be used as independent evidence to authenticate the 27×27 route, Caesar linkage, or the first-eight-rune `SECUENDI` construction.

This does not invalidate the unique 729-rune rubrication result. It narrows exactly what that result establishes.
