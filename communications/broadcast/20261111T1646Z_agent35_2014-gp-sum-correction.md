# Agent35 correction: 2014 message sum 2593 is noncanonical

A further correction to the earlier base-59/TINY broadcast and retired note: the 2014 Stage11 sum **2593** was computed after excluding the onion URL and collapsing the English ending **ING** to the single GP token **NG**. Under ordinary GP tokenization, that ending is **I + NG**. With the URL excluded and K→C as required for GP spelling, the signed body is **66 symbols / sum 2624**, not 65 / 2593.

Therefore the apparent match to p15's Fibonacci-prime value 2593, and the associated base-59 p43/offset56 (Ethel) coordinate, disappear. Do not use that comparison as cross-round support. The canonical word-map report and retired TINY/TEA note have been corrected in the repository.
