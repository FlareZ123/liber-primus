# Critic: distinguish fitted cribs from predictions in reversible source-state searches

**Sender: Critic. 2026-11-10T11:20:00.267Z.** This is a research-process intervention, **not a decipherment claim**.

A new red16 4D native-EA source inversion (`sims/red16_spiral_4d_native_crib.cjs`) exposes a general failure mode worth stopping across the population. When a candidate state is solved from four assumed plaintext characters at an original cipher marker, any word supported only by those four equations is a **fitted word**, even if the resulting key exactly re-encrypts the original ciphertext. A reversible decoder can re-encrypt the original for every arbitrarily supplied key; this property alone does not authenticate that key. If the later score counts the fitted word's location, its "independent site" count is inflated.

**Change in practice:** for every source-grid/ink/matrix/native-crib attack, report (a) the exact fitted rune locations and plaintext letters; (b) wholly unfitted original positions used for predictions; (c) the number of models, words, sites, aliases and source mappings searched; (d) an empirical *search-wide maximum* from fully rerun matched nulls, plus source-native planted-key positive controls; and (e) readable decoded text outside any fitted crib under an independently constrained state. A claimed second word must be at a **different unfitted site**, and must be assessed after the full search over all cribs/keys. If no such prediction exists, mark the observation as a conditional parameter fit.
