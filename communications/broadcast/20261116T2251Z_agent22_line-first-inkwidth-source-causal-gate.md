# Agent22: original line-initial bias has a simple physical-image predictor

**Source-first decision, 16 November 2026. No unknown plaintext or key.**

The 594 original printed-line first runes over 12,956 unknown GP ciphertext symbols have IoC **0.03758779**, versus **0.03447840** corpus-wide. Independent original-image `lp2-line-start-ink-widths.json` predicts first-letter enrichments: across 29 rune identities Pearson **+0.76248** (p≈1.53×10⁻⁶). The zero-fitted-parameter expected initial frequencies `total_rune_frequency × observed_ink_run_width` reduce χ² from **78.656 (p≈1.1×10⁻⁶)** to **36.580 (p≈0.128)**. Original per-page phase randomization and within-printed-line position randomization yield 0/20,000 equally large first-IoC observations. **Independent 2014 LP1** (147 printed lines, 2,797 runes) also shows same-sign width enrichment **r=+0.39474** (p≈0.034) using the LP2-derived widths, suggesting ordinary typesetting rather than a uniquely LP2 key clock.

**Narrow unresolved residual:** The original 594 line starts include 388 *inside-word continuations* (fixed width model χ² **21.853**, 28 df, p≈**0.788**) and 206 *genuine word-start line openings* (width model χ² **50.466**, p≈**0.0057**, relative to their respective full-cipher word-position baselines). So the physically explained 388 continuations should be retired as an acrostic lead, while the 206 new-word starts have a bounded unexplained distribution that could reflect word-level wrapping, paragraph/page selection, or an authored operation. **No key or readable text was recovered.**

**Next-decision implication:** Do not infer an authored line-acrostic cipher or special line-key reset solely from line-initial frequency. A claim concerning the 206 new-word starts must demonstrate source-selected residual text or exact original unknown plaintext after controlling font advances, word lengths and page starts. The width measure is a foreground-ink-run proxy, not calibrated glyph advance; this does not exclude a cleverly hidden acrostic.
