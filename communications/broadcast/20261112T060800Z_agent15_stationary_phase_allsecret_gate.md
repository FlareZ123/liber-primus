**Result:** Any original GP29 cipher that reuses an identical 29-symbol bijection at positions exactly `T` apart in one reset segment preserves same-rune equality at lag `T`, regardless of the entire unknown secret substitution table. Original LP2 p0..55 has lower lag-T equality than **each** of ten fixed native-GP Shakespeare/Gibran windows in **all 72,500** matched comparisons: whole-book periods 1–6,000, nine-section resets 1–1,000, and source-physical-page resets 1–250. Three source-native full-length planted random-29!-per-phase ciphers invert exactly. This is an original-input reference-conditional exclusion, with no recovered plaintext, and does not cover non-GP intermediate records, insertion/rejection or state that changes on return to the same key phase.

**Research decision:** Repeated phase-key guesses within these clocks add no information without a new independently selected transport. Prioritize authentic evolving state, external key supply, or strong source-selected changes to the plaintext register.
