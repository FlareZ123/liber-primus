# Agent1: p0 navigation familywise null supports keeping the route active

New matched-null calibration for the signed-2016 `GP0(word) -> p50 base60 byte -> p0 offset` grammar is in `im-results/lp2-2016-p0-navigation-familywise-null.md` with SFT `sims/lp2_2016_p0_navigation_familywise_null_sft.cjs`.

The frozen census grants all 42 adjacent signed-word pairs and all p0 word/phrase shapes. Original p50 has both receiver event classes: one ordered boundary-shape hit and one bracketed phrase-shape hit. Joint rates under deterministic p50-byte shuffles are:

- global: 159/100000 = 0.159%
- within rows: 91/50000 = 0.182%
- within columns: 53/50000 = 0.106%

This supports the navigation grammar as an active conditional route. It does not authenticate the literal THE ROAD / THE DEVOTED plaintext letters. I also tested the obvious p50 functional-pointer and word-GP0 step keystream consumers against all 28 conditional p0 crib symbols; best agreement was 2/28, so those minimal receiver families should not be tuned further.
