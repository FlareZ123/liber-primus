# Agent38 original-JPEG cipher-side channel and rune readback handoff

**15 November 2026; scoped original-source result, no unknown-page plaintext.**

Two small Python SFTs now allow physically independent cross-checks of the manuscript without trusting a community rune transcription:

- [Original-font, full-width spacing-channel test](../../sims/lp2_original_rune_typography_sft.py) uses original archive JPEGs at native 2400×3600 resolution. Train only on physical p32/p55 (197 rune samples, all 29 GP types). Read 6,352 eligible adjacent-rune gaps on **25 other pages**: a frozen two-glyph font-advance plus visible dot-width model predicts positions with heldout MAE 0.4524 px. The expected number of full-width spaces matches **every visible punctuation-component count**, 6,352/6,352. This rejects *invisible extra full separator spaces* on those pages as a key bit channel. [Scope and controls](../../im-results/lp2-original-rune-typography-space-channel.md).
- [Whole-manuscript image-only GP readback](../../sims/lp2_original_image_full_register_readback_sft.py) uses the frozen classifier on all 58 original scans. Seventeen rune-bearing source pages have **complete, exact** image-derived GP29 register: p2, p9, p12, p13, p14, p19, p26, p28, p29, p31, p32, p34, p46, p47, p49, p52, p55. Numeric-only p50 correctly yields no rune. No right-length image transcription contradicts the original canonical GP29 corpus. The other 40 pages are partial because drop initials, artwork and shifted text blocks disrupt the fixed row scanner. **Those are scanner failures, not established transcription discrepancies.**

**Concrete follow-up for a human-source validation agent:** For original pp23,27,54, try targeted line-baseline registration rather than full cipher resweeps. Physical p54 begins ordinary text near y=916 instead of the training baseline y=673 and a fixed-local row scanner recovers roughly 230/232 positions; decorated opening red drop initials still need manual/fixed-cut handling. If adaptive original-image readback isolates any bona fide new transcription correction, first check that the rune difference changes an actual proposed LP2 inverse or clue selection, then escalate. Current evidence supplies no actual plaintext or key and does not warrant another blind cipher search.
