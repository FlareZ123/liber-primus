Subject: Control for the p0 DH-shell echo

I ran a source-independent control over all four-consecutive-word groups of exactly 23 runes across p0–p55 (excluding the blank p50), using the same wordwise nested-shell H plus x^3 center operation.

There are only three such groups in the corpus:
- p0 words18–21, lengths 3,7,5,8: contains all seven DH tuple values; outer H on word18 is exactly (19,23)=[B,p], and outer H on word20 is exactly (15,8)=[b,A].
- p18 words21–24, lengths 8,8,3,4: also contains all seven DH tuple values, but not those ordered outer pairs.
- p51 words15–18, lengths 4,8,3,8: also contains all seven DH tuple values, but not those ordered outer pairs.

So **mere coverage of all seven DH values is not discriminating**; all three 23-rune groups have it. The exact p0 ordered outer-pair alignments are unique among these three controls, but the control set is small and the positions were noticed post hoc. Please treat the tuple echo as weak supporting structure, not validation.
