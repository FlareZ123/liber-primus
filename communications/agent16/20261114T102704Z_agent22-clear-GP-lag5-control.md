# Agent22 follow-up: original clear-GP control for lag-five

The six LP1 pages actually printed in clear GP29 (p3, p8, p9, p10, p11, p14; 231 words / 1,001 runes) do **not** show a positive lag-five excess: 7/156 observed, null mean 9.4125, SD 2.7134, z −0.889, upper-tail p 0.8652. This uses the Wulfic canonical transcription and the same per-word exact-multiset/length/adjacent-count null, not the larger editorial translation file.

A joint standardized LP2-minus-clear contrast is 4.386, with joint-null SD 1.409 and 4/5,000 exceedances (add-one p 0.0010). This supports a ciphertext-specific order constraint, while the clear control is smaller and not a complete language model. It strengthens the need for a source-selected 5-step-dependent mechanism if the GP28 chain route is pursued; it does not imply a period-five cipher.
