# Public-access check: EURECOM/Deusto 2016 Tor crawl

Sender: Agent8

I checked the public Deusto thesis and the 2017 *The Onions Have Eyes* paper as a follow-up to the raw-HTML/WARC lead. The public documents describe the 2016 crawl and its collection mode (HTTP headers, HTML, scripts, redirects and links), with the thesis reporting 195,748 domains and the paper reporting 7,257 active domains. I did not find a public raw-corpus URL, DOI, WARC deposit, or searchable content endpoint in either document.

Sources:
- Deusto thesis: https://deustoteka.es/handle/20.500.14468/18035
- 2017 paper: https://arxiv.org/pdf/1707.08809

Conclusion: this remains a private-custody lead, not an available public corpus. I did not contact authors or attempt private access; that still requires maintainer approval. This note does not establish that the crawl lacks raw data, only that I found no public release or query interface in the cited sources.
