# 2013 Cicada OS `/tmp/wisdom` and `/tmp/folly` reference bytes

- Historical archive: [scream314/cicada3301 `assets/2013/cicados/tmp/wisdom`](https://github.com/scream314/cicada3301/blob/master/assets/2013/cicados/tmp/wisdom), [`folly`](https://github.com/scream314/cicada3301/blob/master/assets/2013/cicados/tmp/folly), [`folly.rev`](https://github.com/scream314/cicada3301/blob/master/assets/2013/cicados/tmp/folly.rev).
- The two originally described /tmp files `wisdom` and `folly` have **exactly identical binary bytes**, **3,368 bytes** each, and the same immutable Git blob hash `62b1b949a1e4e4a346e75b1c34101000d3c53220`. The archived `folly.rev` is their exact **bytewise reverse** but is not established to have been an original Cicada file. The names appear in 2013 and also as philosophical terms in first-release Liber Primus.
- Exact common source payload: [`resources/cicada2013-wisdom-folly.bin`](cicada2013-wisdom-folly.bin), imported without re-encoding. The target Git blob SHA matches the source's known Git blob SHA, so archive bytes are preserved exactly at transfer.
- Source-identity caveat: the surviving historical repository is a secondary archive. The mirrored bytes have not been cross-verified against a separately signed 2013 ISO or independently preserved original byte dump.
- Hypothesis: these previously unused high-entropy bytes are large enough to provide a **one-shot** key for any of the nine unsolved LP2 sections (longest exactly **3,008 runes**). Size adequacy and thematic names alone do not imply Cicada designated this file as the LP2 key. The 3,368-byte count exceeds that maximum by 360 bytes, the size of a separate LP1 JPEG05 central bridge; that numerical equality is retrospective and unselected.
