# Frozen pre-2014 non-English GP29 register controls

These source-language controls preserve the copied UTF-8 text verbatim. Their prose predates the 2014 Liber Primus release, although these GitHub mirrors were published later. They do not claim that Cicada authored or encrypted the texts.

- **Middle Welsh, `Pwyll Pendeuic Dyuet`, First Branch of the Mabinogi:** `pwyll_pendeuic_dyuet_welsh_source.txt` is the unchanged file [at pinned commit 788549850c37d683f1b8ec1b2ba8c851b83aa722](https://github.com/minormobius/agent01/blob/788549850c37d683f1b8ec1b2ba8c851b83aa722/read/pwyll/source/pwyll-wikisource.txt), credited in its header to [Welsh Wikisource](https://cy.wikisource.org/wiki/Pwyll_Pendeuic_Dyuet), under **Creative Commons Attribution-ShareAlike 4.0**. Redistribution of this text is under the same source license; its header is retained. The original literary work predates modern copyright. Cicada's earlier 2012 Mabinogion book reference was an **English translation**; the Welsh original is an independent hypothetical plaintext register, not an authenticated book key.
- **Old Norse, `Hávamál`:** `havamal_old_norse_source.txt` is the unchanged `complete.txt` from [CLTK old_norse_texts_heimskringla at pinned commit 2fb9652585dbb159404b480330a7167f4c34af1b](https://github.com/cltk/old_norse_texts_heimskringla/blob/2fb9652585dbb159404b480330a7167f4c34af1b/S%C3%A6mundar-Edda/H%C3%A1vam%C3%A1l/txt_files/complete.txt); that repository credits **Heimskringla.no and editor Guðni Jónsson** for the public-domain historic text. This is thematically source-plausible Old Norse verse, not a first-party Cicada plaintext claim.

The only content changes for cryptanalysis occur in the separately committed `sims/lp2_nonenglish_register_bounds_sft.cjs`: removal of the indicated Welsh metadata preface and the single Old Norse Roman heading; source-native tokenization; explicit reversible-source spelling assumptions. No accented or runic spelling has been silently replaced in these reference fixtures.
