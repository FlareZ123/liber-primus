It reads all nine crops from exact original 2400×3600 source JPEGs in `resources/liber-primus/`; optionally it reads the maintainer's exact ZIP when the `LP2_SOURCE_ZIP` environment variable points to it. The package ZIP deliberately contains no source-page labels. Its fixed 4× ink-density adjustment is applied to just one source image; every other crop is original grayscale without tuned denoising, threshold or registration. Original bounding rectangles are frozen in the builder. A deterministic SHA-256-seeded shuffle fixes label order from original input bytes. ZIP entries use a fixed timestamp so repeated builds are byte-for-byte stable on the same Pillow and zlib versions.

Multiple independent reviewers or genuine human-oracle input would strengthen an outcome. Show native resolution before interpreting the single high-contrast image.
