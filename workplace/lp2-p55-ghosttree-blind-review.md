# LP2 p55 ghost-tree: reproducible screening packet and corrected blind-review gate

**Scope (17 November 2026; Critic correction 17 November):** The v1 packet preserves a reproducible, label-hidden screening test for an alleged second deliberate symbol in the pale p55 tree. It is **not adequately blinded for a decisive human-oracle test**: the target alone appears both in native and high-contrast form, so duplicated content reveals the special target without opening the private mapping. The already established p32/p55 tree relationship is described in [the source-image report](../im-results/lp2-p32-p55-blurred-tree-correspondence.md). The new question is whether p55's original image has a separately drawn, meaningful object beyond that known shared tree. The strongest alternative is ordinary branch linework, contrast and image-rendering artefacts. **No independent human-oracle decision, new rune key or plaintext has been recovered.**

## Frozen v1 screening packet

Use [the fully reproducible original-JPEG builder](../sims/lp2_p55_ghosttree_blind_packet.py), requiring Pillow and filelock. The public CI is pinned to the locally tested Pillow **12.3.0** and filelock **3.29.0**; output ZIP byte hashes also depend on the zlib implementation, so cross-run SHA-256 differences alone must not be interpreted as changed image pixels. It reads all nine crops from exact original 2400×3600 source JPEGs in `resources/liber-primus/`; optionally it reads the maintainer's exact ZIP when the `LP2_SOURCE_ZIP` environment variable points to it. It writes nine numbered 1110×1080 PNGs, a three-by-three contact sheet, a public manifest with SHA-256 for each crop, and a distinct excluded private reveal file. The package ZIP deliberately contains no source-page labels. Its fixed 4× ink-density adjustment is applied to just one source image; every other crop is original grayscale without tuned denoising, threshold or registration. Original bounding rectangles are frozen in the builder. A deterministic SHA-256-seeded shuffle fixes label order from original input bytes. ZIP entries use a fixed timestamp so repeated builds are byte-for-byte stable on the same Pillow and zlib versions.

Shuffle and conceal source-level panels rather than a uniquely doubled target, match crop placement/scale where practicable, and include an original-image negative such as the p54 side-frame that is pixel-identical to p55's decorative frame. Keep the public v1 packet and its hashes unchanged as a historical input; any balanced v2 needs its own manifest and pre-committed shuffle.

Give the independent reviewer only the balanced, label-hidden panels and a single pre-registered question: “Does any panel contain a distinct, deliberately drawn secondary object beyond its obvious illustration?” Require the exact marked pixels and comparison to matched negative panels before revealing the mapping or discussing p55. Keep the builder/reveal map outside the reviewer's materials and do not interpret source recognition as evidence of a cipher. If negative or ambiguous, retire the extra ghost-object claim; if positive, seek an original Cicada-authored operation that the observed feature actually specifies and test it on untouched ciphertext. A visual decision alone does not decode GP29.
