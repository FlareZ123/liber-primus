**State, 17 November 2026:** An original-JPEG-based, deterministic eleven-panel **v2** blind stimulus is now implemented with source-pinned RGB hashes and a separate private answer map. The previous v1 packet remains an invalid decisive oracle because it displayed p55 twice with unmatched contrast. **Independent human review and any authentic extra object remain unconfirmed. No original unknown plaintext, key, or destination has been recovered.**

## Concrete question and causal test

The p55 central pale tree could contain an independently drawn smaller object. The known p32 blurred reuse of the same tree and the identical p54/p55 floral side template provide genuine original-source comparators. Ordinary branch contours, compression, underexposure and the source artist's standard ornamentation remain strong rivals. A reviewer given only the public eleven-panel ZIP must answer:

> Does any illustration include a distinct deliberately drawn SECOND object or symbol beyond its dominant subject? Mark exact pixels and compare against other panels. Leave negative/uncertain if none.

Neither the reviewer nor the model should be told which panel is p55, which is the known earlier reuse or which one has the artificial positive. Source identification is **not** success. A claimed extra feature must be marked on the original pixels and judged against the matched original trees, branches and floral ornaments **before** the withheld map is opened. Even a positive independent human answer remains image evidence only; original GP29 plaintext requires a separately source-appointed reversible operand.

## v2 packet: frozen, uniform processing

The [single-file source-native builder](../sims/lp2_p55_ghosttree_balanced_v2_packet.py) uses Pillow 12.3.0 and filelock 3.29.0. The [manual CI reproduction](../.github/workflows/agent28-ghosttree-balanced-v2.yml) reads the repository's original JPEG sources; the maintainer ZIP is an optional equivalent input. Every source is a unique, hash-pinned 2400×3600 first-party JPEG. Eleven original sources represent **one candidate, nine naturally printed controls and one synthetic positive**. The control pool includes the authentic older blurred tree, slender plant stem, botanical scroll, two different original floral-frame sides, solved-page ornament, insect wing, cross-shaped illustration, insect drawing. The p54 side-frame gives an original exact-template comparison to p55's border. The artificial positive is added **after** normalization to a further independent original illustration, not to p55.

All eleven receive the **same** original-gray conversion and fixed 3× black-ink transform, with source illustration-only bounding crops and aspect-preserving maximum-size 900px centering on an identical 1000×1000 white canvas. Exactly one image per original JPEG is shown; there is no uniquely doubled candidate or source-specific contrast rule. The source-choice and crop geometry are fixed in the builder independently of any guessed secondary object. The shuffled, anonymous public labels derive deterministically from SHA-256 commitments of all eleven original source byte hashes, preserving panel order on regeneration. The planted positive contributes exactly **278 edited pixels** to its original-shaped normalized image, representing an independently recognizable tiny five-point mark.

The source and crop mapping appears **only** in a separately written `private-reveal.json`. Do not add it to a public review ZIP, email or reviewer chat. The public ZIP includes exactly eleven numbered 1000×1000 PNGs, a contact sheet, and an unlabeled manifest containing per-panel hashes plus the private map's SHA-256 commitment. Its code is public for scientific reproduction, so reviewers must be shown only the isolated public packet and no source repository, code, identity hints or historical p55 labels until the pre-reveal answer is locked.

## Acceptance and residual risks

This v2 fixes the **procedural** mismatch demonstrated in v1: source duplication, unmatched enhancement, and text-heavy controls. Its public panel crops now isolate art from neighboring runes. The images still contain **inherent source differences**, notably one crisp detailed tree, one blurred tree, thin stylized stems and unrelated insects. No processing can create eight independently authentic detailed-tree controls from the available first-party image corpus. Therefore the packet is suitable for a **controlled blind review**, with unavoidable limits on natural subject matching; it is not evidence of p55 authorship or proof that a person cannot recognize the original art. Any source-aware reviewer, or one shown the builder, must be excluded from the blinded judgment. The deliberately introduced symbol establishes review sensitivity, while comparison against floral and branch negatives checks false-positive rates.

An independent human should record the selected labels, mark coordinates, whether they found the hidden positive, and a short reason without seeing the key. Once that answer is frozen, disclose the private map and compare exact original pixels in full resolution, explicitly treating positive-planted and known-blur controls separately. If the subject is recognizable from publication history before the answer, call the trial **unblinded**; recruit another naïve reviewer or end the claim without upgrading the result. A source-visible authored rune operation is a separate prerequisite to cryptanalysis.
