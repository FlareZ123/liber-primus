# Integrated original-cipher inversion challenge

**Decision frontier, 14 November 2026.** The 56 unsolved LP2 physical pages p0–p55 contain 12,956 ciphertext runes over 55 rune-bearing pages and 2,896 printed words; physical p50 is a rune-free number table. There is **no authenticated unknown-page plaintext, creator-supplied unknown-page key, complete historical inverse, or identified final destination**. This document is the current *attack contract*. The authoritative evidence synthesis is [results/README.md](../results/README.md); the complete, superseded experimental inventory is [archived intact](../im-results/archive-integrated-original-inversion-challenge-20261114-before-critic-consolidation.md). The archive records exact historical scope, rather than current priorities.

**The immediate bottleneck is an independently selected key or reversible operation.** Synthetic planted recoveries, finite English-reference exclusions, retrospective numerical coincidences and wrong-key ciphertext round trips do not identify the historical LP2 cipher. Prioritize authentic source bytes, an explicit extraction/state rule and coherent original plaintext over another sweep of unfixed parameters.

## One shared original-input submission contract

An original LP2 decryption candidate must provide all of the following. Missing items should be explicit, and synthetic experiments should be labeled as such.

1. **Frozen source premise.** Give the original image/bytes, exact offsets or cells, content hash where possible, independently justified extraction and fixed GP29/alternative alphabet order. Distinguish historical evidence from invented design choices.
2. **A real inverse.** Specify encoder, decoder, key generation or retrieval, IV/state, page/word/line clocks, punctuation and F handling, reset boundaries, and any side information needed for lossy or stochastic transitions. A noninjective toy encoder that silently discards plaintext symbols cannot certify a solve.
3. **Original ciphertext, verbatim.** State physical pages and exact original rune indices; disclose all key/phase choices fixed from the same original text. Print actual candidate unknown plaintext with segmentation and demonstrate exact forward re-encryption of the tested original. A bijective wrong key round-trips too, so this is a necessary implementation invariant **rather than evidence of key identification**.
4. **Independent selection and controls.** Include authentic solved-Cicada positive controls in the correct source orthography, source-native planted controls, wrong keys/coordinates, alternate-source controls and a relevant null for every selection that used the original text. A withheld page already mined by the repository is within-study heldout, not independently preselected evidence.
5. **Whole-artifact consequences.** Account for anti-repeat sites, word-end F capacity when claiming transparent-F transfer, cross-word/page joins, visual boundaries, red/punctuation marks and other features actually implicated by the proposed operation. Confront failures without adding tuned exceptions.
6. **Decision criterion.** State *what observed result* would authenticate the key/route and *what result* would retire it. Prefer complete original-key provenance and coherent contiguous plaintext; report exact gaps and remaining alternatives.

For an invertible pair `E_k` and `D_k`, `E_k(D_k(C))=C` is true for **every** candidate key `k`. Distinguish key provenance and meaningful plaintext from round-trip implementation success. Similarly, independent synthetic key recovery identifies a key only in the specified synthetic generator class. The public LP2 corpus has been examined thousands of ways; prospective evidence requires a source derivation fixed independently of whichever original feature is scored.

## Division of useful research effort

- **Historical evidence recovery:** period-original deep-web HTTP bytes, signed earlier-round instructions, original illustration sources and authentic source-selected key material; observe owner authorization boundaries.
- **Integrated cryptanalysis:** develop or reuse a small number of genuinely different *lossless* original-input decoders with frozen source state, not a proliferation of free-key score sweeps.
- **Adversarial evidence review:** independently challenge key provenance, transcription, original-input generalization, repeated tests and the distinction between historical keys and arbitrary bijective wrong keys.

The Director assigns new research decisions via [live Issues](https://github.com/FlareZ123/liber-primus/issues?q=is%3Aissue+is%3Aopen+label%3Adirector-task).
