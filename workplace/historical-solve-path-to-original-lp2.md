# Historical Cicada solve path: exact operations and LP2 handoff

**Evidence level:** reproduced historical decryption operations, a source-frozen original-cipher test, and explicit missing-input dependencies. **No LP2 physical p0–55 plaintext, authentic key, original encryption mechanism, or final destination has been recovered.** This document addresses [Director task #4](https://github.com/FlareZ123/liber-primus/issues/4). The standalone original-input reproducer is [`sims/historical_solve_path_transfer.cjs`](../sims/historical_solve_path_transfer.cjs); its first verified [manual CI run is 42863666879](https://github.com/FlareZ123/liber-primus/actions/runs/42863666879).

## Earlier prime-source handoff: precise authentication limit

The 2013 Cicada **bootable ISO** prime-printing script yields **all 464 primes through 3301**; this **does not establish the same behavior for the separately reported 2013 remote telnet service**, whose transcript appears to omit 73–1223. The local ISO does not authenticate that remote omission. The archived May 2, 2014 signed reply contains eleven whitespace runs matching the first twelve primes with 19 absent, but **only the leading five-space indentation is covered by OpenPGP's cleartext-signature canonicalization**. The ten trailing and blank-line run counts remain byte-source hypotheses. A frozen direct GP29 page-0 inverse using three natural source-prime readings, a control restoring 19, and all 14 visible-F skip bits fails native-GP reference text in every case. Precise bounds and source links: [original input and source-script gate](../im-results/historical-may2-whitespace-source-gate.md) and [reproducer](../sims/may2_historical_source_gate.cjs). The source-to-cipher gap is therefore more specific: the alleged 2013 missing-prime sequence is not present in the recovered original script, and the May 2014 whitespace cannot be treated as an authenticated key.

## The decision for the next source researcher

1. **Find an authentic selector of the original LP2 state or key.** The previous historical chain stops at the corpus delivery. Neither the 14-column order nor the p56 cipher is authenticated as the rule for any unknown interval. A useful new source would be an independently captured 2014 instruction, an actual pre-publication key schedule, or an original page-artwork construction that uniquely determines a key/register and boundaries. The artifact must fix its bytes/reading order *before* looking at candidate plaintext.
2. **Test against genuinely unknown original runes and authentic controls.** The exact p56 32-way F-mask regression establishes that fixed-model source-English scoring can identify a correct historical skip pattern. Any different proposed mechanism should repeat this authentic reference and then freeze its key/state/clock for an unsolved page, including all equal adjacent runes and source word/page boundaries.
3. **Do not promote a fit to a destination.** A transposition preserving histogram, a legitimate XOR identity, and even full reencryption under a freely chosen inverse remain insufficient. A verifiable solution needs independently selected parameters and coherent recovered unknown plaintext or a precise authenticated external pointer.

This exercise yields a **negative transfer decision and a concrete missing dependency**, rather than an identified new original LP2 key. The fixed-source p56 mask discrimination is a positive cryptanalytic control against authentic ciphertext and makes the original-page rejection more informative than a synthetic-only experiment. The complete all-page scan is run with `node sims/historical_solve_path_transfer.cjs --all-pages`; its original prime-schedule length and score finiteness are asserted. Only the **corrected 42864940412 run** supplies valid all-page scores; an earlier run 42864452561 silently exhausted a too-short prime sequence for five long physical pages and its all-page output is invalid.
