## What the independent primary source establishes

Iskander Sánchez-Rola, Davide Balzarotti and Igor Santos, [*The Onions Have Eyes: A Comprehensive Structure and Privacy Analysis of Tor Hidden Services*](https://www.eurecom.fr/en/publication/5152), WWW 2017, DOI [10.1145/3038912.3052657](https://doi.org/10.1145/3038912.3052657), describes a PhantomJS crawler with **three completed sweeps: twice in May 2016 (three days apart) and once in June 2016** (§2.2). Starting from **195,748** publicly collected onion domains, the team discovered **198,050** domain names, visited **7,257** active services and approximately **1.5 million** unique onion URLs. These dates overlap the 2016 signed Cicada continuation clue.

The crucial distinction from other studies is the **collection-mode storage specification** in §2.1: “all the HTTP headers, the HTML code, all scripts”, as well as redirects and links, were saved for offline analysis. The crawler prioritized ten links per page at up to three levels from the homepage; its more expansive **connectivity mode explicitly did not retain page copies**. The study reports approximately **81.07%** of active sites completely crawled in collection mode, **18.49%** completed only in connectivity mode, and **0.54%** with more than 10,000 URLs not fully visited. Its dynamic PhantomJS capture is not established to be byte-for-byte identical to the origin's HTTP response entity; that is a distinct requirement for an exact hash preimage.

Primary research artifacts: [author-hosted paper](https://santosgrueiro.com/papers/2017/2017-sanchez-rola-onions-www.pdf) §§2.1–2.2; [EURECOM publication record](https://www.eurecom.fr/en/publication/5152); [independent 22 December 2016 university announcement](https://www.deusto.es/en/home/campus-life/news-events/news/the-structure-and-privacy-analysis-of-the-dark-web-authored-by-researchers-from-deustotech-and-eurecom-has-been-accepted-in-the-flagship-international-conference-www-2017/noticia). No publicly accessible raw-body or host-list release was identified in targeted publication/author searches on 13 November 2026, which is a *search limitation*, not evidence that original data have been destroyed.

The manuscript describes a deep-web page whose content hashes to this value; SHA-512 is a testable 512-bit candidate, **not an explicitly labeled algorithm or serialization**. This named host is a historically authenticated **known LP2 index**, not an independently established locator for the unknown hash preimage.

A productive custodian lookup has **two separate levels**, because the printed p56 digest **does not give the target onion hostname**. First, ask whether the specifically documented **book-distributor host** `ky2khlqdf7qdznac.onion` was collected in May–June 2016, and whether the stored pages are original unmodified HTTP response-body bytes with UTC capture metadata. This is a *known-host and capture-fidelity positive control*, not a complete preimage search.

**Authentic body-control if the known host was captured:** compare a surviving root-index response to the historically preserved 1,640-byte ASCII LF specimen `resources/cicada2014-onion7-index.html` (title `133`, element id `331`, image links `0.jpg` through `57.jpg`). Its original-body SHA-256 is `9d515f2c170c44ab0f5acbdc7ba2de2be62cc07b132ab7f9609532b3b5622e80`, SHA-512 is `83e50c118edb70dc34c9c760e332830a066b82006ebbbdcc7347b818d1961a571f32ef5a3717e98e282754d4a004dc0f7f0d99fb3824bb1b281a947c7ba70a31`, and Git blob SHA-1 is `303db130705f0ef9be2a738f4336d5cfcebde80c`. The known-index digest and its failure to match the different printed p56 target were **already established** by [the Onion7 index digest study](../im-results/onion7_index_an_end_digest.md). The new use is as a predeclared data-fidelity control for this independently identified academic 2016 corpus. Disagreement may reflect page changes after 2014, DOM serialization, line endings, or absent original HTTP bodies; it cannot be silently repaired until a hash fits.

**Second, decisive level: one custodian-local corpus-wide digest equality query**, conditional on consent, retained raw bytes, and a reasonable privacy/data-access policy. Because the actual target URL is unknown and the named host only distributes LP2 images, an exhaustive *one fixed digest* SHA-512 comparison across this academic corpus's original page-body bytes is a materially stronger discriminator than searching only `ky2khlqdf7qdznac.onion`. The custodian would disclose **only whether any exact match exists**, and if so its one matching URL, byte size, capture UTC, body-preservation method, and validated digest. No other site content, address inventory, browsing activity, or bulk archive transfer is required. If a whole-corpus query is denied or infeasible, only the limited known-host test remains available. A negative across that known host **must never** be presented as absence of the p56 preimage across unknown onion URLs.

A source-preserved response-body digest match would be decisive original evidence. A nonmatching rendered PhantomJS DOM, connectivity-mode-only URL, absent known distributor host, or unverified body-retention format remains inconclusive.
