## Requested decision

1. Cite the precise original physical page/line/visual mark that would cause the player to try the action.
2. Specify the authentic historical operation, all operands and numerical conventions, direction, and stopping rule **before observing output**. If the evidence only proposes a class of operations, explicitly state the missing selector.
3. Predict one exact, independently checkable original-rune or plaintext feature at a **withheld** page/line/offset. For a claimed decipherment, give a fully reversible forward map with an exact output and a source-fixed key. A visually interesting coincidence without a reversible receiver is incomplete.
4. Report the earliest point where the inferred route requires an unprinted key, arbitrary alignment, unsourced image identification, unconstrained cipher family, or knowledge of later solver interpretations.

If nothing specifies a unique next step, the useful answer is the **earliest precise source gap**. Do not optimize generic Vigenere, Atbash, transposition, number-string, or steganographic settings to recognizable words.
