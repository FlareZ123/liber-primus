# Liber Primus — original source packet

This packet contains 56 original page images in their release order, labeled p00 through p55. These labels are packaging labels only. The JPEG bytes are unmodified. The context folder contains original Cicada-published material and a public key for signature verification.

## Independent task

Study the supplied artifacts as a puzzle. Identify any structure or operation that is selected by something visible in the original materials. For each candidate, record the exact clue, operation, parameters, and a prediction on an untouched page or region **before** testing it. Do not assume that all pages share one cipher or that an attractive numerical match is intentional. A report of no independently selected operation is a valid result.

## Working rules

- Use only the first-party context described in ALLOWED_CONTEXT.md.
- Do not consult third-party walkthroughs, community interpretations, modern solver repositories, derived transcriptions, plaintexts, or current research notes.
- Do not use an LLM or AI assistant as a substitute for independent human observation.
- Preserve the original images. Do not crop, recolor, deskew, or recompress source files before recording the original observation. Any derived view must be reproducible and clearly marked.
- Keep a timestamped record of observations, tools, versions, parameters, and outputs.
- You may stop at any time. No solution is presumed or required.

The session facilitator should provide no hints, candidate keys, issue descriptions, or prior research findings.
