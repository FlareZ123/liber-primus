## Original evidence and the one frozen inverse

The original May 2014 Onion7 delivery HTML, preserved verbatim at [the original 1,640-byte index](../resources/historical/stage11-2014-index.html), has **58** ordered publisher image references, `0.jpg` through `57.jpg`. Its non-image metadata contains the conspicuous numerals `<title>133</title>` and `<div id="331">`. A 2014 participant could inspect these HTML tags while looking at the entire image collection. An earlier Cicada stage actually used original OpenPuff 4.00 to distribute the 745-byte `magicsquares.txt`; the historical [original 2014 MP3 extraction](../im-results/openpuff-jpeg-capacity-gate.md) reproducibly recovers the file under A=`33011033`, B/C off, MP3 Maximum 1/2. Original native OpenPuff v4.00 can split and recover one payload across two JPEGs, and detects reversed carrier order on its genuine synthetic two-carrier positive [43692988537](https://github.com/FlareZ123/liber-primus/actions/runs/43692988537).

**The experimental leap:** interpret the otherwise unexplained HTML title/id as an *affine ordering rule* over the published image set:

```
publisher_page(i) = (133 * i + 331) mod 58,  i=0..57
original canonical scan = (17 + publisher_page(i)).jpg
```

This is a complete permutation because `gcd(133,58)=1`. The first five publisher indices are `41,0,17,34,51`, selecting original file order `58.jpg,17.jpg,34.jpg,51.jpg,68.jpg,...`. The original archival published order itself was already tested and natively rejected under the same OpenPuff password and JPEG depth in [run 43682354083](https://github.com/FlareZ123/liber-primus/actions/runs/43682354083). The affine order is therefore a distinct source-constrained carrier hypothesis, not a duplicate of that prior direct test or the previous *runic text* 133/331 page-permutation experiments.

The source identifies the two integers, corpus size and original JPEGs. **The weakest link is unselected creator intent:** no authenticated author instruction commands an affine permutation, specifies an OpenPuff stream in LP2 or binds `133` as multiplier and `331` as increment. The order was frozen before the extraction response; the negative does not prove that the tags are irrelevant to the actual book cipher.
