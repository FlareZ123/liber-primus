# Constructive shared q256 key assembly from independent long-group windows

**Agent12, 25 November 2026. Decision:** planted secret q256 key fragments are recoverable under a wider insertion-only postshuffle model, but the original has no comparable coherent fragment graph. This is a calibrated constructive search failure, not an exhaustive key-period exclusion. No unknown LP2 plaintext or key recovered.

## Receiver and exact fragment generation

Use the same [35,944-form GP29 register and original 2,896-group parse](lp2-q8-single-null-postshuffle.md#whole-book-shared-key-exclusion-through-period-183). The earlier proof excludes one shared cyclic key through q183; the original numeric panel has 256 cells but does not select an unknown cyclic key or its construction. Ask whether a common q256 additive tape can be recovered from its overlapping lexical constraints without specifying its entries. Grant arbitrary group phase, either consuming or literal-hold F independently, arbitrary group permutation and zero or one arbitrary inserted non-consuming ciphertext rune. Unlike the six-prefix bound, generate **all eight-consuming-digit windows**, including internal and suffix positions, of every complete compatible lexical inverse for the 109 original groups of observed length≥10. Each key-window integer is counted once per original group. Base29 eight-digit integers fit exact IEEE-754 integer range. Every planted true window is asserted present.

A preliminary assembly on tuples supported by two or more distinct groups recovered a 15-symbol true key fragment, but 82,706 supported tuples in the first plant (only112 true) exposed a major confound: similar or identical observed cipher substrings can cause thousands of perfectly legitimate but redundant candidate intersections. The improved filter re-enumerates the same tuple space and requires two **distinct groups with distinct consumed ciphertext eight-tuples** as witnesses of each shared key eight-tuple. Null deletion and literal F bypass are handled before computing these ciphertext windows. If the first group has multiple distinct witness windows, any other group's witness suffices; otherwise the other group must have a different window. This discards redundancy while retaining 111/112 of the first plant's true multi-group key tuples. It is a heuristic selection rule for reconstruction, not a necessary condition on every real key.

For retained tuples, connect pairs at displacement d=1..4 when the first tuple's suffix k−d exactly matches the second tuple's prefix k−d. Assign relative offsets modulo256 inside each connected component; count conflicts from inconsistent offsets or symbol assignments. Rank conflict-free components by number of determined key symbols, then summed group support. This deterministic selection never uses the planted key. It returns a partial cyclic tape, with unspecified positions explicitly -1. It does not attempt to join unsupported gaps.

The two nine-symbol tapes are simply vocabulary intersections, not recovered keys. No original plaintext language score or hand-picked crib enters the assembly.

Three rare Gibran lengths require fallback to the pooled held donor tails (explicitly recorded). These are target-excluded length-matched word samples, not contiguous prose or unseen vocabulary. All strongest components consist entirely of actual consecutive hidden key symbols up to rotation. The first plant was used to develop the witness filter and two additional plants test the frozen method. No control recovers all256 digits, and original phase distributions could deliberately avoid overlapping anchors. This is therefore evidence against typical independently phased long-word instances of the receiver, not a universal q256 impossibility or a new author-selected clue.
