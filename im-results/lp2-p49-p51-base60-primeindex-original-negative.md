# LP2 p49–p51 source-table prime-index inverse: original-cipher negative

## Question and source-selected input

The original 2014 floral-framed physical leaves p49, p50, p51 interrupt their runic prose with **256 printed two-digit base-60 values**. The ten, thirteen and nine eight-entry rows are contiguous across the three leaves, and are canonically transcribed in `resources/liber-primus/lp2-grid-256.json` (256 entries, **161 distinct bytes**). The adjacent rune-bearing leaves have 66 runes on p49 and 92 on p51, giving **158 GP29 cipher runes in 38 printed words**. The table could, in principle, furnish a reproducible key selected by the original illustration and layout. This experiment tests one precise, independently defined candidate: choose the k-th prime by each printed table-byte index and use **(prime[byte]−1) modulo 29** to reverse a GP29 additive cipher on the 158 adjacent runes. This is an exploration, since the historical source has not supplied the prime-index instruction.

The **source operation** is implemented entirely in `sims/p49_p51_table_prime_index_key_gate.cjs`. The first practical execution was blocked by an undefined `directMasks` binding in the `directVariants` loop; Agent7 changed that single identifier to the already-declared `masks` array and remotely checked the repaired file. The command completed under Node.js 22 on Windows: [CI execution, 23 Nov 2026, run 45116970992](https://github.com/FlareZ123/liber-primus/actions/runs/45116970992). This file records the measured result of that actual source run, rather than inferring a successful test from the script's presence.

## Decisive result

The script tests all frozen direct variants with original and source-page-reset clocks, source start indices 0 and 10, and no mask, fourth global F, or fourth p51 F as literal null. Its best original-cipher direct GP29 trigram log score is **−6.1353096146** per symbol, from source offset 10 with a p51 reset and global-fourth-F null. The unmodified adjacent ciphertext scores **−6.6522093462**. Among 100 deterministic shuffled-table controls, **24** perform at least as well as this original best, giving the add-one descriptive exceedance **25/101 = 0.2475247525**. The best reconstructed words are not readable natural GP29 English; this result provides no plaintext.

The exact finite skip-aware key inference (repeat-suppression weight0.83, at most four skips per printed output and40 total) gives maximum original-cipher natural-versus-uniform log-likelihood ratio **−104.0955822** (offset0, reset at p51, global fourth F). All twelve skip candidates are negative. The original source's adjacent rune stream therefore gives no positive support for the typed prime-index keystream family.

A positive control applies this same model to 158 native-GP source symbols with a true source table, deliberately inserts seven skips, and recovers a **true-key log-likelihood ratio +60.6275439**, versus **−102.2262990** for the reversed key. The original known p56 85-rune prime-totient/F-typed decryption also reproduces exactly. These controls show the implementation can register a real key signal under the tested family, without proving any broader negative cryptanalytic claim.
