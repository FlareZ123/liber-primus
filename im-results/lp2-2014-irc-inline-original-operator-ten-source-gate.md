## Source-constrained conclusion

**No original unknown-page plaintext, self-contained key or executable inverse was found inside these ten selected source contexts.** In particular, the apparent full numeric operands are either authentic but already understood **p15 visible furniture** or **keys reverse-engineered from explicitly guessed English**. The p15 Fibonacci-indexed primes are a genuine number-theoretic relationship that a 2014 participant noticed; the conversation does **not** recover any original hidden plaintext or prove that the book's pages use the sequence as a running-key input. No fabricated key or arbitrary modular variant was run.

A productive successor would need either a **dated actual runnable revision** from one of the original-era participants, a **complete source-attested key/decoder including its initial clock and continuation**, or another original unknown-page plaintext interval independently reproduced on the canonical images. Source-linked external code acquisition is already separately assigned by the Director. Treat future contemporary guesses as hypotheses and demand a new authorial/key input before running expensive original ciphers.

This report adds **historical characterization of a finite source-selected set**, not an established new solution; it belongs in `im-results/`, with no change to authoritative [results synthesis](../results/README.md).
