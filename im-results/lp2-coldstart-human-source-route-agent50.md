**Agent50, Director Issue #1643, 18 November 2026. Evidence class: source-path reconstruction. No new decryption, key, or receiver.**

## Outcome

A fresh source-only pass reaches one compelling human-visible route and then stops at the same missing operation already identified by prior repository work.

The route is:

1. solved p57 says **INSTAR**, **SHED OUR OWN CIRCUMFERENCES**, and **FIND THE DIVINITY WITHIN**;
2. original p55 visibly carries an insect/moth and pale tree, giving a natural page-level referent for INSTAR;
3. the conspicuous pp49–51 number field is printed as a literal **32×8** rectangle;
4. its outer perimeter is **76** cells;
5. original p55 is exactly **76** GP29 runes.

That is a plausible human puzzle path from a solved clue to a uniquely sized unresolved target. It still does not specify a reversible table→p55 operation.

Because this invocation had already encountered the p50-ring/p55 relation before #1643, the 76/76 match was frozen as **contaminated prior knowledge** in `workplace/lp2-coldstart-source-route-freeze-agent50.md` before repository comparison. It is not claimed as a fresh discovery.

## Repository comparison after the freeze

The existing terminal geometry report independently records exactly the same 32×8 → 76+180 structure and the same p57 circumference wording. It also already performs the strongest simple inverses that the cold-start route naturally suggests:

- four physical corner starts × two directions;
- literal byte and Euler-totient reductions modulo29;
- both additive signs on all 76 original p55 runes;
- direct byte XOR/addition/subtraction with p55 GP indices or prime weights;
- fixed byte→GP29 mappings over the 180-cell interior using independently known p56/p57 plaintext;
- arbitrary stationary byte→key lookup calibration on the known 180 terminal symbols.

Those source-shaped receivers fail. Separate reports additionally exhaust arbitrary stationary ring→p55 lookup tables over all 152 ring orientations, value-rank transpositions, perimeter totients, RC4-key use, and several clue-selected variants.

Therefore this cold-start pass does not open an untested low-choice operation. The original clue path itself is already in the repository and its immediate consumers are already bounded.

## Single missing source input

The missing input is one creator-authenticated **receiver specification for the 76-cell table perimeter and 76 p55 runes**.

A sufficient instruction would have to fix, before plaintext scoring:

- perimeter start and direction, or a start/direction-invariant rule;
- numeral interpretation or literal-token serialization;
- how each table cell acts on a GP29 rune;
- state/clock behavior, including whether the operation is positionwise or stateful;
- exact inverse/forward convention.

A first-party clue that fixes those choices would turn the visible 76/76 bridge into a testable decryptor. Without it, choosing among modular shifts, substitution, pointer walks, transpositions, XOR, stream ciphers, or state machines is receiver invention.

## Decision

No materially new route survives the cold-start constraint.

Preserve the human solve-path statement:

The next useful work on this route is source discovery, historical recovery, or a blind prediction that fixes the receiver. More perimeter cipher menus should remain gated.
