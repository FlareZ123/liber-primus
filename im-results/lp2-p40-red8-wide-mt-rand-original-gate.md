## The source-first lead

The 2013 Cicada TCP challenge, signed by key fingerprint `6D854CD7933322A601C3286D181F01E57A35090F`, specified the **BASE29** and **RAND** commands. Its BASE29 example is `3301 → 3QO`. This establishes integer conversion in base 29 and the historical existence of a byte-emitting randomness command, but **does not say** that LP2 used Python's MT19937, how `RAND` was seeded, or how generated bytes were assigned to runes. See [the signed-source record](../resources/external/2013-tcp-server-signed-source.md).

The authentic original LP2 p40 begins with **eight red GP runes**, indices `[0,9,19,26,6,23,25,8]`. Immediately after the heading, the printed p40–53 chapter has **exactly 3,000 black runes**, and its numeric p50 interlude has eight columns. These properties suggest a possible eight-position seeding header while leaving the consumed key projection uncertain. The eight-rune **standard left-to-right unsigned BASE29** integer is:

`seed = 5,761,677,436 = ((((0×29+9)×29+19)×29+26)…×29+8)`.

The original seed exceeds **2³²−1** and therefore was **not included** in the earlier complete 32-bit Python 2.7 MT keyskip search; it occupies two 32-bit `init_by_array` seed words. This eliminates a finite coverage ambiguity without proposing another free integer-seed search.

## Frozen original-cipher operation

Use the historical Python-2.7-compatible MT19937 integer initialization and `random()`'s exact two-word, 53-bit float output. Test two naturally discrete uses, with a continuous phase-zero clock beginning **after** the eight-runic red header, no skips, and both arithmetic signs:

1. **Direct GP29:** `K[t] = floor(29 × random())`.
2. **RAND-like byte projection:** `K[t] = floor(256 × random()) mod 29`.

For all 3,000 unchanged black source runes, `P[t] = (C[t] ± K[t]) mod 29`. This is exactly reversible and has no fitted phase, secret numeric input, page restarts, hidden plaintext crib, or manually chosen next state. The two output projections constitute a small, declared alternative for the ambiguous historical `RAND` interface; neither is authenticated as a Cicada instruction to decode LP2. The model is **unskipped direct additive GP29**, so it does not rule out a source-specified skip/state rule or actual 2013 server output.

## Cryptanalytic decision

The **particular** publicly documented BASE29-red8 → full-width Python MT `random()` → direct GP29 pad fails to recover linguistic original text. Its 5,761,677,436 seed was outside the earlier 32-bit seeded-domain coverage, so the experiment resolves one genuinely new exact candidate. A different historical generator, absent skip rule, non-GP plaintext, and unknown external key are outside this test.

The strongest unsupported premise is that the author's 2013 RAND vocabulary meant **Python MT initialized by the chapter's red numeral**. The sources specify neither this RNG nor its use on the chapter. There is no basis for varying phases, 29-byte projections, key signs beyond those declared, or hidden skip patterns until an independent original instruction selects them. This result belongs in intermediate evidence, while the manuscript's plaintext remains unsolved.
