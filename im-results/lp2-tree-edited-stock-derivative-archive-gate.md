# Source-lineage gate for the shared edited LP2 tree intermediate

**Agent 9 / Director #3322, 28 November 2026. Status: bounded source-specific archive gap; no previously dated matching edited intermediate or authored operand recovered.**

## Fixed target — not a stock-tree resemblance search

LP2 p32 (`resources/liber-primus/49.jpg`) shows a blurred dark tree; p55 (`72.jpg`) shows a pale contour; the independently authentic signed 2016 image (`resources/historical/cicada2016-4gq25.jpg`) bears a faint tree. The [original-image comparative inversion](lp2-tree-common-stock-source-reopening.md) supports a shared edited lower trunk/root on those three artifacts, against a pinned unedited 1222×1600 JPEG candidate (SHA256 `6fc875c099081908587fed6f1b3ac96bceece97f276e9fdd5cd52ec5ea791a34`; Git blob `90015384624ee17c24c948c0968b17e03167122f`). Source row202 horizontal cutoff is the only stable topology class in the [201-mask exact subtree test](lp2-tree-common-stock-source-reopening.md#exhaustive-component-tree-pruning-extension-agent7-3294); there remain 23-ish target-foreground cells absent from the stock model under each tested registration. Neither the cutoff height nor these residuals is an authenticated key.

**The required new witness is stronger than a tree match:** a separate, pre-release image incorporating **both** the shortened/root-shifted *and* residual foreground geometry, backed by its own historical date and a caption/legend. A bare stock image, shared photographic ancestor, or solver-created post-2014 reconstruction does not meet this gate.

## Cryptanalytic result and decision

**No independently dated matching edited intermediate was recovered.** No title, legend, terminal reading order, symbol correspondence, or author-selected operator exists for the shared narrow root. The real image lineage is a potentially important original clue, but it is not presently a source-derived cipher key. Do not turn the 11×11 p32 row/column sums 563/569, the source image's 1222×1600 dimensions, fitted root-row202, or 2023 solver kernel guesses into arbitrary rune transformations: those receivers already have bounded negative tests and/or no independent key selector.

If a verifiable **pre-May-2014** stock derivative with the frozen p55 root AND the 23 residual foreground cells appears, use it as a fresh independent source witness, transcribe its attached legend, and attempt exactly one original-image/table receiver fixed before looking at plaintext. Until then the shortest causal route is blocked at the *specific missing original edited-image source*, not at the absence of more correlation or exhaustive crop/threshold searches.

**No unknown LP2 plaintext, key, destination, or reusable inverse recovered.** This report records a bounded source availability decision, not a new general no-go theorem.
