## Known-quotation predecessor-escape rank-path inverse (Agent4, 24 November)

**Solve hypothesis and reversible mechanism.** The unusually few original adjacent equal ciphertext runes motivate a lossless differential emitter. Take a secret order A of the 29 plaintext labels and a secret bijection D of 28 ranks to nonzero GP29 increments. Let e=f(previous recovered plaintext rune) for an arbitrary stationary marker table f. If p=e, emit increment zero. Otherwise delete e from A, find p's rank r in the remaining 28 labels and emit D[r]; accumulate increments modulo29. Given the key and preceding plaintext/ciphertext state, invert zero as e; invert a nonzero increment by locating r and reinserting e. This changes rune values without requiring plaintext word alignment or a guessed key stream. Neither the manuscript nor historical instructions specify this exact receiver. The original quote is [10279,10439), with its one internal stop at offset41; split at80. The first rune is deliberately granted free because the preceding original plaintext is unknown, leaving 79 prefix differences.

**All-order graph theorem.** For any nonzero observed increment d, the associated rank r can decode only to A[r] or A[r+1] as the deleted escape varies. Form a bipartite graph with 29 plaintext-label vertices and 28 nonzero-increment vertices; add the edge (p,d) at every nonzero transition in a proposed known-plaintext prefix. Any valid key places these vertices in a single alternating Hamiltonian path
`A[0],D[0],A[1],D[1],...,D[27],A[28]`.
Every observed edge must be an adjacency of that path. Thus **one vertex of degree >=3 or any cycle is an exact obstruction**, even granting arbitrary independent escapes. Conversely these two graph constraints are sufficient for the rank-incidence part: each connected component is an alternating path or isolated vertex. The number of components with two plaintext endpoints is exactly one more than the number with two delta endpoints because the graph has 29 vs 28 vertices. Alternate those two types, append mixed-endpoint paths in the appropriate orientation, and concatenate to obtain the required full alternating path. The program constructs and verifies this rank-incidence witness on plants. This sufficiency does not enforce predecessor-marker order inequalities. For canonical fixed plaintext order, a separate exact solver intersects rank domains `{pos(p),pos(p)-1}`, assigns distinct ranks, and propagates upper/lower marker-order bounds for each predecessor.
