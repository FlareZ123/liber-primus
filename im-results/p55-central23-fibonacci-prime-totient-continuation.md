# p15 infinity / p57 23-dot to p55 central-23 Fibonacci-prime-totient gate

**Classification: one source-constrained, finite original-input negative.** This experiment tests a specific cross-page human solve-path hypothesis. It does not recover unknown LP2 plaintext, an authentic key, a cipher mechanism, or the intended destination.

## Why this route was worth one test

Three existing source facts suggest a tightly bounded composition:

1. **p15 numerical instruction.** The original 4×4 square is exactly generated by
   abs(3301 - prime(F[n] + 1)), with the first 16 distinct Fibonacci values and a source-visible spiral starting at the red 3299. An infinity symbol is printed below the square. The first 16 underlying primes are therefore source-derived; extending the distinct Fibonacci sequence beyond the 16 displayed cells is a plausible, but not authenticated, reading of that infinity mark.
2. **p57 selection instruction.** The solved p57 page says to shed circumferences and find what is within. Its terminal red punctuation contains the only red 23-dot mark in the LP2 annotation. On physical p55, stripping the first and last rune from each of its 16 complete words leaves 43 runes; removing ten from either end selects a central 23.
3. **p56 operation.** The independently solved p56 page uses the additive GP29 prime-totient operation: subtract prime(k)-1 modulo 29. Replacing the ordinary sequential prime ordinal with the p15 Fibonacci-indexed prime ordinal gives a source-derived 23-position key schedule.

The weak link is explicit: the manuscript does not state that p15's infinity mark continues the prime-index schedule onto p55, nor that p56's cipher operation is reused there. This is one locked hypothesis, not a discovered key.

## Original-input result

The resulting GP sequence is:

  IA IA I R W H NG OE C L OE EA OE T TH OE NG D H NG R S TH

Retaining the original p55 word-fragment boundaries, the selected output is:

- IA IA I R W H NG OE C L OE
- EA OE T TH
- OE NG
- D H NG R S

This is not recognizable GP-English plaintext. The 23-rune sample is too short for an informative language-score or IoC claim; the reported IoCs are retained only as exact diagnostics, not significance evidence.

The reproducer checks the first 16 prime identities against the original p15 square, the unique p57 red-23 marker, p55's exact 16-word/43-interior structure, the 23 selected original symbols, exact forward re-encryption, and an independent synthetic 23-symbol positive control.

## Decision

**Reject this exact direct model:** p15's continued Fibonacci-indexed prime-totient stream does not decrypt p55's p57-selected central 23 under the solved p56 additive GP29 operation. The result does not invalidate the p15 grid decoding or the p57 circumference clue separately. It does not rule out a different, independently instructed use of either source feature.

Do not continue with alternate starts, reverse order, sign flips, skip masks, or fitted word resets. A successor needs a new primary-artifact instruction selecting a different operation.
