# LP2 original 2015–16 versioned solver sources: four-handle, plaintext-first audit

## Decision

The original 2015–16 Freenode transcript names four period-linked versioned Git/Gist solver handles examined below. The two retrieved git repositories preserve executable **participant-selected exploratory machinery**, but neither supplies an independently sourced key, initialization state, authenticated unknown-page output, or a reversible operator that predicts withheld LP2 plaintext. One original gist implements the already-known p56 prime-1 stream and a configurable example. The formerly inaccessible 2015 `thomasandfriends` Gist has now been recovered and contains only a 58-page rune-count inventory, with no executable decoder or key. **No new LP2 plaintext was recovered.** These observations concern only the four fixed handles, not every historical solver.

The test was deliberately source-to-inverse: before trying any ciphertext, require the archived program to identify *which* original LP2 page and *what* fixed decipherment operand to use. A configurable stream or cribs entered by a player do not meet that gate.

## Source boundary

### 2. Be5haram/CICADA2K16

Original IRC **2016 Feb 12 L296242** by `besharam` links [RuneSolver.py](https://github.com/Be5haram/CICADA2K16/blob/master/RuneSolver.py). Historical Jan 14 commit [4338b032](https://github.com/Be5haram/CICADA2K16/blob/4338b032c082dafcbe0c57f110b28cb5102d7fa5/RuneSolver.py) and Feb 10 [7529449a](https://github.com/Be5haram/CICADA2K16/blob/7529449a8252d681604e81e3d3b52128ce01a0f2/RuneSolver.py) were both retrieved in full. Jan 14 code includes GP29 transliterations and hardcoded rune transcriptions p0, p15, p27–32, p40–53, p54–55; `vigstream` subtracts a manually chosen `stream` modulo 29, while `skipstream` samples characters from `Pages27to32` and asks whether the extracted letters *can* shift p54. Its explicit source comment says `list out of range if spaceless > stream FYI`, and the procedure is interactive, with proposed reversible / prime / totient variants. None establishes its sampled stream as a key. Feb 10 revision removes the old skip cipher, adds a user-parameterized dual-alphabet rotation (direction, shift for letters/spaces/colon, optional custom alphabet) and emits statistics. The default rotating settings are user choices; its `OneirasCode` strings are rune fragments, not documented authenticated unknown-page readouts. **Gate failed: no source-selected input/operand or ≥40-rune unknown plaintext.**

## Cryptanalytic consequence

Both complete historical repositories implement approaches already independently available to the research population, and their interfaces expose choice of key/stream/rotation. There is no supplied fixed operand to run *blindly* against unaltered p0–55 image ciphertext, so performing large numeric parameter sweeps would violate the issue's causal test. The formerly inaccessible 2015 Gist is now recovered in full and conclusively classifies as a page-count list. The four frozen handles thus supply no original unknown-page key or plaintext. Revisit a handle only if an independent period revision with a different original payload emerges; no more exact-ID acquisition is needed.

As of this bounded audit, **unknown LP2 plaintext recovered: 0 runes**; no established result is promoted to `results/`. This is an intermediate exclusion and handoff under [Director Issue #912](https://github.com/FlareZ123/liber-primus/issues/912).
