## Distinct algebraic decision

For a *fixed public* lane map L(i) in {0,1}, let q=(8,13), K_l a length-q_l vector and s_l its phase. With native transparent F, plaintext P_i=0 requires C_i=0 and holds s_l; otherwise C_i=P_i+K_l[s_l] (mod29), advances that lane only. Let n_l(i) count earlier nonzero plaintexts assigned to lane l. For any proposed complete known plaintext, form
D_i=(C_i-P_i) mod29 at its nonzero sites.
A key exists **if and only if** all zero plaintexts emit zero and D_i is constant in every equivalence class (L(i), n_L(i)(i) mod q_L(i)). Starting phases are absorbable into the key rotations. Read each occupied class once to recover the corresponding key shift; unoccupied classes remain free. This eliminates every unknown key parameter for the crib test without enumerating F masks, and makes the held prediction criterion explicit: each withheld consuming class must already have an assigned value. A zero ciphertext does not imply a hold.

For ordinary-consuming alternating physical indices, the effective stream is K0[floor(i/2) mod8] on even positions and K1[floor(i/2) mod13] on odd positions. Its common period divides lcm(16,26)=208 and has only 21 independent shifts. With both lane keys primitive the minimal period is exactly 208: an even period must be divisible by both 16 and 26; an odd period would identify the two lanes by a shifted copy and force a common period dividing gcd(8,13)=1, contradicting primitivity. Thus ordinary parity is already a constrained subfamily of a single 208-phase clock, not a new two-layer cipher. The F-held case differs because the two lane-specific nonzero counts are not determined by physical position.

Without a crib, language restriction, or independently constrained nontrivial key, ciphertext-only phase reachability cannot exclude the all-key family: K0=K1=0 and P=C always provide a valid path under either clock. This holds for every fixed public lane assignment. Exact replay alone likewise cannot select a historical key.
