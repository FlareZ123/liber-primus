## Source and discriminating experiment

Search the original **May–August 2014 timestamped solver messages** for a direct claim or question about deciphering physical p0–55 accompanied by a previously unindexed actual decoder/code/paste/file link. The original source objects are (1) the primary Freenode channel, Git blob SHA1 **bdd277c14f94c34b5ae714cd00c238065beeed4e**, 18,487,233 bytes; and (2) the secondary Freenode channel, SHA1 **a2880b1db31ce523599ef30ca2e55291bf295900**, 8,629,610 bytes. These are period participant observations, **not authenticated author messages**.

The [read-only original-byte source parser, including true-positive and p56-exclusion controls](../sims/lp2_2014_irc_nonp56_multirune_claim_link_sft.cjs) confirms both source Git hashes. It selects non-p56 page claim-like messages and tests only code/paste/file URLs in a source-local **±9 printed-log-line, ±12-minute** window, excluding prior dated UnRuneIt JAR, historical paste, solved LP1, Neocities, and storm-dump targets. The parser is deliberately more restrictive than a generic all-link inventory and does **not** claim to screen every conceivable 2014 message.

[Full Windows Node.js 22 original-byte PASS 45002430607](https://github.com/FlareZ123/liber-primus/actions/runs/45002430607), with independent initial identical-count [PASS 45002200446](https://github.com/FlareZ123/liber-primus/actions/runs/45002200446), found **seven** claim-word-containing primary messages, **zero new eligible code/file links**, and **zero** claim messages in the secondary channel. The source predicate also matches questions; seven does **not** mean seven genuine decryptions. The planted control recovers a source-like p10 decryption accompanied by a nearby code URL and correctly rejects a p56-only plant.

## Research decision

The precise **contemporary claimed non-p56 decoder plus a new immediately linked file** path yields **zero actual unpublished artifacts** to acquire and therefore no original-key receiver or plaintext continuation. Close this bounded path. This negative does not show that an uncaptured 2014 upload, private response or creator-signed instruction did not exist. Such a discovered source artifact would warrant a fresh original-byte decoder test; further guesses at participants' local single-word offsets cannot supply a portable unknown-page key.
