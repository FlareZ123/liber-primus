# LP2 GP29 nonzero-step 28-phase escape cipher: exact all-key original equality gate

Original source-based conditional no-go; no unknown LP2 plaintext or authentic key.** This tests the most natural phi(29)=28 clock that survived earlier global-output IoC screens. ## Original clue and executable reversible candidate

The original p0–55 source has 12,956 GP29 rune positions in 2,896 complete printed words, with only 86 identical-adjacent original rune pairs. On a 29-rune prime-field alphabet, a very simple 2014-executable reversible operation reserves each **zero modular ciphertext difference** to encode a rare fixed plaintext sentinel rune, and maps one of the **28 nonzero differences** to the remaining 28 plaintext runes through a secret 28! permutation. The solved Liber Primus author explicitly values **the primes and the totient function**; since φ(29)=28, a 28-step period is a plausible testable public clock. Nothing known actually instructs solvers to use this cipher, and the fixed escape assignment is a hypothesis.

Let C_i be the untouched GP29 ciphertext rune, P_i a putative GP29 plaintext rune, and **EA=28** the selected rare plaintext escape for an explicit complete inverse:

\`\`\`text
d_i = (C_i − C_(i−1)) mod 29
P_i = EA                                      if d_i = 0
P_i = F[segment][phase_i][d_i − 1]             otherwise
phase_i = (i − segment-start) mod 28
\`\`\`

Each F[segment][phase] is a completely unrelated secret bijection from 28 nonzero-step ranks to the other 28 GP runes; the first original cipher token uses a fixed public predecessor 0 for the separate full-replay control. Inverse: output the identical ciphertext predecessor for plaintext EA, otherwise apply the private inverse permutation and add one plus its nonzero rank to the prior ciphertext modulo29. This **needs no extra exception bits**, and is a genuinely fully reversible cipher for every 29-symbol native-GP plaintext (not only typical words). The exact original 86 repeated-ciphertext transitions force 86 plaintext EA symbols, regardless of any hidden keys or segmentation. For the collision test, only **nonzero** source step positions are scored, which grants the model a generous exemption for its 86 literal escape positions.

Four independent, source-visible key-scope choices were tested, resetting the φ29 phase and allowing entirely fresh unrelated 28! permutations:

1. One global period28 key (1 segment, 28 private alphabets).
2. Each printed major original large-mark interval (29 segments, 812 private alphabets).
3. Each physical rune-bearing original page (55 segments, 1,540 private alphabets).
4. **Union of every major mark and every physical page seam** (74 segments, 2,072 independently arbitrary private alphabets).

The fourth version is much more permissive than what any reported historical clue uniquely selects. It includes simultaneous mark and page keys even when a mark sits at a page seam. Its source-controlled 74 segment starts, 28 phases, 86 echo sites, and all 12,956 original rune indices are independently checked. There are **1,848 actually occupied state buckets** in this strongest model. The test neither fixes the original word lengths as plaintext boundaries nor borrows any author-unprovided key from the original ciphertext.

## Exact equality theorem across all private keys

For any two positions i and j with the same authentic source segment and phase, and with both observed source nonzero differences, the same hidden 28! permutation is used. Thus

\`\`\`text
P_i = P_j   ⇔   d_i = d_j .
\`\`\`

The total number of identical input-difference pairs within every (segment,phase) group is exactly the same for the unknown plaintext after **every** possible secret private table. Count unordered equal pairs inside each observed source bucket; compare with **native GP29 plaintext controls placed at the exact same positions**. This tests direct GP29 written prose without relying on global IoC maximization or guessing a key.

Every native-GP English candidate compared retains **the same entire 12,956-rune length** and is allowed arbitrary word boundaries; original physical marks supply only publicly visible state segmentation. There are **128 deterministic full-length contiguous donor windows per source** from Gibran, Shakespeare and Emerson, encoded to GP29 with a normalization independently validated against the exact original solved p57 clear rune text. For the most permissive fourth model, the source-native minima are **2,781 Gibran, 2,667 Shakespeare and 2,802 Emerson**, all strictly above **1,648**. All **384/384** independent literary windows are incompatible with every key under **each of the four source-defined segmentations**.

To avoid relying only on other English authors, the fourth model was tested against **256 independently seeded complete-original-length, original-complete-word-length matched native GP29 controls** sampled from already solved Cicada GP source words, with half the solved source records held out. These finite native-GP controls do not prove every possible English passage impossible; the original message's true register is unknown.

### Exact positive model and source replay

The SFT creates all **2,072 independent 28! maps** for the strongest 74-zone model, using seeded Fisher–Yates permutations, and builds their exact inverse maps. It (a) decodes and completely re-encodes all **12,956 untouched original ciphertext runes**, preserving the 86 authentic repeated-ciphertext escape locations, and (b) independently encrypts and decrypts a full-length 12,956-rune source-native Gibran passage under the same keys and verifies the within-phase pair count is identical for generated ciphertext ranks and their actual native source. The public source marks and pages remain fixed side metadata across the reversible operation.

The explicit original-source synthetic plaintext is intentionally artificial; its exact replay validates the inverse but is **not** evidence of a Cicada key or recovered plaintext. The complete native positive proves the equality obstruction accepts a real plaintext when its corresponding ciphertext was actually generated from the tested architecture.

## Research consequence

Earlier whole-book all-secret **majorization IoC** bounds ruled out arbitrary **periods 1 through 27** for source-mark-reset *direct GP29 rune substitutions*, yet period **28** escaped a whole-book frequency capacity threshold. The present theorem closes the **separately motivated period28 rank-of-nonzero-differences with fixed-EA escape** model, including independent private keys at every original large mark and every page, against all tested native-GP controls. It is stronger than the earlier frequency necessity screen for this structurally different model.

A period28 mechanism with **plaintext-dependent feedback**, a newly rekeyed table within each printed line/word, a changed plaintext length or register, or a different rare-symbol escape mechanism may evade this equality law. Those alternatives need independent author-selected state/keys or source-visible side information. Further optimization of a single 28-phase table under the current precise hypothesis cannot recover native prose from this original manuscript and is not a promising use of compute. **No original unknown-page plaintext, authentic key, or puzzle continuation is recovered.**
