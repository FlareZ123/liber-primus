# LP2 p50 low-value mask: compact GF(2) recurrence gate

## Decision

Director Issue #1518 is negative under its frozen compact-LFSR criterion. The row-major 256-bit p50 low-value mask, with `z[i]=1` exactly when the canonical raw table value is `<60`, has exact GF(2) linear complexity **130**. The minimal recurrence learned from the first 128 bits has order **65** and makes **61 errors on the untouched last 128 bits**, with its first held-out error at global cell 132. Both orders exceed the predeclared source-plausible ceiling of 32, and the first-half recurrence does not predict the held-out half.

The consequence is narrow and decisive: do not replace the literal 256-cell p50 lookup mask with a compact linear-feedback clock. This result says nothing about nonlinear generators and does not weaken the previously established p50 low-value/digit-0 ciphertext association.

## Source and frozen sequence

Input is the repository's canonical original-grid resource:

- `resources/liber-primus/lp2-grid-256.json`
- 256 row-major values
- `z[i]=1` iff `bytes[i] < 60`
- exact weight: **60/256**
- first-half / second-half weights: **31 / 29**

This is exactly the 60-cell class selected by #1508: the 60 lowest base60 raw values coincide cell-for-cell with the literal-leading-zero class.

## Exact minimal recurrences

Berlekamp-Massey over GF(2) gives the full 256-bit sequence minimal order **L=130**. Using the convention

`z[n] = XOR(z[n-j] for j in taps)`

for all positions where the recurrence applies, the full-sequence tap lags are:

`4,5,6,7,8,10,13,14,15,16,18,21,23,24,25,28,30,36,37,38,39,41,44,45,46,49,52,54,56,57,60,63,64,65,67,71,72,76,77,82,84,87,92,93,99,100,103,104,106,107,110,112,114,115,120,122,124,127,128,130`.

Training only on cells 0..127 gives minimal order **L=65**, with tap lags:

`1,2,6,7,9,10,11,12,13,16,19,20,21,23,25,26,27,28,32,34,37,38,39,41,43,45,46,47,48,49,55,63,64`.

Freezing that recurrence and extending sequentially over cells 128..255 yields **67/128 correct and 61/128 wrong**. The first failure is at cell 132. No phase, alternate direction, nonlinear update, or order increase was introduced after inspection.

## Matched exact-weight calibration

The reproducer also draws **20,000** deterministic uniform random masks with exactly 60 ones (`seed=0x1518`) and applies the same measurements. This is a scale comparison rather than an authorship p-value.

- full-sequence linear complexity: mean **128.2227**, range **121..135**; **1,680/20,000** null masks have complexity at least 130;
- first-128 linear complexity: mean **64.2324**, range **58..73**; **0/20,000** have order <=32;
- held-out prediction errors from each mask's first-half recurrence: mean **63.9392**, range **42..86**; **6,610/20,000** have no more than the source's 61 errors;
- exact held-out prediction: **0/20,000**.

The source mask is therefore ordinary-looking at the linear-complexity scale relevant to this issue. Its complexity is not unusually small, and its first-half recurrence has no useful held-out predictive power.

## Scope

This closes only the specific #1518 interpretation that the 60-of-256 p50 class is generated by a compact binary linear recurrence of order at most 32 and can therefore serve as a short LFSR-style cipher clock. Because the gate fails, no 12,956-position prospective clock is generated. Future p50 consumers should retain the printed 256-cell mask directly unless an independent source clue supplies a different generator.

No unknown LP2 plaintext, key, or cipher mechanism is recovered here.
