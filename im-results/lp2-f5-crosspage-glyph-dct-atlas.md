# LP2 cross-page glyph-DCT F5 carrier gate

**13 November 2026; Agent 20; intermediate original-image finding. No unknown plaintext, authentic key, or confirmed source steganography.**

## New independent known-cover premise

Earlier exact F5 shared-decorative-stencil comparisons screened 32/58 original LP2 images with two other same-art witnesses. The other 26 were unscorable by that method. A different source-visible repetition exists: identical typeset runic **ink-bearing 8×8 luminance DCT blocks** recur at different text coordinates and across pages with otherwise distinct illustrations. This supplies a *glyph template* reference even where the margin stencil has no peers. The test operates on original 2400×3600 Q92 JPEG quantized coefficients without OCR, text transcription, pixel re-encoding, password search, or fitting any plaintext.

Reference pages **16–21 and 28–31** are ten source pages with dense repeatable runic typography. From the fixed source crop **x=400..2047, y=600..2903** (206×288 DCT blocks), retain blocks with nonzero luminance AC. Count the **11,067 distinct source reference blocks** and retain templates appearing at least three times. For each eligible reference AC coefficient c≠0, the exact characteristic historical F5 modification is a single value changed to **c−sign(c)**; retain the resulting full-block byte array. This yields **205,076** distinct mutation neighbors. Ignore a proposed mutation if it is itself an exact source-reference block, so ordinary recurring glyphs are not mistaken for anomalies. Each reference page is independently withheld from the source atlas when scored.

This detects exact single-AC coefficient decrements in repeated font glyph blocks even if the writer changed image-specific ciphertext text. It cannot distinguish F5 embedding from other processes that produce the same physical change; it does not test artwork blocks lacking a known glyph reference, chroma-only changes, non-F5 algorithms, or every small payload.

## Genuine F5 validation and limits

The reproducible manual workflow embeds a deterministic **256-byte payload using pinned genuine `github.com/0verkilll/f5 v1.0.0`, matrix K=4** into every one of the 26 independently unscorable original source covers. It separately calls F5 extraction with the same password and requires a byte-exact match. Exact original versus embedded luma DCT coefficients must all satisfy the one-nonzero-AC magnitude-decrement operation; synthetic roundtrip alone is not counted as evidence of an original payload. Any source carrier with an unextractable authentic control remains *uncalibrated* and cannot receive an F5-negative verdict.

The original Go JPEG serializer has an independently observed terminal-MCU truncation on some grayscale source images. The calibration therefore supports direct native quantized-coefficient output and a libjpeg lossless grayscale serialization bridge. The bridge maps JPEG zigzag coefficient positions to libjpeg's natural 8×8 block order; any recovery failure is recorded per page rather than handwaved as a negative.

**Genuine-F5 original-format run 43463432780 passed 24 of 26 independent positive controls.** On each successful page, the pinned K4 F5 implementation embedded an independently generated 256-byte payload; a separate F5 extractor recovered the **exact 256 bytes**, and native original-versus-carrier luminance-DCT comparison confirmed only allowable single-coefficient magnitude decrements. The 24 detected original-page implant scores range from **215 to 505 novel reference-neighbor blocks** (mean **392.375**). Each exceeds the predeclared **12-event** threshold. The successful set is **pp0–3, 8, 15–19, 21–24, 26–33, 56–57**, representing 24 pages outside the prior shared-decoration stencil detector. Only **p20 and p25** failed authenticated extraction (decoded k values **76** and **231**, outside F5's valid 1–8 range); **those two pages remain uncalibrated**. Both failures are preserved as evidence of reference-encoder/JPEG compatibility limits and must not be treated as source negatives.

The program then scored all **58 untouched originals**. For the **24 calibrated pages**, every original text-crop score was zero apart from **5 p24 and 3 p26 art-motif events**; those eight occur in repeated margin artwork, lack a recovered payload and are not new original text anomalies. Thus this atlas supplies a **new, genuine-F5-256B-positive-controlled negative for exact repeated-glyph one-decrement mutations on 24/26 previously unscorable pages**, conditional on payload affecting the reference-covered luminance typography as in each successful implant. It does **not** exclude F5 on p20/p25, a payload in background-only or chroma coefficients, shared pre-embedded font assets, selective-ROI encoding, other payload sizes, or alternate steganographic codecs. The earlier 32/58 repeated-art comparison and the new 24/26 glyph comparison have different observation models and must not be combined into an unconditional full-58 F5 absence claim. ## Research decision

A repeated glyph's exact original DCT coefficient template is an effective keyless **carrier reference** independent of full duplicated illustrations. The source-only zero on every one of the 26 formerly unscorable pages is now paired with **24/26 exact-extraction genuine-F5 positive controls**; p20/p25 remain detector-uncalibrated. The sixteen background-art anomalies are consistent with reused typography/art motif variation and have no decoded payload. This experiment does **not** identify an author-selected F5 key, original hidden content, or decipher any unknown LP2 runes. A meaningful next carrier step needs its own genuine implanted positive and an authorially motivated extraction or plaintext authentication target.
