## Source boundary and proposed operation

The pinned, archived 2012 49-word participant example is [resources/historical/cicada2012-midi-49-words.txt](../resources/historical/cicada2012-midi-49-words.txt) (49 tokens / 47 distinct; `box` and `tray` repeat). A separate preserved participant account records a distinct redacted example and says that each recipient received unique words. It does not attest this 49-word sample as a common LP2 key. The **original MIDI chorus** was the explicitly directed 2012 guide.

The independently signed 2016 message says that *Liber Primus* is the way, and that **its** words are the map. The previously investigated **unverified** word-address interpretation is GP prime sum `S` → **physical LP2 page `S mod 58`** and **zero-based printed word index `floor(S / 58)`**. No signed source names the 2012 personal MIDI list as input; neither the modulus/quotient order nor the zero-based origin is authenticated as a cipher grammar. This report tests the already-existing reading without optimizing its orientation or phase.

For this separate English wordlist, GP spelling maps V→U, K→C, Z→S. GP lacks Q, so **Q→CW** is a disclosed *additional, unselected* transcription choice for the single word `square`. Replacing it with Q→C changes that word's address but changes **none** of the five page-50 results. [Canonical GP corpus](../resources/liber-primus/lp2-corpus.json); [source printed-word segmentation](../resources/lp2-transcription.txt); [source 32×8 numerical table](../resources/liber-primus/lp2-grid-256.json), spread over pp49–51. Original physical p50 contains 104 of the 256 table cells and no rune-printed words.

## Matched chance controls: fixed hypothesis, finite scopes

[Single runnable original-source test](../sims/2012_midi_49word_p50_address_sft.cjs) ([successful Node 22 GitHub Actions check](https://github.com/FlareZ123/liber-primus/actions/runs/43128585100)) uses the complete original wordlist, canonical GP weights, signed 2016 message, printed source table, original chorus, and existing [TextBlob English-frequency lexicon](../resources/control/english_wordfreq_textblob.txt). The SFT freezes the mapping, preserves the exact source word forms and duplicate positions, outputs all 49 addresses, tests Q→C sensitivity and asserts these deterministic null counts.

Seeds and algorithms are pinned: xorshift32 `0x20124350` for shuffled-weight draws; xorshift32 `0x20124351` for length-matched English draws, using lexical type-uniform sampling with replacement and fixed source duplicate positions. Denominators are simulations, not independent historical wordlist samples. The original 49-word count and specific p50 first-row cell subset were found *after* considering these source materials; none of these finite fractions is a preregistered probability of intentional Cicada design. In 100,000 GP-weight shuffles, **6,904** produce at least eight cross-wordlist sum coincidences, versus eight original sample overlaps, and **584** produce equality between the two pre-named words `boat` and `lies`. Picking *some* page with five or more hits is common (~14%); p50 is a visually distinctive runeless table page, but the cross-round reference itself remains speculative.

## Decision and what would genuinely advance the route

The five p50 hits are a real arithmetic concentration under this **chosen** alphabet/address model. There is no preserved signed or player-visible historical instruction linking these **recipient-specific** 2012 words to LP2 page 50 or defining the proposed map. The p50 five-cell readout provides no independently predicted rune inverse, missing key, or withheld plaintext. The 2012 instructions supplied the list for an already-completed e-mail step.

**Close the claimed 2012→p50 map as an unauthenticated decryption route.** Retain the exact five-cell anomaly and null controls as provisional evidence for future re-evaluation only if a new original source explicitly selects the 2012 input *and* fixes the address or use of the table output before original LP2 ciphertext is inspected. Do not launch arbitrary phase, radix, cell-order, XOR or key sweeps on this post-selected subset.
