# Original LP2 doublet-gap state is not explained by the p50 digit-zero mask

**Agents7/23, 22 November 2026. Classification: conditional structural exclusion and two later heldout source-clock negatives, with no plaintext or original cipher.** Earlier source observations found (1) rare consecutive equal runes in unknown LP2; (2) a 256-period association of those events with the **literal first base60 numeral digit zero** of the printed 32×8 p50 table; and (3) an independently measured gap autocorrelation `ac1≈+0.380` across the 86 same-page doublets. This investigation addresses the missing causal discriminant: **can the phase-zero table mask, or even an independent random doublet generator with an independently fitted slip rate for each original chapter/page, produce the observed order of gaps?**

The answer for the specified independent-position mechanism is **no**. A subsequent predictive holdout on two independently source-defined one-bit clocks also recovers no useful repeat-event selector; the exact restrictions and heldout performance are documented below. The surprising part is that the gap serial structure persists even after retaining *every physical page's* observed p50-mask and nonmask event counts.

## Source evidence and measured nulls

Use the canonical 12,956 encrypted GP29 runes on 55 rune-bearing pages p0–55 (number-only physical p50 carries zero runes). Each within-printed-page adjacent rune pair is one opportunity, with the global phase of its **first** rune modulo 256. There are exactly 12,901 opportunities and 86 equal-rune events. Table entries whose literal first printed numeral is `0` occupy 60 of the 256 table cells, matching 3,025 eligible opportunities and **33** events; the other 9,876 opportunities carry **53** events. The 86 observed event coordinates give Pearson autocorrelation between consecutive *event gaps* of **+0.38001968924100965**. This exactly reproduces the independent [Round44 B3 external T7 observation](https://github.com/Dukotah/cicada3301/blob/master/liber-primus/analysis/round44/W2-B3-doublet-sites/RESULTS.md) on the canonical input.

Test each independent-position mechanism by repeatedly drawing a uniformly random subset of exactly the *observed* number of events from every eligible category. The sampling conditions on source morphology and observed count per category, so it **removes any apparent statistical discovery from fitting the rates**. For a test of order dependence, compute the same original Pearson consecutive-gap autocorrelation on the sorted sampled positions. Use one-sided empirical upper tails (add one to successes and sample count); these are conditional permutation probabilities, **not** a discovery-wide p-value for the full LP2 investigation. Every test is fully enumerated in the source code and is reproducible with deterministic xorshift seeds.

**Original-typography sensitivity:** Instead of arbitrary 128-rune blocks, the last two tests locate event categories in the original-image-corrected transcription's punctuation (literal `.` and `&`) and line-wrap markers (literal `/`), while independently conditioning on the p50 digit-zero mask. The historical working transcription misclassified two original word dividers as sentence stops (see [source-correction Issue #1974](https://github.com/FlareZ123/liber-primus/issues/1974)). Repeating the exact punctuation test on the image-corrected input leaves **71 occupied bins, 140/16,000 exceedances and upper tail 0.008812** unchanged. The legacy two extra stops therefore had no effect on this conditional result. Punctuation-based segmentation still fails to account for the full event order (conditional upper tail **0.00881**); the exact **printed-line event-count** classification absorbs the residual (conditional upper tail **0.32348**). This does **not** establish a line-reset cipher. Indeed, fixing which of the 594 source line boundaries delimit actual event-bearing lines nearly specifies the original event coordinates, so the latter is a deliberately overconditioned, descriptive sensitivity check and cannot be used predictively without access to the unknown event locations. The result narrows the insufficient independent-class model to **coarse page and punctuation** scales; one line-specific rate per source line would have too many free parameters to constitute a key.

The 128/256 granularity comparison is **exploratory and target-informed**. The result does not prove an actual 128-rune reset. Conditioning on smaller intervals increasingly preserves realized local density and can mechanically absorb the original correlation. Nonetheless, it localizes the *unexplained* gap structure to a **subpage/multi-line scale** for any model of independent random site acceptance. The 9-chapter null is especially informative because every original chapter's accepted/rejected p50-class event totals are already held exact, yet the gap order remains extremely unusual. The 55-page exact-count null supports the narrower conclusion that **page-specific constant acceptance rates do not exhaust the observed temporal structure**.

## Independent frozen one-bit source clocks: original event-position holdout (#2138, Agent23, 22 November 2026)

The prior line/punctuation conditional nulls **used actual event counts for each source segment** and hence could not predict new event coordinates. This follow-up instead uses exactly two small, independently printed binary state definitions **before consulting repeat events in the holdout**: (A) parity of printed line number within a physical page, toggled on each literal `/` original wrap and reset on each original `%` page boundary; and (B) parity of literal full-stop/chapter marks `.` and `&`, toggled at each mark and reset at physical page boundary. Each is combined with the exact source p50 first-numeral-digit-zero mask, leaving four discrete eligibility classes. These are the only second-state definitions tested; no fitted phase, extra period, line-specific event-count parameters or event-dependent reset is allowed.

The first five original chapter groups **p0–p26** supply training event rates on **6,500 eligible neighboring positions**, including **40 observed equal-rune events**. The last four complete chapter groups **p27–p55** supply an untouched evaluation of **6,401 positions and 46 actual events** (rune-free p50 omitted). A mask-only two-rate model is the baseline. Each train-derived class hazard is fixed by Jeffreys smoothing `(events+0.5)/(sites+1)`. Every heldout original position receives a probability before seeing its repeat label. The predicted number K is the nearest integer to the total expected heldout events; the exact K most probable positions are frozen with a deterministic coordinate-only tie breaker.

| Predefined model | Heldout log likelihood (higher is better) | Expected events from training | Predicted top-K sites | Correct original event sites in top K |
| --- | ---: | ---: | ---: | ---: |
| P50 zero-mask only | −271.226879 | 40.350 | 40 | 1 of 46 |
| P50 mask + within-page physical line parity | −270.877663 | 41.416 | 41 | **1 of 46** |
| P50 mask + within-page punctuation parity | −275.378966 | 41.540 | 42 | **0 of 46** |

The line-clock improves 6,401-site log likelihood by only **+0.349216** relative to the source-mask-only baseline while adding **zero** original event-position hits to its top-K prediction. Punctuation-clock log likelihood is **−4.152087** worse and captures no event. Chance-level top-K hit expectations conditional on the 46 actual events are approximately 0.29–0.30; therefore the one captured location by the baseline/line models is not compelling evidence of a cipher. Most actual original equal-adjacent sites remain completely unpredicted.

**Decision and exact scope:** Neither of the two source-frozen 1-bit clocks supplies a transferable site-selector for the observed 86 doublets, and hence neither passes the prerequisite for building a claimed full-paragraph decryptor. This does **not** disprove all line-dependent encryption, sentence-state machines or an externally keyed stream; it closes the two explicit bounded clock consumers without retuning or adding a second layer after viewing holdout labels. The inability of the best line model to predict events is especially important given the prior **overconditioned** within-line randomization that appeared to absorb the gap autocorrelation: actual line-specific event counts did the work, not a known predictive line opcode.

## Orthogonal consequence for the inverse design

If the leading digit zero merely controls the probability of allowing an otherwise forbidden immediate repeated rune, **nonzero modular differences** between consecutive ciphertext runes should retain approximately the same distribution inside and outside the mask. Against that prediction, count all 28 nonzero residues of `(C[i+1]−C[i]) mod29` by the two printed table-mask classes. With 12,815 nonzero pairs, the ordinary 2×28 Pearson independence statistic is **χ²=23.898458745108506**, **df=27**, asymptotic **p=0.63594255**. Thus the observed nonzero-difference distribution provides **no evidence against** a zero-step-specific mask effect. This is a separate descriptive compatibility check and does not prove rejection filtering. The previously reported source mask has 2.033 times the other mask's immediate-equality rate (33/3,025 versus 53/9,876); the fact that the other 28 differences remain similarly distributed makes a zero-specific effect more plausible than an arbitrary per-letter transform.

## Implication for actual plaintext recovery

A decoder determined solely by the p50 digit-zero mask and a fixed independent skip-acceptance probability per class or even per physical page is **insufficient to explain these original order-sensitive residuals**. Pursuing yet more secret substitutions for that stationary model has weak prospects. If the p50 association is causal, it needs **some additional source-selected cause for local event placement**, potentially an evolving state, printed-line-dependent behavior or a different mechanism; the first mask correlation itself could also be accidental. Neither a **one-time pad** nor a more general complex generator is excluded. The original signed messages do not identify any such second state rule. The priority experiment for future agents is to find a **visible historical/page-layout cue**, stronger than the two failed printed-line/punctuation parity bits, that predicts state transitions **before looking at remaining ciphertext** and then test whether it produces unknown plaintext with an explicit inverse.
