# Rank-one triangular perturbation: invariant and source boundary (#3166)

**Decision:** no independently selected distinct wrapper/function; no new original search. The fixed case is a strict subset of the already tested fixed pair bijections. A genuinely changing public wrapper could escape that result, but must be supplied by original source evidence.

## Mathematical reduction

Let x be a GP29 plaintext pair and define S_f(u,v)=(u,v+f(u)) for any fixed f:GF29→GF29, with inverse S_f^-1(u,v)=(u,v−f(u)). For invertible L,M and fixed b, E(x)=L S_f(Mx)+b is a bijection on the 841 ordered pairs, irrespective of whether f is quadratic, cubing, a prime lookup or nonlinear in some other way. The inverse is M^-1 S_f^-1(L^-1(c−b)). This includes a rank-one perturbation of a linear map, L Mx+L e2 f(e1^T Mx)+b.

No fixed coordinate order, hidden linear wrapper or f selection escapes the complete fixed-digraph pair-frequency/collision invariants. In particular #3147 already grants independent arbitrary fixed 841-way maps in each authentic visual chapter and compares every same-length contiguous native donor window, not only fixed sum-preserving maps. Its exact original distinct-pair counts exceed the largest eligible native counts in every chapter; its original collision counts fall below the smallest native counts in every chapter. See [existing complete evidence](lp2-chapter-pair-sum-fiber-gate.md), [global/page/line/word variants](lp2-fixed-digraph-bijection-gate.md) and [page-private all-key gate](lp2-gp29-digraph-permutation-allkey-original-gate.md). Repeating this with a particular f would be weaker.

There is a second, function-independent fiber invariant. Let alpha=e1^T M and lambda=e1^T L^-1. Both are nonzero, and for every known pair (x,c),

    lambda c − alpha x = lambda b.

Subtract any known pair from each other. The rows [c_i−c_0, −(x_i−x_0)] must have a common nonzero 4-component null vector (lambda,alpha), each two-component part nonzero. Rank4 is an exact impossibility for every f and every pair of linear wrappers. Rank3 identifies the invariant up to common scale; rank≤2 leaves a family. Once an independent fiber and coordinate basis are fixed, the second coordinate supplies exact constraints on f, and repeated first-coordinate values must yield identical residual f(u). Neither rank3 nor a repeatable f is alone proof of an authentic key or uniqueness.

For a genuinely different publicly clocked conjugacy E_i=G_i E G_i^-1, invert the **known** G_i on both x_i and c_i, then apply that same rank test and normalized repeated-pair equality. More generally E_i=U_i E V_i with known invertible U_i,V_i normalizes to E(V_i x_i)=U_i^-1 c_i. If either public wrapper is unselected, the reduction is not an executable original decoder. Allowing a fresh arbitrary private G_i per pair would add state capacity, not constrain plaintext. It would not be covered by the fixed-digraph exclusion; do not conflate the two.

## Source decision

The signed GP chart supplies rune/prime labels, historical DH supplies modular operations with explicitly typed integer operands, and p56 establishes an authentic prime-totient scalar schedule with F transparency. None of these supplies an original instruction choosing a pair order, f in the triangular shear, or a **known changing 2×2 wrapper**. The p28 local H arithmetic remains conditional and has no independently validated continuous receiver. #3161's actual GP shift/Atbash conjugacy reduction concerns affine seed maps and provides no independent nonlinear pair clock. The previously tested all-secret two-quadratic triangular receiver is stronger than a selected fixed quadratic ([existing gate](lp2-p16-p40-quadratic-pair-allsecret-secondcoordinate-gate.md)); no new degree or polynomial sweep is warranted.

No original unknown plaintext, key, or new source edge recovered. Reopen only on a literal pair-register instruction and an independently selected nonconstant wrapper/function. Then the normalized rank constraint is a cheap exact key-elimination step before blind inverse or untouched original prediction. This note is a derivation and decision, not a new experiment.
