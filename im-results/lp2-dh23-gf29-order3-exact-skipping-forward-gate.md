# A DH23-derived GF(29) order-3 keystream with exact collision-skip inverse

## The one frozen hypothesis

The historical Cicada DH23 worked example provides the numbers **23**, **5**, and **6**, in the roles modulus, base and server secret exponent. Their original purpose is Diffie–Hellman illustration. There is **no first-party instruction** to use them as GF(29) recurrence taps, so the following is a limited exploratory use, not an authenticated puzzle decipherment.

Let `K_i` be a 29-symbol key generated by

```text
K[i+3] = (23*K[i+2] + 5*K[i+1] + 6*K[i]) mod 29
C[i] = (P[i] + sign*K[t]) mod 29
```

The three initial key symbols are entirely unknown, uniformly ranging over all **29³ = 24,389** states. The recurrence is uninterrupted over all original **12,956** unknown GP29 runes on physical pages p0–p55. Original word, clause and page separators remain outside the key clock.

The anti-doublet possibility is explicitly granted: if a tentative emitted glyph equals the immediately preceding ciphertext glyph, reject it with probability **0.81**, consume one more key symbol, and retry **the identical plaintext glyph**. This may advance the hidden recurrence by variable amounts, so the negative for uninterrupted order-3 keys does not by itself cover the model.

## Exact hidden-state inverse

The SFT implements a normalized forward algorithm over every one of the 24,389 unknown consecutive-three-key-symbol states. At each emitted glyph, it sums all possible local key-consumption paths, including arbitrary runs of consecutive would-be collisions. For these frozen taps every nonzero state yields at most three equal successive tentative key values, and the all-zero absorbing state has an **exact geometric sum** over an unlimited rejection run. Thus no artificial drift cap, guessed initial seed, or beam pruning is used.

Emission likelihood is the independently trained 29-grapheme Shakespeare unigram, with unit pseudocounts. The null is a flat, source-independent GP29 stream conditioned on the **same 0.81 collision-rejection rate**, rather than an ordinary iid 29-symbol stream. Both additive signs are tested: their exactly equal likelihoods follow from the bijection `K -> -K` when every seed is included, so they are mathematically **one** hypothesis.

## Research decision

Do **not** pursue DH worked-example `[23,5,6]` as third-order additive GP29 key with this collision-driven pad-consumption model. The strongly negative original likelihood, coupled with two positive plants and complete unknown-state marginalization, is sufficient to retire this exact branch.

The evidence does not address a different recurrence, an LP2-authenticated independent seed, nonlinear state updates, a non-GP29 cipher, different output conventions, or a different plaintext language.
