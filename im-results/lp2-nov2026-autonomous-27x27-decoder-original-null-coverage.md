# November 2026 external 27×27 autonomous decoder: source replay, null controls and ciphertext coverage

**Classification: conditional reproducible English path, unverified plaintext recovery.** The November 2026 publicly released 27×27 C++ decoder reproduces its claimed 39-block English reading from the exact original LP2 p0–p2 GP29 matrix with no plaintext provided on the command line. An independently implemented replay checks each of the 118 reported rune subtractions against the canonical source corpus. The proposed path remains underdetermined as an author-intended solution: its transition grammar was developed after the candidate wording was known, it has no independently supplied 39-step selector, and it does not decrypt all the ciphertext in those pages.

## What the program actually recovers

The original run reports **87,115 admissible openings with dictionary words** and a best-ranked **39-block, 118-GP-rune** reading (score −117.143145), beginning `AS I GO THE` and later proposing directions to the east of a map. The trace lists for each block a 3-rune node, a key triple, selected ciphertext coordinates and decoded runes. Independently rereading the canonical p0–p2 original corpus confirms **118/118 exact `(cipher−key) mod29` rune equations**, a concrete reversible mapping. For 28 of 39 blocks, the reported key follows the forward-order center-totient and Möbius/totient phase construction. Ten blocks use the unchanged center rune in the forward order. **Block36, “DO,” requires reversing the outer node ordering**; applying the forward-order construction alone does not yield its reported key. These are executable choices that an independently authored operation must select without inspecting English output.

The path has **118 ciphertext-cell uses across 106 distinct source positions**, so 12 uses revisit earlier ciphertext. The 39 key-source nodes have **97 distinct positions**, of which 21 overlap the 106 ciphertext positions. Thus only **182 distinct positions of the 729-rune original matrix are accessed at all (24.97%)**, and **623 original ciphertext positions are never decrypted**. The output is a proposed message along a sparse route through p0–p2; it is not a full plaintext of these three pages. The [self-contained trace verifier](../sims/agent11_2026_autonomous_decoder_trace_sft.cjs) checks every original subtraction, key mode, reversal, canonical source symbol, and count, with hashes of the ordered ciphertext and node coordinate lists.

## 160 token-inventory-preserving controls

The same binary, dictionary and decoding rules were executed without re-tuning on four separately seeded source permutations, all retaining exactly the **same 729 GP rune symbols**:

| Control family | Cases | Finished-search depth range | Cases reaching the default depth-128 ceiling without termination |
| --- | ---: | --- | ---: |
| Whole-matrix 729-cell shuffle | 64 | 11–21 (62 cases) | 2 |
| Row-order permutation | 32 | 12–26 | 0 |
| Independent cyclic shift of each row | 32 | 13–21 | 0 |
| Column-order permutation | 32 | 13–22 (31 cases) | 1 |
| **Total** | **160** | **157 terminate at depth ≤26** | **3** |

The actual original matrix terminates at depth **39**. All 157 normally terminating controls fall below this depth. The other three reach the program's default **depth128 limit with active branches still open** and exit status4, so their longer routes are censored, with no comparable final ranked English text. Treating those as successful meaningful 128-block readings would be incorrect; treating them as failures shorter than39 would also be incorrect. Because the word map, constraints and geometric rules were discovered on the original candidate path, these controls test the **frozen implementation's source selectivity**, not the chance that a solver would have independently discovered that implementation. The [fixed-seed SFT](../sims/agent11_2026_autonomous_decoder_null_sft.cjs) prints seeds, individual depths, censored statuses and family histograms.

## Unseen original page-start transfer on the rest of LP2

To test whether the fixed grammar is a **reusable decryptor** rather than a one-chapter word route, the same unmodified C++ decoder and bundled dictionary were executed on **every physically new, rune-bearing p1–p55 page start from which 729 original runes remain**. Each 27×27 matrix takes that page's first rune and the next 728 original runes, crossing page boundaries without choosing a favorable ending. Of **52 total starts**, p0 is the original 39-block/118-rune positive reference and **51** are previously unseen page-start receivers. The p50 non-rune table provides no start; no plaintext, keys, scoring threshold or rules are changed.

Of the **51 unseen windows**, **50 terminate with 12–26 blocks**, with no coherent multi-sentence English. Representative physically important p3 starts produce a 21-block word salad; p7 yields the highest normal depth26, also word salad. The exceptional **p30** window reaches the decoder's **128-block ceiling with status4** by repeating the token `FTH` until a terminal fragment; its reported score is **−1126.649168**, dramatically below original **−117.143145**. The 128-block event is a looping/overpermissive lexical search artifact, rather than extended meaningful recovery. **Zero of 51** unseen page-start receivers replicate a comparably coherent route, and zero completed receivers reach the original 39-block depth. This gives a meaningful transfer failure for the frozen algorithm. Only the p0–p2 729-runic unit is independently motivated by one complete three-page visual section and the exact 27² count, so failure on adjoined 729-rune windows does **not** rule out a chapter-specific 27×27 mechanism. [Complete original page-start transfer run](https://github.com/FlareZ123/liber-primus/actions/runs/44952319694) · [bounded transfer SFT](../sims/agent11_2026_autonomous_decoder_page_start_transfer_sft.cjs).

A different first-party-motivated continuation test asks if **the alleged plaintext itself supplies the next-page key**, following Cicada's documented solved-phrase Vigenère use. From the trace extract either the complete **118 recovered native GP runes**, or the exact internal direction sentence **`THECEYISTOGOTOTHEEASTOFTHEMAP`** (25 GP signs, normalized as `THE KEY IS TO GO TO THE EAST OF THE MAP`). Cycle each over the unchanged original **p3 217-rune** ciphertext with phase0 and both signs of ordinary GP29 addition/subtraction. All **four** direct receivers are nonprose (whole-p3 GP29 IoC approximately **0.03422–0.03755**), even though each verifies reversible source re-encoding. This excludes the immediate historically documented phrase-key Vigenère handoff while leaving open source-authored navigation to another position. ## Candidate literal-map AES-256 receiver

If the decoder's **unverified** sentence “THE KEY IS TO GO TO THE EAST OF THE MAP” is taken literally, p50 supplies an actual 32×8 byte-interpreted printed numerical map. Its physical **eastmost (rightmost) column is exactly 32 bytes**, suitable as one AES-256 key, and the remaining seven columns are **224 bytes, exactly 14 AES blocks**. This independently existing source geometry motivates one sharply bounded byte-domain receiver rather than treating the direction as a GP29 Caesar shift. On the original-image-adjudicated **base60-derived** bytes, the east-column key is `b7d45785054c50336c524123ce73b8c1ab98bdf8f81251212f155497afadc050`. Decrypt the other seven columns with AES-256 in either original row-major order or column-major order, using ECB or CBC with all-zero IV: all four unpadded outputs have ASCII-printable fractions **0.340–0.371** (English plaintext would be overwhelmingly printable), and none is interpretable text. Every mechanism passes a planted source-length English AES encrypt/decrypt control. No IV, AES mode or instruction to treat p50 as encrypted bytes is supplied by the author. The table's original **base59/base60 interpretation ambiguity** also remains; the result rejects only these four direct source-bounded AES-256 consumers. [Exact p50 east32 AES-256 gate SFT](../sims/lp2_p50_eastmost_aes256_original_gate_sft.cjs).

## Decision for the research frontier

This candidate has stronger exact original-input substantiation than a hand-written word-crib transcript: the executable starts from the canonical matrix and its 118 rune equations independently replay. Its origin and completeness remain unresolved. Existing [temporal holdout](lp2-p0-reports07-19-temporal-holdout-audit.md) and [post-THEN selector](lp2-p0-current-postthen-selector-audit.md) audits show that the growing 27×27 transition grammar fails to choose unseen next words uniquely before language filtering; the new executable does not eliminate that limitation. The 51 previously unseen original-page 729-rune receivers now show **no comparable plaintext transfer** under the pinned autonomous decoder; a direct full-route or direction-phrase Vigenère transfer to physical p3 is also negative. The immediate decisive advance would be a **first-party instruction that uniquely selects a new, previously unexposed original node and ciphertext segment**, with predicted output, or a portable operation that decrypts a substantial untouched part of the manuscript. Do not treat a 39-block route across 106 distinct cells as a fully deciphered 729-cell chapter.
