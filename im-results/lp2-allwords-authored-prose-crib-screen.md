# Complete LP2 original-word-length crib comparison against selected prose sources

**Current status:** original-cipher source-text screen with complete word-length parsing and two positive controls. No plaintext from any unsolved LP2 page and no authentic key recovered. Beyond the prior Blake, Crowley, Shakespeare and other source-text screens, the newly tested source is William Gibson's complete *Agrippa*, which **Cicada itself used for its authenticated 2012 book code**. This is a historically selected crib source, not a free literature search. The source's copyrighted poem remains an external input rather than being committed here. The 2013 *Book of the Law* source already had its own original LP2 search; this page points to that prior independent result rather than crediting it as new.

## Recoverable plaintext-crib premise

All **2,896** continuous original LP2 words retain printed delimiters across **12,956** runes (physical pp0–55, with p50's purely numerical grid excluded). If Cicada reused a long passage from an independently known book and preserved its word boundaries, its plaintext word-length sequence would be identifiable *before* deciphering the rune identities. Such a passage could supply an actual known-plaintext crib for recovering cipher state or a key. The original scanner interprets all line/page wraps as continuous within-word text while honoring dots, dashes and paragraph separators.

There are two frozen candidate plaintext registers: raw ordered A–Z word lengths, and conventional greedy GP-runic lengths (trigraph `ING` before `NG`, then `TH NG EO OE AE IA EA` as single glyphs). Seven-word exact signatures are used as search seeds, and every hit is extended maximally left and right over the entire physical LP2 unknown stream. This yields the exact longest source-aligned passage, without a fitted cipher, reorderings or changes to manuscript separators.

Blake is historically motivated: the 2012 Cicada puzzle itself used *The Marriage of Heaven and Hell*. The current full-work search extends the earlier illustrated excerpt tests, which considered selected lines from Blake's *Laocoön* and portions of Daniel 4 ([preexisting source-specific report](lp2-daniel4-blake-tree-source-crib.md)). The entire 4,609-word *Marriage* offers **no contiguous nine-word exact match** with the original unknown LP2 word-length sequence under either orthography. The strongest eight-word GP match begins at physical **p46 / original LP2 word2516**, aligning to the candidate-source phrase “BUT WHEN HE HAS DONE THIS LET HIM”. It is a short length coincidence, **not recovered plaintext**.

The newly checked **2012 Agrippa edition** is pinned to Git blob `a4e13bdcbfa64be9c087e092b51f028126f51cb3` from [trizen's preserved 2013 solution script](https://github.com/trizen/experimental-projects/blob/master/cicada-3301/book-code.py), whose first `book = """..."""` assignment contains precisely the 1,682 GP-normalizable word tokens. This is an actual original-Cicada book-code source. Original LP2 has 2,896 printed words crossing 32 physical-page boundaries, which are joined in the test. Latin-token lengths match **at most 7 consecutive original words** (LP2 physical p15 / original word797, source word99), and greedy GP29 rune contractions match **at most 8** (LP2 physical p47 / original word2583, source word773). **Zero matches of nine or more words** occur in either frozen register, and a planted **16-word** Agrippa passage at LP2 word1000 is recovered by the same exact seven-word seed and maximal-extension scanner. This rules against a long, untouched, exactly segmented *Agrippa* quotation serving as directly recoverable LP2 plaintext; it does not rule out altered verse, other editions or *Agrippa* used as key material. The complete copyrighted text is neither reproduced nor stored. To repeat, obtain the linked pinned historical script separately and pass its local path to `node sims/lp2_2012_agrippa_wordlength_crib_sft.cjs <path-to-book-code.py>`. The SFT authenticates the source Git blob before matching.

The **second original Cicada 2012 book-code source**, the public-domain 1911 *Encyclopaedia Britannica* 11th edition, volume 6 slice 3, was screened from the very edition archived with the actual 2012 decoder: [archived source `31447.txt`](https://github.com/neuroretransmit/cicada/blob/ade9a02889ef8acbc8cde8edbfd0a785c369f4c3/2012/006-two-book-codes/books/31447.txt), pinned Git blob `8cba4356812ff852e3fe9c88e80ab1e9b5b8670c`. The historical 2012 book-code begins at the `CICADA (_Cicadidae_)` heading, zero-based source line **15,388**. From that visible point to the end are **34,487** Latin tokens, with maximal original LP2 length matches **8 Latin / 8 GP29 words**, zero nine-word matches. For the larger, independently frozen **whole 186,810-token source file**, 3 original Latin and 1 GP-rune length matches reach **nine** words, but **zero reach ten**; the longest cases are short generic prose and are *not* identified plaintext. The latter whole-book test is a deliberately broader control, distinct from the historically selected CICADA-entry interval. Each of four source/register combinations successfully retrieves a **planted 16-word** original-layout passage. Exact source blob verification, two complete word-segmentation modes, ≥7-word seeds and exhaustive maximal extension are implemented in [the isolated SFT](../sims/lp2_2012_britannica_wordlength_crib_sft.cjs); run it on the separately obtained original file. These findings exclude only exact word-preserving quotations under the tested source registers, preserving other key and rewriting possibilities.

For context, Cicada's 2013 use of Crowley's *Liber AL vel Legis* already motivated a separate complete-original test: the actual 2013 preserved chapter-I text has **no eight-word hit**, and the alternate complete three-chapter transcription has a longest match of **eight** words in both registers. That conclusion, including a planted sixteen-word passage, is recorded in the [earlier original-input Liber AL gate](lp2-2013-liber-al-wordlength-original-crib-gate.md) and should not be interpreted as fresh recovery here. The individual chapter-II/III slices in `resources/external/` also produced at most eight-word matches on an exploratory whole-book check, consistent with the existing complete-book limit. This comparison does not depend on directly using *Liber AL* as a Vigenère running key, which was separately rejected in the [complete-key test](book-of-law-running-key-gate.md).

## Positive controls, falsifiability and next decision

The [original broad-source reproducer](../sims/lp2_allwords_reference_length_crib_sft.cjs) exactly finds a planted **16-word Shakespeare** word-length excerpt inserted at original LP2 word1000 ([manual CI run 42973182756](https://github.com/FlareZ123/liber-primus/actions/runs/42973182756)). The [new full-Blake reproducer](../sims/lp2_historical_book_length_crib_sft.cjs) likewise asserts its exact source-word count (4,609), verifies the original **2,896 words / 12,956 runes**, checks longest-match maxima **7/8**, and recovers a planted **16-word Blake GP29** passage from source word500 at original word1000. Its source is `resources/external/blake-marriage-1906-gutenberg45315.txt`, already pinned in the repository.

**Decision:** An uninterrupted, normally GP-spelled quotation from the complete Cicada-linked Blake book, the historically used Gibson *Agrippa*, or the 2012 *Britannica* source is absent at the minimum length needed for a useful plaintext crib. Do not treat isolated seven- or eight-word length matches as quoted plaintext. A new source-text attack should be commissioned only when the original page or a signed cross-round clue actually identifies the source and an alternative transformation that predicts rune-level plaintext; searching increasingly broad literature without a selector offers little decryption leverage.
