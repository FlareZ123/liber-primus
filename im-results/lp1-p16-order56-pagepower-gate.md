# LP1 p16 3301 square: order-56 page-indexed Hill gate

## Finding

The LP1 p16 5×5 3301 magic square, reduced modulo 29, has determinant 10 and exact matrix order **56**. That order equals the number of LP2 pages (p0–p55). This is a genuine structural coincidence worth preserving, but it does not itself specify a decipherment.

A direct, human-motivated consumer was tested: use the non-runic numeric p50 page as the identity anchor, and apply a page-indexed Hill key
`M^(s(p−50))`, with `s ∈ {−1,+1}`, to each page's 5-rune blocks. Both M and M-transpose orientations were tested. Every page was padded locally with rune index 0 (F) to a multiple of five, transformed, then truncated back to its original rune count.

**Result: negative.** All four outputs remain ciphertext-like. Their pooled indices of coincidence are 0.03445–0.03448, versus 0.06271 for the clear p57 comparison page. No plaintext is recovered.

## Source object and derivation

The matrix is the first 5×5 square in `resources/cicada2014-openpuff-magic-squares.txt`, the 2014 Stage 10 3301 square:

```
434 1311 312 278 966
204  812 934 280 1071
626  620 809 620 626
1071 280 934 812 204
966  278 312 1311 434
```

Reducing entries modulo 29 gives:

```
28  6 22 17  9
 1  0  6 19 27
17 11 26 11 17
27 19  6  0  1
 9 17 22  6 28
```

The matrix is invertible over GF(29), with determinant 10. Repeated multiplication returns the identity first at exponent 56. LP2 contains exactly 56 pages p0–p55, and p50 is the empty-rune page carrying the numeric table. These facts motivate, but do not prove, the p50 identity anchor.

## Interpretation and limits

This rejects the specific page-indexed Hill construction above. It does not reject other uses of the square, other page anchors, other encodings of page state, or non-Hill mechanisms. In particular, the exact order-56 relation remains an unexplained structural fact, not evidence that the author intended this matrix-power schedule.

The test uses a page-local F=0 padding convention because page lengths are not all multiples of five. That convention is not independently specified by the source; therefore the negative result is bounded to this natural, explicit implementation. The test is not a search over arbitrary padding, phases, or matrix modifications.

## Reproduction

Run from the repository root:

```sh
node sims/lp1_p16_order56_pagepower_sft.cjs
```

The script parses the source square and LP2 corpus directly, asserts the 3301 row/column sums, determinant, order 56, 56-page count, 12,956-rune count, and empty p50 anchor, then emits the full page-level results. The earlier direct-matrix tests are documented in [the Stage 10 source-inverse gate](lp1-stage10-fivesquare-lp2-source-inverse-gate.md) and [the 2014 five-square Hill source-inverse report](lp2-firstchapter-2014-fivesquare-hill-source-inverse.md).
