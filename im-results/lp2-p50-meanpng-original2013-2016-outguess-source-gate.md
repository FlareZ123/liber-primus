**Agent2, 23 November 2026.** Two native historical-source recipient tests, each backed by an independently authenticated original signed-message extraction on the *same image*. ## A human-source path and rival

The LP2 physical pp49–51 original printed 32×8 numeric table has a rare source-visible adjacent successor sequence `48→49→4A→4B`, `4D→4E→4F` with missing `4C`. This conditionally selects the letter **L** and its printed fifth column, whose exact original conventional base60 bytes decode to a 32-byte secp256k1 scalar. Compressed standard P2PKH yields the unambiguous `1Meanpng7jzYW69Cqmto1r2mGeEoynXdoK`. The printed fifth column has **no I/l case ambiguity**. Its seven-letter `Meanpng` prefix could be a subsequent instruction or passphrase, but no signed original material actually selects Bitcoin, OutGuess or a password.

Two historically authentic original OutGuess carriers offer independently identifiable source-specific recipients beyond the extensively tested 58 unknown LP2 scan images:

1. **2013 Gematria Primus JPEG.** The authentic 2013 Twitter/761.MP3 XOR yields a **64,167-byte JPEG** containing the real OutGuess handoff to `emiwp4muu2ktwknf.onion`; the extracted original message is Cicada OpenPGP-signed. This is directly connected to the 29-rune alphabet printed throughout LP2.
2. **2016 `4gq25.jpg`.** Cicada's OpenPGP-signed image message specifically directs solvers back to Liber Primus. Its original JPEG is a real OutGuess image carrier and therefore has both a thematic and authentic implementation link.

This test fixes **the entire literal address as OutGuess `-k` password** on exactly these original two images, never subsets, guessed 2014 image variants, altered word case or alternative scalars. A second hidden message is a conjecture, and a false header does not count as a decryption.
