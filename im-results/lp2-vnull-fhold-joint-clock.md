# Joint collision-null and literal-F clock: exact original-input inverse

## Decision

The direct ordinary-consuming V-NULL page-reset prime-minus-one receiver gives no coherent original candidate. More importantly, a distinct exact inverse now combines the externally proposed V-NULL collision-retry/null mechanism with Cicada's authentic nonconsuming plaintext-F convention. It rejects 105/110 original page-reset prime-key/sign configurations on exact event feasibility alone; the five survivors have strongly negative language Bayes factors. A spacing-free F-free-interval gate excludes every q1–13 key on the black-only original p7 interval under the pinned finite contiguous reference-donor model, including page-private or chapter-private keys and separate red rubric treatment. q8/q13 are independently excluded on black p8 and p54. The hybrid is exploratory and not an established LP2 mechanism. No unknown plaintext or key is recovered.

The prior ordinary V-NULL receiver in [the event-DAG report](lp2-vnull-exact-event-dag.md) assumes that every ciphertext glyph advances the key. That assumption is false for the historically authenticated plaintext-F holds. This instrument eliminates the need to guess the two types of exceptional event.

## Exact sender and inverse

Use the native GP29 ordinal alphabet, with F=0. The underlying key is a known sequence K. At ciphertext position i and consuming-key position j:
- Plaintext F emits 0 directly, without consuming K or undergoing collision rejection.
- Every nonzero plaintext p proposes c=(p+K[j]) mod29, consuming one key digit.
- If c equals the preceding ciphertext rune, reject with probability s=1-.664/3.448 and emit one uniformly chosen nonrepeat null, retaining the same p for the next proposal. Otherwise emit c and advance plaintext.

For each state (i,j), an authentic F edge exists exactly if C[i]=0. A consuming genuine edge has p=C[i]-K[j] mod29 and is allowed only for p!=0. A null chain forces p=C[i-1]-K[j] mod29 !=0 and must emit different ciphertext; every subsequent proposal either equals the preceding ciphertext (another null) or equals the observed output (termination). These edges exhaust the fixed sender's possible events, including consecutive nulls. Their weights are exact log sender probabilities, with log(1-s) on an accepted doublet and log(s/28) per null. Each edge emits exactly one plaintext rune. It is not a deterministic bijection: the actual null choices are preserved in the recovered event witness.

The forward DP augments (i,j) with the last three emitted plaintext rune indices, summing all paths and retaining an independent exact MAP backpointer. A parallel uniform GP29 plaintext prior on the same event graph supplies an evidence denominator. The Bayes factor per ciphertext rune is (log Z_language-log Z_uniform)/n. The evidence is for observing the given finite output ending at an event boundary under indefinite generation; no known original plaintext length is assumed. The frozen interpolated 1–4-gram model trains on the first 70% of three existing literary sequences, with context prior masses 8,16,32. The returned event path is replayed against the original input. No printed word boundaries are required.

## Spacing-free all-key periodic inverse on F-free intervals

This closes a gap between the ordinary-consuming [all-key capacity proof](lp2-vnull-periodic-allkey-capacity.md) and the word-anchor hybrid tests above. The source of the idea is the authentic F-bypass convention: a ciphertext interval containing no F (index 0) cannot contain a literal plaintext-F hold. Even if the key clock is latent elsewhere, it advances at every position inside this interval, whether that position is a genuine emission or a null. No printed word or sentence boundaries are assumed. The previous ciphertext rune is known (F) at each selected interval's start; an arbitrary initial key phase is absorbed into the secret period vector. The underlying cyclic key need not be named or supplied.

Let C_i be ciphertext, x=K[i mod q], y=K[(i+1) mod q]. A genuine event requires p=C_i−x !=0. A null requires p=C_{i−1}−x !=0 and C_i != C_{i−1}; for an internal null, y−x must equal C_i−C_{i−1} (next event is a null) or C_{i+1}−C_{i−1} (next event is genuine), modulo 29. At the final interval position, a possible null is granted any continuation outside the interval. Thus each position has real/null options constrained by two neighboring key digits. For any nonzero top-rune set T and integer w in [0,100], a real event contributes 100 if p∈T and 0 otherwise; a null contributes w. Summing per-position maxima gives an upper bound on 100H+wd, with H the count of genuine plaintext symbols in T and d the number of nulls. Impossible real/null pairs receive −∞. Grouping the factors by key phase and conditioning on the first digit gives exact cyclic max-sum DP over every q-digit key, without enumerating 29^q keys. Set T empty and w=1 to obtain a rigorous upper bound D on d.

For stronger bounds, partition the interval into neighboring position pairs (offsets 0 and 1, with end singletons). If the first is a null, require the next event label to match the same pending plaintext. Each pair now depends on three successive key digits. Sum the two partition bounds and divide by two, which is safe because both partitions cover each position once. Condition on the first two key digits and use exact cyclic triplet max-sum DP. Remaining relaxation is across distinct pairs, not an assertion that the maximizing key admits a full event path.

If the genuine plaintext is a contiguous substring of a pinned reference donor, its F-free length L lies in [n−D,n]. For each allowed L, exhaust all F-free donor windows. Their affine floor f=min(100H−wL) implies the necessary inequality 100H+wd ≥ wn+f. A positive gap between this floor and the all-key maximum excludes the entire receiver under the finite reference envelope, independent of printed separators, key values and initial phase. For w=100, this is a rare-rune count comparison. T sets are top non-F GP symbols ranked on Shakespeare/Emerson; the choice of weights and sets is exploratory and the finite donor exclusion is deterministic, not a statistical generalization.

The q1–12 pair-factor capacity bounds on black-only p7 already give positive gaps; the narrowest gaps are +80 at q11 and +100 at q12, with T15/w88 and T19/w100 respectively. The q13 pair cap is insufficient (gap −300), so directly invert the finite donor family instead of selecting an additional language statistic.

For each F-free donor run and each possible starting rune admitting at least L_min=n−D genuine emissions, consider every legal real/null mask on the first q ciphertext positions (2^q masks before duplicate restrictions). The first q consuming events fix all q key digits: subtract the pending donor rune from either the current ciphertext (genuine) or previous ciphertext (null). Thereafter the key is fixed; the next donor rune produces either exactly the observed ciphertext (emit), exactly the predecessor with a distinct observed ciphertext (null), or an impossible value. This reduces all allowed donor lengths to one deterministic walk per donor start and initial mask. At every eligible emitted length, also grant an arbitrary pending nonzero rune for a trailing all-null suffix. The earliest successful length is sufficient to retain the associated key. Every retained key has a complete event-replay witness. No n-gram score, intact-word condition, printed separator, fixed phase, or preselected null count enters this exact search. ## Ciphertext-only key recovery without a donor: exact-score dual bounds

The finite-donor exclusion above does not address arbitrary newly authored prose. To address that limitation, a new blind receiver trains a nonzero GP bigram model on Shakespeare and Emerson; it receives only the ciphertext, period, and preceding ciphertext F. No donor text, group boundaries, key phase or null positions are supplied.

For a fixed periodic key, a Viterbi state contains the last emitted plaintext and the pending nonzero plaintext (if any). A genuine event emits the latter if pending, with language transition and collision acceptance weight; a null carries the pending value, with log(supp/28) insertion weight. An unknown preceding plaintext receives the largest conditional probability. The final pending null is permitted. Every chosen path is replayed. Pair factors upper-bound each event's log score by relaxing overlapping real/null label consistency and, after a null, using the best previous plaintext probability. Conditional cyclic max-sum suffix tables give an exact best-first enumeration of key vectors in decreasing relaxed bound order. The search may stop with a certified global optimum for the specified bigram objective when all remaining key bounds fall below its best feasible score. This is not a proof that a linguistically highest-scoring key is the real key.

On 12 deterministic, conditioned F-free plants with Gibran/native plaintext (169 genuine runes, q8/q13), 12/12 true keys rank first in the pair relaxation and are recovered by a 512-key budget. Five global optima are certified; two bigram MAP plaintexts are exact. A stronger relaxation introduces a multiplier λ_i at every interior shared ciphertext position, adding λ_i to the preceding pair's null decision and subtracting λ_i from the following pair's null decision. These terms cancel on every consistent actual path, so *every* multiplier vector gives a valid all-key upper bound. Exact cyclic max-sum yields both a maximizing key and local label subgradient; iterative subgradient steps tighten the bound. A 2,048-key best-first search with the best dual factors improves the feasible primal, and a replay-checked 4-gram MAP reranks the null decisions for the inferred key. No certificate for the 4-gram objective is implied.
