# 2012 MIDI 49-word list versus the 2014 7×7 square

**Classification: source-exact 49-to-49 register obstruction, plus a bounded historical instruction check.** Director Issue #159. No unknown LP2 plaintext, historical cipher key, or authenticated 2012-to-2014 handoff was found.

## Independent original inputs

1. The 2012 MIDI stage's decoded first track instructs participants to **encrypt, sign and email** the supplied 49-word list using their new PGP key and Cicada's public key. Its exact 292-byte list is preserved in `resources/historical/cicada2012-midi-49-words.txt`, copied without modification from independent archive [`neuroretransmit/cicada/2012/009-midi-puzzle/words.txt`](https://github.com/neuroretransmit/cicada/blob/main/2012/009-midi-puzzle/words.txt), Git blob `4351148626eaaed6854713b0c037fc3cdedff6f1`. **49 words, 47 distinct:** only `box` and `tray` repeat. The accompanying archival [original message and MIDI decode](https://github.com/neuroretransmit/cicada/blob/main/2012/009-midi-puzzle/README.md) contain no 2014 reference or 7×7 square instruction.
2. The 2014 OpenPuff [original three-square output](../resources/cicada2014-openpuff-magic-squares.txt) has a middle 7×7 square of exactly **49 cells**. Every row and column sums **1033**; its center is **331**. It has **only 24 distinct numeric values**, and all cells match under 180° rotation. The number 7 occurs four times, 22 values occur twice, and center331 occurs once. Original 2014 seventh-onion [HTML](../resources/cicada2014-onion7-index.html) selects 331 as its `div` ID and displays all 58 LP2 images; no text points to the 2012 MIDI wordlist. The 2014 OpenPuff square belongs to the historical 2014 pipeline rather than to the 2012 MIDI email submission.

## Exact discriminating test

Suppose the proposed 49-to-49 transfer is a literal aligned dictionary **numeric square cell value → one fixed word**, with no per-position secret. If the same numeric value appears in two square cells, it must select the same 2012 word at both positions. The original square's central symmetry makes **24 opposite pairs of cells numerically equal**. In the source's 49-word list, **all 24 opposite pairs have different words**. Therefore the literal lookup has no full solution in source order.

The [standalone original-source SFT](../sims/cicada2012_midi_onion7_valueword_gate.cjs) performs the stronger exact count: for each of the square's **eight D4 rotations/reflections**, group cells by their numeric value and retain the most frequent assigned original word per group. Every orientation requires changing **25 of 49** word assignments to satisfy *any* deterministic value→word dictionary. The count includes the four occurrences of value7. A constructed true dictionary assigning one synthetic word to each of the 24 values yields **zero** mismatches, and a one-word corruption yields exactly **one**. This validates the necessary-condition test without searching keys.

The shared number **49 = 7²** remains real and might still be a deliberately reused motif; the evidence does not independently select the 2012 list as a later cipher key. A purely position-indexed 49-entry key is mathematically possible, but the original 2012 instruction already assigns the words a different immediate purpose and no visible 2014 instruction restores them. Permuting, hashing or rekeying the list based only on the equality of lengths would introduce an unselected transformation.

## Decision

**Retire the direct 2012-list → 2014-square numeric-value dictionary route.** Under all eight natural visual orientations it fails the exact repeated-number consistency test on original source. Preserve the archived 49-word input for future independent clues, but do not commission arbitrary anagrams, reassignments, book indexes or GP29 additive pads. A viable successor must supply an original human-visible instruction selecting the list and specifying a unique position-dependent operation that yields a falsifiable LP2 plaintext prediction. The exact 2012 wordlist-to-2013 PARABLE mismatch has separately been closed in Issue #140; this test is specific to the **2014 7×7 repeated-value square**.
