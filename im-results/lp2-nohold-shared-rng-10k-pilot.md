# Ordinary-nohold shared-RNG 10k epoch pilot — negative decision

**Status:** the tested model/window is retired as a plaintext route. This is an intermediate exclusion, not a proof against other PRNG families or source-selected mechanisms.

## Question and frozen model

Test whether LP2 p0–55 can be generated by one CPython 3.4 MT19937 instance using:

1. one integer `randrange(29)` key draw per attempted rune, implemented by `getrandbits(5)` with rejection of values 29–31;
2. a `random()` 53-bit coin only when the first key draw would repeat the previous ciphertext rune;
3. a constant threshold (s), with coin < (s) rejecting the attempt and retrying the same plaintext rune, otherwise accepting the repeated ciphertext rune;
4. **no literal-F hold**: every plaintext symbol, including F, consumes the key draw;
5. one continuous raw-word cursor across all pages.

The bounded seed pilot was `[1398988800,1398998800)`, 10,000 consecutive epoch-second seeds beginning 2014-05-02 00:00 UTC. The threshold domain was `(.72,.882]`, represented exactly by integer (k=\lceil s2^{53}\rceil) in `[6485183463413515,7944349742681555]`. Neither the CPython 3.4 API nor this timestamp subwindow is selected by an LP2 source clue; this was a narrow exploratory pilot, not an authenticated key search.

## Input and reproducibility

- Canonical source: `resources/liber-primus/lp2-corpus.json`, blob SHA `054f2a0f780b7d46901acbe3d9bf4f0ac1801165`.
- Target: pages 0–55, 12,956 GP29 indices, 86 adjacent equalities, FNV-1a over indices `fe63c4ed`.
- Exact interval sieve: `sims/lp2_nohold_shared_rng_epoch_sieve.cpp`. It propagates raw MT-word cursor states and exact integer threshold intervals; it has no language prior and no arbitrary cursor/rejection cap.
- Controls: CPython integer-key vector `[13,17,9,14,24,8]`; 16 planted positive controls; 64 interval-versus-fixed-threshold checks; eight exhaustive three-rune oracle checks.
- C++ workflow run: [45565851103](https://github.com/FlareZ123/liber-primus/actions/runs/45565851103).
- Exact plaintext ranking: `sims/lp2_nohold_shared_rng_exact_plaintext_sft.cjs`; Node workflow run [45566906382](https://github.com/FlareZ123/liber-primus/actions/runs/45566906382).

## Plaintext ranking

The exact fixed-seed decoder uses a GP29 character trigram model trained only on the pinned Gibran and Emerson controls, with Shakespeare held out:

| Control | GP29 runes | Mean log probability (nats/rune) |
|---|---:|---:|
| Gibran training | 62,492 | -2.1888 |
| Emerson training | 321,327 | -2.2360 |
| Shakespeare held out | 217,106 | -2.4564 |

For all 13 candidate seeds, the decoder tested the midpoint of the feasible threshold interval. It also tested both endpoints for the four widest intervals: 21 exact candidate/threshold decodes in total. Every MAP path re-encrypts to the original ciphertext at its exact seed and threshold, but none resembles coherent prose. Their mean MAP scores range from -6.5184 to -6.4237 nats/rune, far below held-out English. The compatible path counts at midpoint thresholds range from approximately (10^{67.9}) to (10^{82.0}), so replay is massively non-identifying. A representative best-path prefix begins `CPTHOEFTEFXAEX...`.

This is a model-conditional rejection, not a theorem that no plaintext exists under any language or cipher. The English controls are relevant because the solved LP material is English, but an alternative plaintext language would require independent evidence.

## Decision

Retire this exact no-literal-F CPython 3.4 integer-conditional model over this 10,000-seed pilot window. Do **not** expand it to the full May 2–12 timestamp range, tune the threshold around the lower boundary, or add more language-model variants without a source-derived seed/API/threshold selector. Preserve the sieve and decoder as reproducible negative evidence. No unknown LP2 plaintext, key, or Cicada destination was recovered.

The earlier six-schedule pilot reported no full-book survivors for the other five API/schedule combinations; the committed C++ reproduction here covers the sole surviving integer-conditional schedule.
