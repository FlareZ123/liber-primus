# Conditional perfect-binary-tree traversal for the p3–p8 255/255 interface

The physically consecutive p3–p7 scroll section contains **255 complete printed words** (1,145 GP29 runes) and tree-illustrated p8 has **255 original ciphertext runes**. This matches the node count of an eight-level perfect binary tree, `2^8−1=255`, and prompts a distinct trial from the already documented direct word-sum, chained-digest and GF4/p50 receivers. It is **not** proof the drawn slender tree encodes 255 nodes: the illustration supplies no numbered nodes, exact binary topology, visit order or key operation.

**Frozen conditional experiment:** Assign the 255 source words to a 255-node heap using breadth-first, preorder, inorder or postorder traversal. Read a different traversal to choose the GP29 one-rune key for each original p8 symbol. Four readily executable word projections are the first rune, last rune, sum of its genuine GP prime values modulo29 and sum of GP ordinals modulo29. For each of 16 traversal pairs and four projections, test both GP29 additive signs, **128 complete reversible receivers**, no phases, no arbitrary alphabet, no learned secret. All original source words are parsed at real hyphen/period boundaries; the flattened register reproduces exactly the original p3–p7 1,145-rune source. Each decrypted candidate is reencrypted byte-for-byte in GP29; a separately planted solved-p57 native GP passage recovers all 255 runes.

**Result (original-input pure JS execution, 23 November 2026; Node22 standalone reproducer added, CI not run):** original p8 GP29 IoC **0.03427513**, solved p57 **0.06270997**. The best of 128 decodes, *postorder source → breadth-first receiver / last original word rune / positive GP29 key*, reaches only **0.03881427**, while the source-plausible predeclared breadth-first→inorder / first-rune / subtraction interpretation gives **0.03257681**. **Zero of 128 reaches IoC 0.055** or coherent contiguous prose. Merely reordering the ciphertext cannot change its symbol-frequency IoC at all. The best here therefore remains randomlike despite after-the-fact model selection.

This **rejects only** the tested canonical complete-tree permutations paired with these four direct additive word projections. It does not rule out a real authored tree cipher, a changing-state transformation, or a nonadditive tree hash. In fact the original artwork does not physically select a 255-node binary traversal: without that independent instruction, expanding to arbitrary topology or secret node labeling would merely fit a key. **No unknown original plaintext/key or authenticated decoder emerged.** To advance this lead, first obtain a 2014-visible instruction identifying the tree's nodes, traversal and exact word-to-rune operation, then predict an untouched original p9 receiver.
