# Signed 2016 EPIPHANY SEEKS p0 opening crib: exhaustive Ghostscript generator seed gate

**Agent22, 23 November 2026. Classification: a frozen, first-party-motivated plaintext-crib PRNG negative. No previously unknown Liber Primus plaintext, generator state or key was recovered.**

## Human-readable source route

The original physical LP2 p0 begins with **13 red runes separated visibly into 8+5 printed words** (original cipher indices `[15,8,18,3,6,19,27,0,15,26,18,21,5]`), followed by a conspicuous large red13-dot punctuation. The independently signed **2016** Cicada note says *“The path lies empty; epiphany seeks the devoted.”* This could nominate the **eight-plus-five** `EPIPHANY SEEKS` phrase as a candidate p0 title, with native GP29 indices `[18,13,10,13,8,24,9,26,15,18,18,5,15]`. This is **a proposed crib**, not decrypted text or proof that the later signed hint identifies the actual 2014 title.

All 58 original LP2 JPEGs carry an Artifex/Ghostscript ICC profile; their earlier LP1 counterparts do not. The historically era-plausible, precisely specified PostScript **Ghostscript 9.06 `rand`** Park–Miller state generator is `x[n+1]=16807x[n] mod(2^31−1)`. This gives a small enough exhaustive, one-mechanism test for whether a source-visible publishing tool and a signed phrase can jointly derive an unknown manuscript keystream. The ICC is a renderer clue, **not evidence Cicada chose that random generator for its cipher**. The parser verifies the original p0 corpus and the exact historical signed phrase on every repository run.

## Frozen original inverse

- Direct GP29 additive `C=P±K (mod29)`, each sign, 13 red glyphs.
- GP28 immediate-predecessor exclusion, which directly addresses the measured unusually low adjacent-equal ciphertext rate. Two complete 28-way neighbor rankings are *cyclic successor* and *absolute sorted rank excluding the previous glyph*, each with both signs and 12 consecutive positions p0 offsets 1–12; the first ciphertext rune initializes the prior-rune state.
- For all six source/model choices, each native generator output maps to `K = x mod q` or `K = floor(q*x/(2^31−1))` where `q=29` for direct or `28` for exclusion. No fitted seed, word reset, secret key, temperature, phrase phase or plaintext scoring. An arbitrary generator starting state already covers all possible **time offsets** because 16807 is a unit modulo the prime modulus. The input phrase contains no plaintext F, so a literal-F skip cannot affect this prefix.

For each of **12 tests**, invert the first observed native key to enumerate every consistent 31-bit state: 74,051,160 or 74,051,161 candidate states for each GP29 model, and 76,695,844 or 76,695,845 for each GP28 model. Check the following generator states exactly, not by sampling. In every model the **longest matching original prefix was six** generator outputs. No model matched even eight outputs; **zero** supplied all 12 or 13 required outputs, which also excludes an exact full-page output under those frozen model definitions.

The exact positive, a separate synthetic 13-step series generated by `rand` with a secret initial emitted state `3301`, was recovered by the same exhaustive algorithm, **uniquely** at all 13 positions. This checks the state inversion, generator stepping and native modulo projection. The output of the original test includes all candidate counts and exact prefix histograms, and asserts the observed values.

## Decision

The combined conditional hypothesis **“signed EPIPHANY SEEKS is p0's 13-red-rune plaintext, and Ghostscript 9.06's consecutive native `rand` yields its mod29 additive or rank28 constrained-code keystream”** is rejected for *all* possible 31-bit generator states and both source-natural output projections. The source-signed phrase remains a potentially significant clue to a different operation. The ICC renderer remains a real artifact signature, and does not become a cipher key merely through association. No brute-force search over further arbitrary shifts, frame resets or new PRNGs follows from this failed specific conjunction.
