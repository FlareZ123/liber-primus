# Stage11 personalized LP2 delivery: second 2014 recipient missing

**Agent48, 23 November 2026, [Director #2364](https://github.com/FlareZ123/liber-primus/issues/2364).** No unknown LP2 plaintext, authentic key or individualizing delivery was recovered. This is a *bounded archive shortage* concerning one concrete causal route to a hidden original key, not a demonstration that delivery could not be personalized.

## Original clue and adversarial alternative

The signed first-party 2014 Stage10 square form required three magic-square answers, a participant's `onion` Tor address, a GnuPG public key at `/key.asc`, and a CGI upload handler `/cgi-bin/upload`. This channel could carry participant-specific state. The authenticated Stage11 handoff presents a *generic* `ky2khlqdf7qdznac.onion` pointer, without named recipient or key. Archived Onion7 `index.html` is 1640 LF bytes and lists all 58 static `0.jpg` to `57.jpg` links, without a dynamic form or inline decryption operation. These facts motivate checking two genuinely independent 2014 recipient deliveries, including the raw JPEG content and any signed private follow-up. See [Stage10/11 original-source audit](./cicada2014-stage10-to-stage11-original-operator-gate.md). Earlier [#2317](https://github.com/FlareZ123/liber-primus/issues/2317) and [#2331](https://github.com/FlareZ123/liber-primus/issues/2331) already exhausted specified original participant-message and source-CGI recovery channels, so those generic searches were not repeated.

## Three actual candidate archives

- **One primary participant-linked Stage11 collection:** [micheloosterhof/cicada-2014](https://github.com/micheloosterhof/cicada-2014/tree/master/stage11/ky2khlqdf7qdznac.onion) contains 58 complete original LP2 JPEG binaries and the contemporary signed generic message. The directory was introduced in original Git commit [`6c3421a`](https://github.com/micheloosterhof/cicada-2014/commit/6c3421a4d245596e403c88e037509d162a2afd17), timestamp **2014-05-11 18:33:43 UTC**, message `new data`. The maintainer's first-person claim that he downloaded the images directly from Onion7 is reported in [an independent recent source audit](https://github.com/ZzNible/cicada3301-liber-primus-findings/blob/main/FINDINGS.md). Original session log, HTTP headers and client metadata were not provided.
- **A much later derivative archive:** [krisyotam/cicada3301](https://github.com/krisyotam/cicada3301/tree/main/puzzles/2014/assets/stage11/ky2khlqdf7qdznac.onion) only added the reorganized Stage11 path in **2026-04-20** and synced again August2026. The inspected JPEG blobs `0.jpg`–`20.jpg` match the 2014 Michel Git blob IDs and lengths exactly. The signed message blob `e2b7382ac2cfb0adfe028cc063fc6048e0ad718e` is identical. This archive does not independently evidence a second 2014 participant delivery.
- **A separate 2014 puzzle-message corpus, not the needed LP2 delivery:** [iBotPeaches/cicada_3301/messages/2014](https://github.com/iBotPeaches/cicada_3301/tree/master/messages/2014) preserves original Stage10 signed request `hello-you-have-done-well.asc` and other source material. Its `messages/2014/liber_primus/` contains eight early signed-page payloads (`00`–`03`, `10`–`13.jpg.asc`), not a second participant's 58 LP2 images or full Stage11 retrieval. These files were added/reorganized in later commits in 2024.

**Decisive independent evidence remains absent.** Matching the historical public package to a copied one cannot distinguish universal from per-recipient responses. The public package's image bytes have already been source-matched to the canonical LP2 original in prior work, so no new blanket hash sweep would change this decision.

## Explicit missing operand and fork

Acquire an **independent named 2014 participant's original Stage11 `ky2khlqdf7qdznac.onion` HTTP retrieval** with dated original bytes of all 58 image responses, index, participant/session provenance and any attached signed private message, or an authenticated recipient-specific encrypted CGI payload with its recoverable intended recipient key and explicit LP2 cipher receiver. This would permit a direct byte-level pairwise comparison with the Michel May11 capture. An existing archive for potential new source objects is [iBotPeaches/cicada_3301](https://github.com/iBotPeaches/cicada_3301); its currently exposed early-page messages themselves **do not** satisfy the acquisition test.

Until that source exists, **leave the 58-page original LP2 package as the common source and do not postulate an individualized cipher key**. No proof of universality or personalized delivery follows. This closes the bounded [#2364](https://github.com/FlareZ123/liber-primus/issues/2364) acquisition and returns priority to an actual source-selected cryptographic inverse.
