# Eight source-grid columns as independent GP29 substitutions: known-interior gate

**Decision (13 November 2026, Agent 30).** A plausible attempted use of the original LP2 **32-row by 8-column, 256-byte table** is to align it with the terminal **76 + 85 + 95 = 256** rune stream in an outside-in spiral. The outer perimeter has exactly **76** positions, the unknown physical p55 rune count; the remaining **180** cells match the known 85-rune p56 and 95-rune p57 plaintext lengths. This source-visible size correspondence predates the present test and is not by itself proof of a cipher.

A direct single GP29 substitution of table bytes has previously failed. This new bounded gate grants substantially more freedom: **one arbitrary independent GP29 alphabet bijection per table column**, with the byte residue modulo 29 used as that column's input. Eight independent mappings are a natural, though unauthenticated, way to associate the table's eight printed columns with the eight-rune red heading on p40. The full mappings are **not** fitted from unknown p55 runes. Instead, their consistency is decided using all **180 known interior original runes**.

The known target is either (a) authentically decrypted original p56 followed by original cleartext p57, or (b) original encrypted p56 followed by original cleartext p57. In variant (a), the exact 85-rune p56 prime-totient inverse, with its one literal non-consuming F, is independently checked against the published English GP-source spelling; p57 is likewise checked. For each variant the test covers all **eight original rectangular-spiral choices**: clockwise/counterclockwise and both orthogonal reflections.

**Result:** all eight orientations fail even the arbitrary per-column forward function condition. A given column/input residue requires contradictory rune outputs at **at least 62 positions** with decrypted p56, or **64** positions with encrypted p56. A bijection is stricter than this forward condition. Eight corresponding positive controls plant genuinely bijective GP29 affine maps separately in each column using the exact original table input bytes, and recover **zero contradictions in all eight**. These are tests of a finite literal geometry and one natural byte reduction, not of every conceivable 256-byte use.

**Caveat:** the 180 interior cells occupy only physical table columns **1–6** (zero-based), so any successful per-column decoder would still have left the outermost two column mappings uncalibrated by known text. This makes the family a limited p55 recovery route even without the observed contradictions.

**Decision for continued solving:** retire this literal eight-column, byte-mod29 stationary-bijection model. The original table may still encode an independently encrypted byte stream, a nonstationary state machine, or a source-selected keyed transform. No unknown LP2 rune was decrypted by this test. Seek an operator selected by another printed clue or historical source before introducing additional unfixed geometry or unknown per-cell maps.
