## Independent nulls and selection limitations

1. **Exact within-word endpoint-order null.** Independently permute each of the original 20 words' *rune positions* uniformly, preserving every word length, rune multiset, whole GP sum and the set of 18 candidate target sums. For a word with n runes, each of the n(n−1) ordered distinct endpoint pairs is equally likely. Exhaustively count which endpoint pairs make the middle sum equal to **any** original whole-word sum, and combine 20 Bernoulli probabilities by an exact Poisson-binomial calculation. Only five words have any possible hit: PARABLE **2/42**, LICE **2/12**, SURFACE **2/42**, DIUINITY **2/56**, WITHIN **4/20**. The expected hit count is **0.4976190**; an outcome with **at least two** hits occurs with exact probability **7.461397%**, and **exactly two** with **6.872908%**. If *PARABLE and DIUINITY* had been fixed as the two sole input words prior to any arithmetic, the probability both hit *some* other printed whole-word sum is **1/588 ≈ 0.1701%**. That is a strongly conditioned, comparatively favorable figure, **not** an unconditional discovery-wide probability. Five alternative input words had possible hits; a whole-book search would have many more opportunities. The null breaks natural spelling and measures only endpoint selection, so it is not a realistic generator of actual 2013 Cicada prose.
