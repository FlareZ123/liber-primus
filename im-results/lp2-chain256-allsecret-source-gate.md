# Original LP2 chain-step / period-256 all-secret gate

**12 November 2026, Agent 13.** An independent original-input test of a concrete reversible candidate: the 256 source-visible bytes printed across LP2 physical pp49–51, combined with the 28-step nonzero ciphertext-difference alphabet. **No unknown LP2 plaintext or authentic historical key was recovered.** This report excludes a source-motivated cipher *family*, rather than another guess at a specific key.

## Original-source operation and key-independent prediction

The manuscript's 256 numerical cells form 32 rows of eight two-character tokens. Their conventional base60 reading supplies a candidate 256-byte key; that parse remains conditional. Under the separately proposed primitive GP29 multiplier 15, let C be the 12,956 original GP29 rune indexes from physical p0–55, with C before the first rune taken as 0. Compute D[i] = (C[i]-C[i-1]) mod29, and let E[i] = log_15(D[i]) in 0..27 for nonzero D. For D=0, emit reserved GP symbol EA/28 and do **not** consume the key clock. Exactly **86** zero steps occur. The generator 15 has exact order 28 in the nonzero residue group mod29. Neither the zero-step interpretation nor the log mapping is established as the historical cipher.

An attractive first consumer, now rejected, repeats the printed row-major 256 bytes (B) as a 28-way additive key on *only* nonzero steps: P[i]=(E[i] ± (B[keyClock mod256] mod28)) mod28, while zero steps emit EA. Both signs are nonlinguistic; output whole-book rune IoCs are approximately 0.03527 versus approximately 0.03448 for the original ciphertext. This is only a fixed specific key, so the main test below grants **every possible unknown phase-specific 28-symbol bijection**.

Suppose instead that each nonzero position at clock phase t mod256 is encoded by an arbitrary *bijective* substitution f_t:P→E, and that EA uses the zero-step escape. For two positions in the same phase, P_i=P_j if and only if E_i=E_j. Consequently the total same-phase equal-pair count, after removing EA and using the exact reset segmentation, is a **key-independent necessary condition** for *every* one of the (28!)^256 phase-key combinations. This does not rely on guessing a key or on any language model.

The source-native English controls are the same GP29 mapping used elsewhere in the repository: case-fold, replace V→U/K→C/Z→S/Q→C, greedy-longest GP tokenization (including TH, EO, NG, OE, AE, IA and EA), and remove only nonletters. We take all complete length-12,956 windows at fixed stride 6,000 from pinned Shakespeare and Emerson texts, and at stride 3,000 from pinned Gibran. The 104 windows are independent of the source-ciphertext key.

## Fixed-escape symbol word-position gate on original printed words (Agent43, 12 November 2026)

**New independently discriminating necessary condition, not a recovered cipher.** A strict predecessor-exclusion encoder can represent 28 payload symbols by nonzero differences and reserve the zero difference for **one fixed plaintext symbol**, often proposed to be GP index28 `EA`. Even if all 28 nonzero output labels use secret phase-dependent permutations, under this specific *literal escape* contract every same-page immediate ciphertext repeat **must** identify an occurrence of that one plaintext symbol. Its word position and incidence are invariant under every secret key on the other symbols. No key sweep is needed.

The exact original physical p0–55 stream has 12,956 rune positions and 2,896 complete punctuation-delimited words, including words that cross printed lines or pages. Excluding the first rune of each of the 55 rune-bearing pages, it has **86 adjacent repeats**; **23 occur at the beginning of a canonical printed word**, including **3 beginnings of two-rune words**. This is a necessary `(total, word-start, two-rune-start)=(86,23,3)` occurrence signature for any one literal reserved GP symbol. Note that a marker can occur at a word start even when the repeated preceding ciphertext rune belongs to the preceding word.

A fixed-layout native-English test uses the existing exact GP29 transcription and the project’s established GP transliterator (including `ING→NG`). In **1,500 seeded source-native draws per Shakespeare, Gibran and Emerson**, every one of the original 2,896 word lengths is filled by an actual GP-transliterated word of equal length from that author’s pinned corpus, independently sampled with replacement. At all 55 authentic page starts, counting is suppressed because there is no in-page predecessor. This preserves word-start positions and original pages; it does **not** assume plaintext word identity or test native-English source passages verbatim.

**The jointly permissive ±10 occurrence window and the all-29-symbol scan both fail in all 4,500 fixed-layout samples.** The original `EA` count of 86 is individually plausible for Shakespeare/Emerson, but its concentration at word starts is not typical of these samples. The any-marker test is stronger than testing `EA` alone: it allows a completely unknown fixed reserved plaintext rune and treats the other 28 labels as unconstrained. The 4,500 draws are intentionally simple independent-word controls; these counts do not establish a universal probability bound, an authorial plaintext distribution, or impossibility in another language. The inspected occurrence band is an explicit generous diagnostic, not a key-estimation procedure.

**Authentic solved-Cicada register control:** The original `resources/transcriptions/liber_primus_master.txt` preserves four passages printed directly in plaintext GP runes: LP1 `SOME WISDOM` ($-section2: 157 runes / 31 words / 2 EA), `THE LOSS OF DIVINITY` (section4: 755 / 181 / 6), `AN INSTRUCTION` (section6: 89 / 18 / 0), and LP2 `PARABLE` (section17: 95 / 20 / 0). These authentic clear GP passages contain **1,096 runes, 250 printed words, eight literal GP `EA` symbols, and zero `EA` word beginnings**. This source-native control lends direct contextual force to the absence of 23 `EA`-initial words in the modern-language comparison, although 1,096 clear runes cannot by themselves calibrate all 12,956 unknown runes or exclude a different manuscript register. The original GP rune counts and exact `EA` word positions are asserted in the same SFT; the solved text is read directly, without decoding or inferred spelling.

**Positive control:** The independent CommonJS [original-input SFT](../sims/lp2_zero_repeat_marker_wordstart_sft.cjs) constructs a complete 12,956-rune lossless marker encoder for three different reserved runes (`F`, `J`, `EA`): for non-page-leading positions it emits the prior ciphertext rune exactly when the planted plaintext symbol equals the reserve, otherwise adds `1 +` its position in the other-28 alphabet modulo29. Exact inversion recovers every rune and the native-text marker counts, starts, and two-rune starts match the resulting ciphertext repeat sites. Both the original source counts and all 4,500 native controls were executed against pinned repository bytes (the script's output is deterministic). This test is distinct from the prior 256-phase collision exclusions, which **imposed the 86 source-observed marker positions** on comparison controls and therefore could not test whether those positions resemble locations of any one natural-language token.

**Research decision:** Deprioritize the *literal fixed escape symbol* (especially `EA`) as a complete explanation for all 86 observed repeats behind a 28-way predecessor cipher unless an independent original-source rule explains the unusual word-initial concentration. The same source evidence leaves **word-conditional escape semantics, state-varying reserved symbols, deliberate position changes, alternate languages, and nonliteral repeat handling** open. No unknown LP2 plaintext or authentic key follows.

## Decision and limits

**Reject direct native-GP English plaintext behind the 256-phase stationary bijective predecessor-rank families tested: the original log-step with book/nine-chapter reset and EA zero markers, plus cyclic/sorted ranks under book/page reset with held/advanced erasure clocks and F/EA marker reservations.** In every declared clock and rank convention, the original same-phase equality rates are far below the corresponding original-length native-GP controls, before any key selection. The original exact source grid modulo28 Vigenère consumer is a strict subfamily and need not be retried with different phase permutations.

This excludes neither a cipher with state that evolves when the same key phase recurs, nor alternate plaintext alphabets, a changed zero-step meaning, insertions/erasures, different key clocks, or an independently selected 256-byte stream-cipher expansion. It also does not prove that the original 256 cells were intended as a repeating key. Any proposed descendant should specify **which source instruction changes one of these assumptions**; searching all 256-phase keys would otherwise be unproductive.
