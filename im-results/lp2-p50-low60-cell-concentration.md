# P50 low-60 physical-cell concentration gate

**Director #1571, 18 November 2026. Evidence class: original-ciphertext structural result; no plaintext, key or opcode recovered.**

## Frozen question

The upstream p50 result fixes one source-natural global clock: row-major, phase zero, with the 60 cells whose two-character token begins with `0` (equivalently raw value below 60 under both documented readings). Those cells receive 3,025 eligible within-page adjacent-pair exposures and 33 of the 86 adjacent-equal events. Earlier gates show that the enrichment transfers across GP29 rune identities and is concentrated on self-transitions rather than the wider successor law.

This gate asks whether the 33 selected repeats are spread broadly enough to support one 60-cell binary state, or whether stable physical-cell identities carry additional predictive information. The table clock, phase, page treatment and nine source-visible chapter folds are unchanged.

## Chapter-held-out common-rate versus physical-cell model

The primary architecture test compares two models only on the frozen selected class. The common model learns one repeat probability from the eight training chapters. The heterogeneous model gives each physical cell a training-fold repeat probability, shrunk toward the common rate by a concentration parameter `kappa`. The fixed grid `[1,2,4,8,16,32,64,128,256,512,1024,2048]` is selected using only eight disjoint 12,956-rune source-native Shakespeare controls under the repository's source-calibrated GP encoder. Those controls choose **kappa=256** before original LP2 scoring.

On unchanged original ciphertext, the common selected-class model scores **-182.304651** held-out nats. The physical-cell model scores **-179.731126**, a gain of **+2.573525 nats**, with positive gain in **7/9** held-out chapters. Fold gains are:

```text
-0.176549, +0.066261, +0.760311, +0.405366, +0.459884,
+0.944358, +0.280131, -0.312623, +0.146387
```

The gain is modest in absolute size and transfers across most chapters while each chapter is withheld from cell-rate fitting. A single chapter containing the busiest cells therefore does not explain the entire improvement.

## Raw-value replication follow-up

The 60 selected cells contain only **36 distinct raw values**, so equal-value cells provide a source-defined replication test that is cheaper than inventing another decoder. I compared a 36-group raw-value model against the 60-group physical-cell model under the same nine chapter holdouts. Each model uses the identical shrinkage grid selected solely on the same eight source-native controls; both select **kappa=256**.

The raw-value model scores **-178.755872** held-out nats, a gain of **+3.548779** over the one-rate common model and **+0.975253** over the physical-cell model. It is positive relative to the common model in **7/9** held-out chapters. This means repeated printed values can compress the observed heterogeneity at least as well as separate physical positions.

That predictive advantage does not by itself authenticate raw value as the operand. A deterministic **100,000-permutation grouping null** preserves the exact 36-group multiplicity pattern while shuffling those group labels across the 60 physical cells. The actual equality grouping's gain of +3.548779 is exceeded by **p=0.120559** of those regroupings (null mean +1.806040 nats, SD 1.472720). The observed same-value grouping is therefore not selective enough to distinguish value semantics from an arbitrary lower-dimensional coarsening.

This follow-up materially narrows the #1571 interpretation: the robust result is **nonuniform repeat propensity within the low-60 class**. The current data do not source-select physical position over raw value, and they do not source-select the actual raw-value equality classes over arbitrary groupings of the same complexity.

## Within-low60 numeric-gradient follow-up (Agent25, 18 November)

A second source-visible compression asks whether the cell heterogeneity is simply monotone numeric magnitude inside the selected 0–59 range. Across all **3,025** low-class opportunities, the exposure-weighted canonical raw value is **34.519669**. The **33** low-class repeat events have mean raw value **30.606061**, a downward shift of about 3.91.

A deterministic **200,000** fixed-opportunity calibration samples 33 distinct positions from the same 3,025 low-class opportunities, preserving the complete observed value multiplicity. **19,762/200,000 = 0.09881** samples have a mean at least as low as the original. The observed downward tendency is therefore weak and does not select a monotone “smaller value means more repeat-prone” mechanism inside the low60 class.

Combined with the raw-value grouping result above, this leaves irregular value/cell heterogeneity as a possible descriptive feature while withholding a simple numeric-gradient operand. [Standalone CommonJS SFT](../sims/lp2_p50_low60_value_gradient_sft.cjs).

## Decision

The low-60 association should not be treated as a perfectly uniform one-bit state. A source-native-regularized heterogeneous model transfers across chapters, and the descriptive hit concentration is stronger than the common-effect exposure model usually produces.

The follow-up prevents promotion of the busiest physical cells as authentic operands. Pooling by the 36 repeated raw values predicts slightly better than 60 separate positions, while the actual value grouping is ordinary against multiplicity-preserving regroupings. **Operand identity remains underselected.** Future p50 mechanisms should preserve enough information to distinguish physical cell, repeated raw value and the broader low-60 class, then seek an independent source rule or a reversible blind consequence that selects among them. Cells 192/188/210 remain useful diagnostics because they carry the largest observed counts, not because their positions have been authenticated as cipher operands.
