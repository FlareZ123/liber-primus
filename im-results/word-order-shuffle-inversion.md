# LP2 word-order key inversions: clue-seeded shuffles and original grid columns

**Evidence classification (2026-11-10, Agent 37): two original-ciphertext inversion screens with powered exact-key controls and matched null comparisons; no recovered LP2 word order, rune plaintext, or genuine key.** This report directly compares the two new tests. The prior [word-length order study](wordlength-order.md) established that ordinary adjacent length dependence is strikingly weak in the visible LP2 words and that simple rail-fence/column rearrangements do not restore it.

## Attack surface and immutable text cuts

The canonical `resources/transcriptions/liber_primus_master.txt` gives nine original `$` sections of rune lengths `[729,1145,1729,9,1894,1021,1524,1589,3316]`. Merge the short nine-rune fourth section to the fifth, producing eight substantial sections. The image-audited red title endpoints remove exactly `[2,3,2,3,4,3,2,2]` whole title words, leaving **[156,252,381,434,220,346,353,733]** words for the eight body permutation problems, **2,875** words in total. Printed page/line wraps do not break a word. These exact token counts are asserted before any candidate scoring.

The proposed cryptosystem would first scramble complete plaintext words separately inside each section, thereby concealing English word-length neighbor dependencies while preserving their length multiset and internal ciphertext word breaks. Since an unknown independent rune cipher might subsequently transform each word, this experiment evaluates *only* inverse word order, without fitting or claiming any decrypted letters. A true inverse should restore English-like direction in the relationship between adjacent word lengths, not just inflate an undirected test statistic.

## Experiment A: numeric-seed Fisher-Yates word-order permutation

`sims/wordlength_seeded_shuffle.cjs` enumerates every unsigned seed **0–4,095** under two 32-bit PRNGs (LCG and xorshift) and three across-section key policies (identical seed, seed+section index, continuous stream). It inverts a Fisher-Yates permutation of each section body, measures 3×3 adjacent-word-length Pearson chi-square with categories `1–2`, `3–5`, and `6+`, and selects the best across **24,576** configurations. The original eight unshuffled bodies have χ² **3.3317348593**. The selected inversion, **LCG seed 582, identical-seed mode**, has χ² **33.0102853222**.

Twenty-four independent original-body length shuffles rerun the *entire* 24,576-search maximum: median maximum χ² **25.99942**, highest **32.88517**. Zero controls exceed the real selected maximum, giving add-one upper-tail **p=1/25=0.04**. This coarse, high-variance Monte Carlo indication alone cannot identify the mechanism, especially given other previously explored permutation families.

**Independent directional disconfirmation.** Train a 3×3 GP-English word-length log-odds transition model on the first 80% of the separately stored Shakespeare control. Score the visible LP2 word-order and the χ² winner without retuning it. Original LP2 directional log-odds is **−16.27158815**, while seed-582 inverse is **−37.86530380**. The inversion has a more striking *anti-English* short/long adjacency pattern, so its χ² peak is not a credible English plaintext ordering. This distinction rules out mistaking unsigned dependence for evidence of linguistic restoration.

A known-source source-English positive plant at the true hidden seed **3301**, LCG same-seed mode, recovers *exactly* that key and mechanism as search rank one with source χ² **72.93076**, against encrypted χ² **5.31093**. An independent **45% chance of adding one rune per word** still recovers exact seed3301 with source χ² **45.75176**, scrambled **6.70960**. These are controlled demonstrates that ordinary English dependence survives the declared attack family and is detectable when present.

Full original, planted and directional results: [successful second CI run 42770857592](https://github.com/FlareZ123/liber-primus/actions/runs/42770857592). The earlier [first run 42770123540](https://github.com/FlareZ123/liber-primus/actions/runs/42770123540) tested the original, controls and randomized null before the independent directional check was added.

## Experiment B: eight original 256-bit numeric-grid columns as word-shuffle keys

`sims/grid_word_order_inversion.cjs` derives eight **literal 32-byte vertical columns** from `resources/liber-primus/base60-grid.json` (exact source table SHA-256 `3b9b07d9a26e6d55c432d94d2661fdff3c2b348daed06821f2bdb23184a4b290`). Instead of the previously unsuccessful **rune additive pad** hypothesis for these keys, use each column as a PRNG key for a permutation of *complete words*. Frozen alternatives: AES-256-CTR versus ChaCha20, forward versus reversed key bytes, 32-bit Fisher-Yates draw read little-endian or big-endian, and forward versus inverse permutation convention. For each of the **16** settings, solve the full **8! one-to-one assignment** of grid columns to sections using exact subset dynamic programming.

The score is a **five-bin directional** word-length adjacent-transition log likelihood ratio trained only on the independent initial 80% of the Shakespeare control, with no LP2 parameters fitted except the candidate family and eight key assignments. Without any change to word order, original LP2 score is **−27.85456**. The best of the 16×8! tests attains **−6.54752**, with ChaCha20, reversed source keys, big-endian draw, and column assignment `[1,2,4,3,0,7,5,6]`.

To calibrate the highly optimized key assignment, perform **64** independently deterministic byte-order shuffles *inside each original 32-byte column*, and rerun exactly the same 16×8! inversion selection. Null maximum-score median is **−4.81557**; **52/64** beat the original-grid score, yielding plus-one **p=53/65=0.81538**. The apparent best grid-key permutation has no evidential advantage over scrambled keys.

A synthetic source-English planted manuscript, with an independent hidden eight-column assignment `[6,2,4,0,1,7,5,3]` and true AES-256-CTR, forward-key, big-endian Fisher-Yates, is recovered **exactly**, including the complete assignment. The no-padding positive source scores **37.64731** after correctly undoing the scramble versus **−21.36517** while scrambled. With 45% per-word one-rune extension, the true model still ranks first with exact assignment and decoded score **3.34478** versus scrambled **−31.06689**. The successful [CI run 42770488273](https://github.com/FlareZ123/liber-primus/actions/runs/42770488273) reproduces the observed table and both plants.

## Cryptanalytic significance and next decision

These attacks invert an *entire putative intermediate operation* while leaving the unknown rune cipher untouched. They establish that simple seeded and AES/ChaCha table-column word permutations, if applied in the tested order with ordinary GP-English word lengths and intact visible boundaries, should leave statistical signals. No comparable signal is present in the actual encrypted book.

The seed-582 3-bin χ² peak should **not** be promoted or treated as a restored passage: an independent English directional check contradicts it. The grid-column maximizer similarly loses to matched randomized keys. Neither experiment can rule out a cryptosystem that changes word boundaries, shuffles across section headings, uses an untested generator/nonce, carries a different language register, or deliberately balances length patterns.

The strongest further work is to use the eight 256-bit columns in an *actual rune stream inversion* with ciphertext-dependent consumed-key skips, which the direct no-skip AES/ChaCha tests leave open. Such a method must ultimately reproduce and recover original rune plaintext instead of accepting word-length statistics alone.
