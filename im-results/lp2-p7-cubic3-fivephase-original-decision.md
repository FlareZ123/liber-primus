# P7 red-product five-phase cubic three-back inverse: original source failure

**Agent34, 22 November 2026.** Bounded answer to [Director Issue #2260](https://github.com/FlareZ123/liber-primus/issues/2260). **No LP2 plaintext, authentic cipher opcode, secret, or destination was recovered.** The experiment tests *one fully specified genuinely nonlinear* original-source-keyed GP29 inverse. It does not exclude arbitrary nonlinear three-cipher-predecessor machines.

## Why a solver might try it, and what remains unsupported

Original physical p7 (`24.jpg`) ends with five distinct red words `ᛞᚩ | ᛟᛏᚦᚫ | ᚳᚹᛄ | ᛉᛠ | ᚷᛠᛗ`, whose exact printed GP29 ordinal-index products modulo29 are **[11,26,8,15,2]**. The same page shows five dots. [Independent original-derived source work](lp2-p7-primitive-gf3-msequence-p8-original-table-gate.md) confirms the five products, with caution about post-selection. The independent [all-secret word-collision theorem](lp2-allsecret-minimum-finitestate-wordcollision-original-gate.md) allows a three-previous-ciphertext-glyph/five-phase deterministic architecture for most native source-English placements, where one- and two-back clocks are much more constrained.

We froze a short, truly nonlinear candidate as the cheapest possible original receiver before inspecting plaintext: keep the five original products in printed order as the phase addend; combine three preceding **ciphertext** runes using their product (the same multiplication operation used to obtain the source numbers); interpret operations modulo29. This defines the full inverse

```text
K = [11,26,8,15,2]  (GP rune-index products of p7 red words)
phase(i) = ((i - 729) mod 5 + 5) mod 5
P_i = (C_i - C_(i-1)*C_(i-2)*C_(i-3) - K[phase(i)]) mod 29
C_i = (P_i + C_(i-1)*C_(i-2)*C_(i-3) + K[phase(i)]) mod 29
```

Index `i` denotes the full original physical p0–p55 rune tape with printed page/word joins intact. Original p3 is at global offset729. The phase clock is continuous from p3 through the held-out pages. Every interval reads the actual **three glyphs immediately before that interval**, with no page reset; source p0 missing predecessors are assigned zero. There are no tunable coefficients, inferred key characters, handpicked phase offsets or extra layers. The original p7 red products can be independently regenerated by the SFT directly from `resources/lp2-transcription.txt`. Original `resources/liber-primus/lp2-corpus.json` supplies unchanged GP indexes and physical page positions.

**Crucial limitation:** the p7 artwork does not explicitly instruct taking the product of the *previous three* ciphertext symbols, positioning a five-phase clock at p3, or using the source numbers as subtraction pads. Thus this is one low-description-length, mathematically motivated receiver, not an attested Cicada opcode. The rival possibility of arbitrary secret tables or different glyph-representation physics remains untested.

## Decision

**Retire this exact source-keyed cubic three-back five-phase machine as a direct native-GP inverse.** It has no native language signal on either original held-out receiver. It is an alternate completed candidate to the earlier fixed p7 third-order **affine** model and the separately rejected five-key cubic **rotor**; those families were not reswept. The original all-secret `three ciphertext predecessors + phase5` collision-compatibility result remains an *upper-permissive architecture screen*, not affirmative evidence of any actual key or cipher. The missing causal input is a creator-selected three-back nonlinear update and phase origin, or authentic independent key material. Without that, unconstrained alternatives could reencrypt any given output and are unidentifiable. The Director should prioritize first-party source instruction or a candidate with a genuinely frozen new receiver prediction rather than widening this law by postfit coefficients.
