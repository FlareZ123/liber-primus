# Two original PARABLE clause sums and signed DH23 clocks independently target p0's THE|DEVOTED physical boundary

**Agent4, 22 November 2026. Classification: exact original-input cross-source recipient selection, conditional on inferred 256-byte table navigation. No unknown plaintext recovery, no authenticated GP29 inverse, and no claimed LP2 decryption.** This is an independent, bounded corroboration of an already selected p0 nine-rune receiver using **all three original clear-p57 PARABLE verses**, with previously printed 2013 DH parameters. It is materially closer to a cipher receiver than an isolated number equality: the two distinct walks land on *different sides of the same original physical word boundary*.

## What a human player could see

The authentic final LP2 p57 PARABLE, after its seven-rune title, has three original verse spans of **30, 30 and 28 runes**, with exact original GP-prime sums **1259, 1031, 1229**. Those numbers occur in 2013 participant records; their product **1,595,277,641** appears in the pre-2014 Cicada audio file's original ID3 PARABLE label. Historical provenance and exact original GP29 arithmetic already established in [2013 source synthesis](../results/2013-761-parable-prime-products.md). None of these numbers were fitted to p0 ciphertext.

The **signed 26 January 2013 Cicada TCP example** specifies an actual Diffie–Hellman worked exchange: prime `p=23`, base `g=5`, private exponents `a=6`, `b=15`, public `A=8`, `B=19`, shared `K=2`. Those are historical worked-example values, rather than confirmed author-selected LP2 key material. In a separate candidate interpretation, the p28 line containing literal `DH` gives several matching geometric counts; this historical precedent makes the operation worth testing, while still leaving its LP2 transfer unlicensed.

The physical LP2 p49–51 numerical table contains exactly **256 two-character tokens**. Treat each original printed token as one conventional base60 byte and a zero-based **pointer to another of the 256 cells**, as already modeled in the repository. Taking every p57 clear-clause sum `mod256` therefore gives **three source-derived, fixed initial addresses** `[235,7,205]`; no original ciphertext is examined to select those addresses.

Follow the original unedited table pointer with the first two historical **DH23 worked-example hop counts** `K=2` and `a=6`, respectively. The full original cell sequence is:

```text
  K=2 steps: 235 -> 121 -> 237

  a=6 steps: 7 -> 183 -> 81 -> 58 -> 146 -> 92 -> 236
```

**The outputs are adjacent original p0 rune positions in the exact reverse order 237,236**, straddling its physical 2-rune/7-rune word boundary.

The older, independently established **2016 signed-message word-map** selected precisely the same boundary using **another operation and different original source tokens**: authentic signed words `EMPTY` and `EPIPHANY` have whole-word GP0 sums **92** and **121**, and the original table returns `p50[92]=236` and `p50[121]=237`. These are *the last two cells traversed by the new two p57-seeded paths*. Thus the new paths do more than return the p0 coordinate: each path enters an already source-selected **signed-2016 word address** immediately before producing its terminal p0 offset:


## Conditional fixed-residue Monte Carlo gate

We tested how often this exact structural receiver appears under a restrictive source-preserving control. Keep all **256 original full-byte values** and their multiset; swap full byte values *only* between table positions whose original coefficient residues modulo29 are identical. This preserves every original 256-position GF29 residue and all exact original H/G polynomial factor relations. Count before inspecting any candidate plaintext.

The fixed ordered-boundary event appears only **21/200,000** times (0.0105% of the restricted shuffles). Retrospective discovery through many source relationships, operation choices and prior candidate target assignments **is not charged**. Hence this is a conditional, sensitivity-calibration statistic and **not** an authorship probability, cryptanalytic plaintext score, familywise significance, or reason to accept a specific seven-rune crib. The result makes the route worth testing only if an independent original instruction supplies the still-missing inverse.

## Independent 2016 word-map key candidate at the same boundary

A separate test of the corrected 29-word signed-message body register finds one unique adjacent pair whose p50 destinations are consecutive:

- body ordinal 4, `EMPTY`: GP0 sum **92**, p50 address **236**
- body ordinal 5, `EPIPHANY`: GP0 sum **121**, p50 address **237**

The residues are **[5,5] mod29**. The two addresses straddle the p0 word boundary at offsets236/237; the preceding two-rune word at offsets235–236 is original GP29 **[8,5]**. The two possible additive signs give:

```text
C-K = [3,0] = OF
C+K = [13,10] = PI
```

The signed message does not fix the sign. This key candidate therefore competes with the earlier conditional `THE` crib for the same receiver; it is not a verified decryption. It is unique among the 28 adjacent pairs in the corrected 29-word body register.

This is a separate, inferred two-symbol key candidate; it is not derived from the p57/DH paths. The p57/DH paths independently corroborate **recipient selection** at the same boundary, while the 2016 pair supplies a possible short key. Neither route establishes a reusable LP2 cipher. The following seven-rune `DEVOTED` candidate remains underdetermined. See [the updated 2016 p50 word-map report](lp2-p50-functional-graph-2016-wordmap.md) and its SFT.

## Decision: the missing actionable step

These original controls create an **independently source-convergent candidate recipient**: solved p57 clause sums, signed 2013 DH clocks, later signed 2016 word-value addresses and exact p0 physical ink all meet on the same original-ciphertext boundary. The p57/DH route itself does not derive a key. A separate 2016 EMPTY/EPIPHANY word-pair test supplies the two-symbol [5,5] key candidate described above; its C-K and C+K outputs are OF and PI, respectively, and it competes with the earlier conditional THE crib.

The smallest useful next decision is to seek a **second independent, source-selected receiver or longer untouched ciphertext span** that can test the 2016 word-number key rule and distinguish the competing OF/PI/THE readings. The p57/DH route remains navigation corroboration, not the key. The seven-rune DEVOTED residual remains underdetermined because same-type transfer fails. Do not rescue any candidate with arbitrary phase, mask or word-alias searches.
