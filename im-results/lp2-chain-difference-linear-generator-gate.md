# LP2 first-difference stream: linear-generator gate

**Status:** intermediate negative. No plaintext, key, or cipher mechanism recovered.

## Question

A recent external analysis proposes expressing the unsolved LP2 rune sequence as a chained additive process,

\[
C_{i+1}=C_i+s_i\pmod{29},
\]

and treating the observed step sequence as a 28-symbol keyed stream, with zero steps corresponding to adjacent repeated runes. The proposal is useful as a way to expose the first-difference sequence, but the equation alone is not evidence of encryption: for any ciphertext sequence, setting \(s_i=C_{i+1}-C_i\pmod{29}\) makes it an identity. A cryptanalytic mechanism still needs a source-constrained relation between \(s_i\), plaintext, and/or key material.

This gate asks a narrower question: **is the observed step sequence itself generated by a small linear recurrence or first-order LCG?** A positive result could expose a recoverable key generator; a negative result would prevent an unproductive small-PRNG branch.

## Input and exact sequence

Input: `resources/liber-primus/lp2-corpus.json`, Git blob SHA `054f2a0f780b7d46901acbe3d9bf4f0ac1801165`.

Flattening pages 0–55 in corpus order gives 12,956 rune indices and 12,955 first differences:

\[
D_i=(C_{i+1}-C_i)\bmod 29.
\]

Observed distribution:

- Zero transitions: **86**.
- Nonzero transitions: **12,869**.
- Counts among the 28 nonzero residues range from **404 to 510**.
- The zero count is therefore a sparse exception channel, not a uniform 29-symbol output. The nonzero values are broadly balanced.

## Tests

### 1. Berlekamp–Massey over GF(29)

For each sequence, Berlekamp–Massey was fit on the full stream to measure linear complexity. A separate model was fit on the first half and tested one symbol at a time on the untouched second half.

| Sequence | Length | Full linear complexity | Prefix complexity | Holdout exact hits | Holdout accuracy |
|---|---:|---:|---:|---:|---:|
| All differences | 12,955 | 6,478 | 3,239 / 6,477 | 203 / 6,478 | 3.1337% |
| Nonzero differences | 12,869 | 6,435 | 3,217 / 6,434 | 200 / 6,435 | 3.1080% |
| Nonzero rank (value − 1) | 12,869 | 6,435 | 3,217 / 6,434 | 200 / 6,435 | 3.1080% |
| Nonzero discrete log base 15 | 12,869 | 6,435 | 3,217 / 6,434 | 222 / 6,435 | 3.4499% |

The random-symbol baseline over GF(29) is **3.4483%**. Linear complexity is approximately half the sequence length, as expected for a high-complexity sequence; the fitted recurrences do not predict the held-out symbols.

The discrete-log encoding uses 15 as a primitive root modulo 29. This is one motivated 28-symbol bijection, not an arbitrary alphabet-permutation search.

### 2. Binary LFSR on natural 5-bit symbol encodings

The same streams were encoded as five-bit symbols, in both MSB-first and LSB-first order. The nonzero stream was tested as raw residues, rank values 0–27, and discrete-log values 0–27.

Across the eight encodings:

- Prefix linear complexity is approximately half the training bit count.
- Held-out accuracy ranges from **50.06% to 50.67%**, against a 50% random-bit baseline.
- No encoding provides reproducible predictive power.

The small best-case excess is not treated as evidence: eight related encodings were examined, and no independent prediction or key recovery follows from it.

### 3. Exhaustive first-order LCG search

All multiplier/increment pairs were checked over the complete sequences:

- Full differences modulo 29.
- Nonzero rank sequence modulo 28.
- Nonzero discrete-log sequence modulo 28.

**No exact first-order LCG fit exists** in any of the three cases.

## Conclusion and boundary

The observed first-difference stream is not explained by a low-complexity GF(29) LFSR, a natural five-bit binary LFSR, or a first-order LCG under the tested encodings. This is a scoped exclusion, not proof of a one-time pad, a cryptographic PRNG, or any particular cipher.

Crucially, these tests concern the **observed** \(D_i\). They do not test an unknown key stream \(K_i\) in a model such as \(D_i=P_i+K_i\pmod{29}\). A cryptographic or source-derived key could still make the observed differences appear high-complexity.

**Research decision:** do not open a generic LFSR/LCG/PRNG search branch unless a clue independently selects the generator, seed, or key source. The next useful breakthrough must supply key material or a reversible plaintext relation; merely renaming first differences as a 28-symbol stream does not advance decryption.
