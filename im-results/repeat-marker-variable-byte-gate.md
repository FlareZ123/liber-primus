# Original LP2 doublet-delimited byte packets: exact all-secret per-page obstruction

**Result (10 November 2026): a source-exact conditional exclusion, with an independently executed reversible positive control. No unknown LP2 plaintext, authentic key, full cipher mechanism, or final destination was recovered.** The statement concerns a variable-length binary transport model not covered by the earlier *fixed-width* 5n-digit/3n-byte rank tests.

## Proposed lossless model and all-key necessary condition

Use original LP2 physical rune-bearing pages 0–55, excluding rune-free p50, exactly as indexed in [the source corpus](../resources/liber-primus/lp2-corpus.json). The first rune of each page initializes a 29-valued predecessor state. Every subsequent immediately repeated ciphertext rune is a visible, nonconsuming **packet separator**. Each intervening sequence of \(L\) strictly nonrepeated ciphertext transitions carries a big-endian or little-endian \(L\)-digit base-28 integer representing **unrestricted** bytes. The natural maximum payload width is

\[
m(L)=\max\{m\in\mathbb Z_{\ge0}:256^m\le 28^L\}.
\]

The successor for digit \(d\in\{0,\ldots,27\}\) is an arbitrary secret one-to-one assignment of the 28 nonidentical output runes, conditioned on the *preceding printed ciphertext rune*. We grant **29 independent unknown successor permutations for every physical page**, vastly more freedom than a global cyclic alphabet. Rows must remain fixed *within that page*. There is no assumed plaintext language, source key, probability model, or need to solve these secret permutations.

The exact BigInt capacity condition on a packet integer \(V\) is \(0\le V<256^{m(L)}\). With big-endian digits, the most significant digit cannot exceed

\[
B_L=\left\lfloor\frac{256^{m(L)}-1}{28^{L-1}}\right\rfloor.
\]

When \(B_L=0\), the first output after the same predecessor rune must be the **unique rank-zero successor** of that predecessor. Under reversed digit significance, the *last* transition in each packet is instead forced to rank zero. The same zero forcing holds if the payload width is **any smaller nonnegative integer** than \(m(L)\). The proof permits every possible secret permutation; the contradiction is at the output-symbol identity level.

## Two independent contradictions in the original ciphertext

The original ciphertext contains **12,956** runes on **55** physical rune-bearing pages, exactly **86** repeated-rune separator events and therefore **141** page-scoped packets. Of these, **139** are nonempty, **2** are empty, and the 139 maximal-width packets would contain **7,637 unrestricted bytes**. Exactly **53** packets independently have \(B_L=0\).

| Interpretation | Physical page | Packet lengths and maximum byte widths | Two rank-zero transitions under the same predecessor |
| --- | ---: | --- | --- |
| Most significant digit first | **33** | \(L=151,m=90\) and \(L=31,m=18\) | **ᛞ→ᛇ** at local/global positions **1/7,961** and **ᛞ→ᛋ** at **183/8,143** |
| Most significant digit last | **42** | \(L=21,m=12\) and \(L=249,m=149\) | **ᛖ→ᚹ** at local/global terminal positions **21/10,165** and **ᛖ→ᚫ** at **271/10,415** |

Each row is already contradictory *within one physical page*. Two different successors cannot both be the unique rank-zero output from the same predecessor under a stationary page-local row permutation. Thus **neither digit orientation supports any key whatsoever**, even after granting a separately secret 29×28 table for each of the 55 pages. The page-33 and page-42 certificates are independent of the other 54 pages and of natural-language assumptions. No brute-force search or statistical threshold is involved.

## Independent implementation and synthetic inversion

[Standalone CommonJS reproducer](../sims/repeat_marker_variable_byte_gate.cjs), Node 22, uses the committed canonical original numeric corpus and asserts all packet counts, original witnesses, and exact integer inequalities. Its fresh synthetic positive control (seeds \`0x12003301\`, \`0x12003302\`) uses a concealed random cyclic 29-rune alphabet, uniform generated byte payloads, exactly the original page lengths and marker coordinates, and each of the two digit orientations. Each plant encodes all **7,637** source-layout bytes into 12,956 artificial ciphertext runes, independently decodes **7,637/7,637** exact bytes, and **re-encrypts every one of the 12,956 emitted runes** with the same secret order and original marker positions. The test was executed successfully through [manual Actions run 42855829487](https://github.com/FlareZ123/liber-primus/actions/runs/42855829487) (the older forward-only run is [42855455553](https://github.com/FlareZ123/liber-primus/actions/runs/42855455553)).

The plant demonstrates the codec is coherent and that ordinary valid packets pass the test. It does **not** identify an LP2 key, authenticate the byte-packet hypothesis, or prove anything about a genuinely encrypted binary payload.

## Scope and next decision

This eliminates the exact model in which the printed doublets are separators, all remaining glyphs are base28 predecessor-coded digits, each segment carries an unrestricted integral number of bytes, and predecessor rows stay fixed on each physical page. Changing rows **inside a page**, a separate per-packet salt or reset, explicit extra metadata, a restricted byte codebook, variable-length framing with a different numeric capacity contract, an encrypted intermediate, and other symbol/byte codings are separate untested mechanisms.

There is no source instruction establishing this byte framing. Further searches of secret stationary row permutations for this precise model are mathematically pointless. To revive the family as an actual decryption attempt, first obtain an independent manuscript or historical rule that provides packet-level state and predicts recoverable plaintext, rather than freely adding a new key after observing these two contradictions.
