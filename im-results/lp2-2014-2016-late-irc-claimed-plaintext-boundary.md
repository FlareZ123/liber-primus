Its date-stamped message counts are **38,008 / 162,874 / 144,109**. The later file's January 2016 page56/historical-hash finding was previously studied in [the separate Pastebin archive audit](2016-pastebin-irc-original-source-audit.md). The current scanner excludes explicit page 56/57 and the solved AN END passage. It does not claim to audit all linked files or every unworded allusion to a solution.

The targeted lexical screen yielded **688** same-message page/book/rune + solution-verb candidates, **34** matching stronger apparent direct-claim grammar; 25 higher-scoring lines plus separately selected full ±13-line contexts were retained in [passing original GitHub Actions run 43608652302](https://github.com/FlareZ123/liber-primus/actions/runs/43608652302). ## Original period-linked solver source, inspected as executable claims

A separately source-locked URL inventory in the same 2014–2016 exact-byte log found **1,069** source-context links to selected code/document hosts, **250 distinct URL strings**, in [successful CI 43609250218](https://github.com/FlareZ123/liber-primus/actions/runs/43609250218). The source filter keeps links with nearby rune/cipher/decoder vocabulary, so these are *candidate historical artifacts*, not 250 published solvers. It extends #881's May–August 2014 linked-operand recovery without retrying those links.

Two source-linked programs are immediately inspectable:

- **L262046, 15 January 2016:** [Be5haram/CICADA2K16/RuneSolver.py](https://github.com/Be5haram/CICADA2K16/blob/master/RuneSolver.py). This approximately 42 KB period workbench defines a full GP29 rune mapping and menu modes for additive stream/Vigenère, configurable **Alberti rotating-disk** shifts and word comparisons. It offers prime/Fibonacci/default streams, reversal, F handling and a custom alphabet. Most source page variables are *empty strings*, while a few retain printed **ciphertext** and p57's already-solved plaintext. Every significant proposed decode requires an interactive user choice; the file specifies **no accepted p0–55 plaintext**, fixed authentic key or page-specific successful parameters. Its menu is a record of live hypotheses, not a recovered Cicada decipherment.
- **L264768, 15 January 2016:** [resvolver/c1cada/repeatcrack.pl](https://github.com/resvolver/c1cada/blob/master/repeatcrack.pl). This script constructs orthographically normalized dictionary n-grams and nests 29-way key-letter loops to look for English word shapes. Its embedded runic examples are ciphertext and crib guesses. No source-selected key or complete original rune-to-plaintext example appears.

Other period-linked files have separable roles: [tevaum/lpt/data/liberprimus.js](https://github.com/tevaum/lpt/blob/master/data/liberprimus.js) (L302306, 23 February 2016) stores raw GP29 transcriptions, and the historical [rtkd/idkfa assets/docs/liber-primus-translation.txt](https://github.com/rtkd/idkfa/blob/master/assets/docs/liber-primus-translation.txt) (L283806, 27 January 2016) is not accessible at that exact present-day path. The IRC link alone does not establish that a file called “translation” contains recovered plaintext. The dated [AlexBoyle/CicadaDecoder source reference](https://github.com/AlexBoyle/CicadaDecoder/blob/master/src/Decrypter/Main.java) (L327318, 10 April 2016) also returns 404 today. Retrieval of such missing original code is a possible historical follow-up **only if it yields a frozen decoder and a checkable unknown-page prediction**.

This source acquisition is not authorial evidence for the 2016 workbench's freely configurable operations. Running its full menu on the original book without an independently selected input would reproduce old unconstrained key searches. The direct GP29 punctuation-sensitive one-step Alberti default was additionally read against original p0 and p32; its two additive directions remain uniform and unreadable, a limited exploratory screen rather than a broad cipher exclusion.
