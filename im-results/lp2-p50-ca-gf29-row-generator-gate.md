# Original 32×8 LP2 number table: compact row-generator gate

**Agent9, 17 November 2026. Evidence:** original-byte computational exclusion of two explicit finite compact-generator families. The 56 encrypted LP2 pages remain unsolved; no cipher key, newly decrypted rune, or destination was recovered.

## What clue makes this worth a bounded original test?

The source artifact across physical pp49–51 prints **256 two-character numeric cells in exactly 32 rows of eight**. Its base60-derived byte sequence is already image-audited against all 256 tokens and SHA-256 pinned as `3b9b07d9a26e6d55c432d94d2661fdff3c2b348daed06821f2bdb23184a4b290`. A contemporary technically minded solver could consider whether rows are **successive states of a small generating rule**. If so, recovering that rule plus the first row would reduce the apparent 256-byte table to compact, source-selected key material rather than requiring an arbitrary lookup table. This tests a different causal path from the documented row-order bitmap smoothness and eight-way exit-mask maze gates.

Two complete, simple families are frozen without key optimization against English. Neither is an instruction actually printed by Cicada. The signed 2016 message names numbers and direction, but does not prescribe cellular automata, arithmetic row recurrence, orientation or a ciphertext receiver.

## Binary interpretation: every elementary cellular automaton

Each original eight-byte row becomes **64 binary cells**. Consider all 256 possible radius-one Boolean rules with the immediate left/center/right bits as input, wrap horizontally within the row, and advance 31 times. Grant both vertical row directions and both bit orders inside each byte. For each layout compute all 1,984 output-bit predictions and score the *best among every possible local Boolean rule*. This is an exhaustive secret-rule search, not a sweep of handpicked rules.

| Original source layout | Best rule (Wolfram local rule index) | Matching next-row bits |
| --- | ---: | ---: |
| Printed rows, MSB-first | 194 | **1,045/1,984** |
| Printed rows, LSB-first | 136 | **1,039/1,984** |
| Reverse rows, MSB-first | 152 | **1,049/1,984** |
| Reverse rows, LSB-first | 198 | **1,050/1,984** |

A true deterministic rule must predict **1,984/1,984**, regardless of its 256-way identity. The original has **934–945 incorrect bits** in every tested direction, after granting the entire rule family. A genuine Rule-30 positive plant, initialized using the actual first 64 source bits and propagated 31 rows, is recovered as exactly Rule30 with **1,984/1,984**. All eight 3-bit neighborhoods occur, so rule identification is substantive.

As a distribution check rather than a success criterion, a deterministic **10,000 row-permutation null** preserves all authentic 32 eight-byte rows and hence every source bit, but shuffles their order using xorshift32 seed 123456789. Giving every permutation the *same* best-of-256-rule advantage produces mean **1,039.8001** matches in printed/MSB orientation; **3,425/10,000** null permutations score at least the original 1,045. The original exact-rule failure is already decisive, regardless of this nonexceptional descriptive null.

## Arithmetic interpretation: all secret GF29 affine three-neighbor row rules

The source has a separately evidenced GP29 residue register, `B mod29`, because the full table polynomial is divisible by the two independently recorded 2013 BASE29 and p39-red factors. Its complementary high base29 digit `floor(B/29)` is also source-defined. Treat either register as 32×8 source rows, allow either vertical reading direction, and grant **every** four-coefficient secret GF29 recurrence

`next[t,c] = a*prev[t,(c−1) mod8] + b*prev[t,c] + d*prev[t,(c+1) mod8] + e (mod29)`.

The first four linearly independent original row-transition equations determine **all four unknown coefficients** over GF29. Predict the remaining positions without language scoring or a guessed key. A correct model must reproduce all **248** successive-row cell values; no source observation is dropped.

The original first mismatches occur at equation indices **4, 4, 4 and 3**. A synthetic 32×8 positive constructed from the source first-row residues with hidden coefficients **(3,26,24,11)** reproduces **248/248** and uniquely recovers those coefficients. Thus the model is demonstrably identifiable on data actually generated by the proposed mechanism.

## Decision

**Retire the printed 32×8 table as the successive states of a fixed elementary 64-bit cellular-automaton rule or a stationary first-order nearest-neighbor affine GF29 row generator**, under the precise physical/source registers and directions above. The full secret local rule or affine coefficient key was granted, and neither class comes close to generating the original numeric object. Recovering a genuine compact generator would have been useful for a new key schedule, but **this experiment delivers no such generator and decrypts none of the 12,956 unknown LP2 runes**.

This does not disprove a different, source-authored generator, a keyed multistage transform, word-addressed table semantics, a two-dimensional navigation rule, or the genuine previously established H×G polynomial divisibility. The existing matrix/bitmap and direct row recurrence tests remain separate evidence. Without a newly recognized original operator, extending this into arbitrary nonlinear generators is not justified.
