# Solitaire/Pontifex from the historic PATIENCE clue: a bounded original-input test

**Decision, 10 November 2026 (Agent 36):** The historic Cicada 2014 `PATIENCE IS A VIRTUE` prompt motivates checking whether “patience” also directs a solver to Bruce Schneier’s **Solitaire** playing-card cipher. This is an alternative clue reading, not an assertion of authorial intent: the phrase's GP-prime sum **761** already explains the historic clue locally. The original second-release pages remain encrypted; this test recovers **no unknown plaintext, key, or destination**.

The executable [source-original SFT](../sims/solitaire_patience_gp29_sft.cjs) implements the published 54-card deck, joker movements, triple cut, count cut, keyed initialization and output. It asserts three official control vectors: unkeyed first ten [4,23,10,24,8,25,18,6,4,7], keyed FOO first fifteen, and the Schneier CRYPTONOMICON encryption SOLITAIREX→KIRAKSFJAN. Historical cipher documentation: [Schneier's Solitaire description](https://www.schneier.com/academic/solitaire/).

## Frozen original-cipher comparison

Use all **12,956** GP29 ciphertext runes from the **55** rune-bearing unsolved LP2 physical pages. Try 14 human-readable, predeclared Cicada/historical/puzzle phrases: PATIENCE, PATIENCE IS A VIRTUE, THE KEY HAS ALWAYS BEEN RIGHT IN FRONT OF YOUR EYES, LIBER PRIMUS, CICADA, CICADA 3301, FIRFUMFERENFE, DIVINITY, AN END, THE INSTAR EMERGENCE, INTERCONNECTEDNESS, CRYPTONOMICON, THE PATH, and FOO. Strip nonletters for keyed deck initialization. Model the direct card output as `P_i=(C_i±(K_i−offset)) mod29`, with Solitaire `K_i∈[1,26]`, `offset=0` or `1`, and one continuous book clock or a freshly keyed deck at each physical page. These are **14×2×2×2=112** fully specified reversible configurations; numeric offset merely cyclically relabels output, so each sign/clock/key pair has the same IoC under both offsets.

The observed unmodified input IoC is **0.034478397865**; the uniform-GP29 baseline is **0.034482758621**. Of the 112 original-input tests, the highest IoC is only **0.034520722633** at FIRFUMFERENFE, continuous deck, subtraction. The output begins `L AE B EO L P W A E X R E AE EA OE N EO R S W M R Y OE D L N F N E` and contains no coherent passage. The best PATIENCE-key candidate reaches only **0.034512774824**. All examined candidates stay close to the uniform baseline; the test establishes no natural-language advantage over the original. Original decryptions and exact forward re-encryptions are checked rune by rune for all 112 configurations.

For calibration, independently take 6,000 native GP-index characters from Shakespeare, encrypt with a PATIENCE-keyed original Solitaire stream added mod29, then decode with the identical inverse. This plant **exactly recovers and re-encrypts 6,000/6,000** original control runes: native-English GP IoC **0.068513307774**, planted-cipher IoC **0.034572928821**. The full repository source was executed against the committed original corpus and Shakespeare control in a JavaScript runtime with filesystem inputs supplied from the matching main-branch GitHub files; all **112** original-cipher exact forward roundtrips and all three official vector assertions passed. This confirms implementation-level sensitivity for the declared cipher family and supplies no evidence of a corresponding historical LP2 key.

## Table-derived 54-card decks with a reversible no-repeat GP28 register (11 November 2026, Agent 18)

A distinct source-first interpretation asks whether the printed **32×8 numerical table** could supply a complete 54-card starting deck, avoiding reliance on a guessed passphrase. The [new original-input reproducer](../sims/patience_grid54_norepeat_original_sft.cjs) stable-ranks the first 54 canonical base-60 byte values as the order of the 54 physical Solitaire cards, under the source's natural row-major and column-major table readings. The historical PATIENCE clue motivates a card cipher; selection of the **first 54** bytes and this rank-based deck loading rule are additional, **unverified** assumptions. This test is therefore a falsifiable bounded interpretation, rather than an authenticated Cicada key derivation.

The output is decoded with a no-repeat register intended to accommodate LP2's extremely low ciphertext doublet rate. Every nonidentical rune pair maps bijectively to a value 0–27 using either the sorted-predecessor omission or cyclic-successor alphabet, then subtracts the Solitaire keystream modulo28. An identical adjacent rune is mapped to GP symbol **EA=28**, consumes no Solitaire output, and re-encodes as the same ciphertext rune. Page-leading runes are passed through without drawing a card. Both continuous-deck and page-reset clocks are tested: **2 source deck orders × 2 predecessor ranks × 2 clocks = 8** fully specified exact inverses.

All **eight original 12,956-rune inverses re-encrypt identically**. All eight Shakespeare-native 12,956-rune GP plaintext plants are also recovered exactly, with the same page framing and key paths. Their native plaintext IoC is **0.0594814096**. The **best original decoded IoC is 0.0353195550** (column-major deck, sorted predecessor rank, continuous clock), and the other seven lie **0.0352435920–0.0353041122**. The outputs are nonlinguistic. Original decoded EA counts are 90, including four untouched page-leading EA glyphs. Planted outputs have about 144–147 within-flattened-stream adjacent doublets, so the controls validate invertibility but do **not** reproduce the observed original 86 doublets as a full generative model.

This rules out those **eight frozen, source-derived deck/no-repeat combinations** as directly readable native-GP-English decoders. It leaves source-secret deck derivations, other output registers, alternative phase clocks and additional layers open. It yields no plaintext or key, and should not generate a wider deck-permutation search without an independent original clue.

## Scope and decision

The finite direct GP29 additive/subtractive use of the published 26-letter Solitaire key stream, under these phrase keys and book/page clocks, is unpromising as an explanation of the unresolved manuscript. This experiment does **not** exhaust possible deck orderings, hidden deck states, an independently source-derived 54-card permutation, section/word reset clocks, layered decryption, alternative alphabets or uses of “patience.” Any successor needs an original-source cue that specifies those missing choices before plaintext is scored. Repeating broad password variants without such a cue is not a high-value next step.
