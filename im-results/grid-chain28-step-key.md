# LP2 28-state chain-step cipher with eight printed AES keys

**Agent 5, 10 November 2026. Intermediate negative, with independent exact key/plaintext recovery on a planted control. No original plaintext or key recovered.**

The manuscript contains 86 immediate same-rune steps. A plausible candidate transformation uses a 28-symbol keyed increment rather than direct rune substitution. Under the explicitly conjectured rule, plaintext GP rune index 28 (ᛠ, EA) emits zero step. Every other plaintext symbol p in 0..27 emits d=1+((p+k) mod28); the ciphertext is C[i]=(C[i-1]+d) mod29. A known key supplies the exact inverse p=(((C[i]-C[i-1]) mod29)-1-k) mod28. Both signs and both possible key-consumption policies for zero steps are searched. This special-EA rule is **a proposed model, not a known Cicada mechanism**.

The 32×8 base-60 byte table on physical LP2 pages 49–51 supplies eight exact 256-bit vertical-column AES keys (resources/liber-primus/base60-grid.json). The candidate resets at eight merged substantive cipher sections of lengths **729,1145,1729,1903,1021,1524,1589,3316**. All **120** global variants combine five IVs (zero and four independently defined Fibonacci-square row/spiral choices), forward/reversed keys, mod28/scaled28/unbiased-rejection byte conversion, two arithmetic signs and two doublet key-consumption policies. For each variant, maximize a GP-English unigram log-likelihood over all distinct eight-column-to-eight-section assignments using a 256-subset exact dynamic program. English rune priors are trained only on the first 240,000 characters of a fixed Shakespeare fixture.

**Original LP2 result:** 55 rune-bearing pages, 12,956 runes; **12,862 nonzero steps between the eight group initials**. Best of all configurations uses zero IV, reversed key bytes, unbiased rejection mapping, additive sign + and *no key consumption* on zero steps. Optimal zero-based column assignment is **[5,1,2,4,7,0,3,6]**. Its decoded English-vs-uniform log-likelihood is **−10,650.104115**, or **−0.8280286204 per nonzero step**, decisively unlike natural GP-English under this source model. The other best mode maxima remain negative (−0.82999 through −0.83729). The fitted assignment is an optimizer state, **not key recovery**. No familywise p-value is claimed.

**Blind positive recovery:** Generate an independent 2,896-word GP-English manuscript from the last 60,000 Shakespeare fixture characters, matching *every* LP2 word length (three words require recorded training fallback). Encrypt all 12,956 symbols with the actual printed grid column keys, the spiral prime-complement IV, unbiased byte rejection, negative arithmetic sign, zero steps consuming key draws, and the identity column assignment; 113 plaintext EA instances emit zero steps. The same 120-mode search, without key parameters, selects **all actual global settings and all eight original columns at rank 1**, and the exact inverse recovers **12,948 / 12,948 encoded plaintext rune values**, excluding only group-initial state seeds. Its score is **+0.3876729068 per nonzero step**; the runner-up falls to **−0.8312577773**.

The source-derived grid keys therefore **do not provide evidence for this explicit keyed 28-state chain model**. This finite result does not exclude a distinct secret key/KDF, different IV, non-GP plaintext, changed ciphertext alphabet, or other cryptographic layers. Another arbitrary key derivation would demand a new independent manuscript constraint.
