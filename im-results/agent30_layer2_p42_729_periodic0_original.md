# LP2 original p42–44: powered 729-rune historical two-stage periodic inverse

**Decision (17 November 2026):** The unchanged historical GP29 anti-repeat-LAST outer-key / unknown-period Vigenere inner-key receiver produces **zero independently verified whole-window plaintext candidates** on a newly source-anchored 729-rune interval beginning at physical p42, under **ordinary F consumption**. The later matched-null, powered literal-F-bypass experiment also completed with zero original candidates. An equally sized source-independent 20-stream randomized-key control also produces zero. Both independently planted 729-rune GP29 English controls at periods six and nine passed on precisely the same whole-window detector and plaintext verifier. This is a negative for the bounded source/key/clock family and this original window, **not a claimed general solution, nor an exclusion of longer keys, other untested F-handling rules, or other original plaintexts**.

## Original-source selection and exact input

Use canonical `resources/liber-primus/lp2-corpus.json`: all 272 GP29 rune indices from physical p42, all 274 from p43, then exactly the first 183 from p44, in original printed order. The resulting `n=729` input is one contiguous interval of the physical p40–53 chapter. Previous ciphertext state is the actual final GP29 rune of p41, **11**. The p42 prefix is byte-identical to the independently prepared original 272-rune p42 test, but the longer interval fixes the short-window length weakness of the unknown-period detector. The first 729 original GP29 index bytes have SHA-256 **`728115bbc13b381be31f0ba93dd193e3108e2af9534a97ffdb000011d6020b6e`**. [Original-source window builder](../sims/agent30_p42_729_window_source_sft.cjs) requires this digest, original page lengths, and preceding-state value and emits the exact historical reference `W/R/L` window format. This is independent of the original 729-rune p0–2 opening and the first300 runes of the parent p40–55 source segment.

The historical reference implementation is pinned to [pnotisdev/cicada3301@15200c67abee106913ba01ff504c5b6e88d16cc7](https://github.com/pnotisdev/cicada3301/tree/15200c67abee106913ba01ff504c5b6e88d16cc7), with only its previously regression-proven `u8→u16` periodic column counter width change. The exact prepared source and binary are preserved in [original source run 44062412799 artifact 14318552323](https://github.com/FlareZ123/liber-primus/actions/runs/44062412799/artifacts/14318552323). The source's 20 historically selected independent number-stream key records are unchanged, `core20.ksb`; matched null `null_core20.ksb` is deterministically created from independent uniformly random GP29 streams, preserving each record length and count (seed **3301002**).

The source-pinned original screen options were exactly: `mode=periodic ms=2:14 litf=0 abort=150:2.5 n=729 beam=16 mults=1,28 models=0,1 threads=4`, same on original and null. The native `verify.py` recomputed the top 20 candidate decodes across **all 729 original runes** and 20 alternative key offsets per hit: candidate requires whole-window GP-English log score `≥+2.0/rune` and `≥ matched-offset null maximum +5.0`. A high short-screen statistic alone is explicitly **not** a decryption.

## Independently generated source-native controls

The independent [pinned `plant_ref.py`](https://github.com/pnotisdev/cicada3301/blob/15200c67abee106913ba01ff504c5b6e88d16cc7/work/layer2/plant_ref.py) builds exact 729-rune encryptions of the source's held-out GP-native English: initial 398 runes from `eng0` plus 331 from `eng1`. The controls retain all actual original `core20` key tapes and native decoder options; the injected source stream is `primes`.

- **m=6, ordinary F**, keyword GP indices `[7,18,4,3,16,24]`, true key offset2000, phase2, sign28, Atbash1, outer multiplier28/model1. The original model's correct 729-rune plant scores **+38.3207**, authentic source offset/period are recovered and native whole-window verification passes.
- **m=9, ordinary F**, keyword `[4,21,2,17,8,12,5,23,9]`, true key offset5000, phase4, sign1, Atbash0, multiplier1/model0. True period/stream/offset are recovered, original screen score **+26.8462**; independent native whole-window verification passes.

Each control was generated under the original reference's default `previous=-1` and then set to `previous=11`, the new passage's authentic previous-ciphertext rune, **only after checking the planted first emitted ciphertext rune (17 for m6, 8 for m9) differs from both possible states**. Therefore the generator's no-repeat collision handling did not fire on either path's first emission; the ciphertext and all subsequent states are identical under the new authentic previous-state header. No cipher parameters, scoring thresholds, original key family or historical code were tuned to the original test.

These two positive controls establish **detectability at these two independent long-key shapes**, not proven statistical power for every period 2–14 or the separate plaintext-F-skip path. Original-run [controls artifact 14318953349](https://github.com/FlareZ123/liber-primus/actions/runs/44062412799/artifacts/14318953349) independently confirms all four original 729-rune m6/m9 × F-off/on positives but fails three shorter272-rune controls; do not treat 272-rune periodic branches as negatives.
