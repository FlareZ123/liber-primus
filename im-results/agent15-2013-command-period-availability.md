# March 2013 command period-availability gate (#2556)

## Result

**Positive for the period-visible protocol semantics; corroborated but not independently date-pinned for the exact organizer command sequence; negative for public pre-LP2 availability of the recovered participant-specific transcript and DH values.** This narrows the historical prior, without selecting an original LP2 decoder.

1. A public [single-revision Gist](https://gist.github.com/navinpai/7837596) explicitly displays creation **7 December 2013, 05:24**, and contains the TCP specification copied from Pastebin CrRvGrkT plus Python participant implementation. Its README raw path identifies blob revision 98b383923095465ba02432ffc6be06c4a877b2b9. The rendered Gist has one revision; raw and revision-history URLs did not resolve through the web tool, so no new byte hash is asserted. This is independent evidence of public pre-May-2014 command semantics. The authenticated source is already preserved in [2013-tcp-server-signed-source.md](../resources/external/2013-tcp-server-signed-source.md), including the January 2013 signed specification and contemporary Twisted correspondence.
2. The Gist implementation specifies participant-side selection of both base and secret via random.randint, returns the base and public exponent result, and derives DATA from the received client public value. It reads KOAN from a local text file. BASE29 is deterministic; NEXT receives and stores organizer-sent text. Its logging format (filename pattern, UTC millisecond timestamp, sent/received direction and repr, base/secret selection message) is consistent with the recovered clientlog's implementation family. This comparison establishes semantics, not participant identity or shared-key intent.
3. [Fandom NEWS! TCP Servers had been tested!](https://uncovering-cicada.fandom.com/wiki/NEWS%21_TCP_Servers_had_been_tested%21) reports a **different** March 3 server log: BASE29 1033 at 10:59:10; four KOAN calls; DH 3301 three times at 10:59:28, 10:59:56, 11:00:29; NEXT 11:00:58. [Archived Menu](https://uncovering-cicada.fandom.com/wiki/Archived_Menu) associates this news entry with March 3 2013, and indexed publication metadata is consistent. It is corroboration of organizer operand selection, but the original wiki revision and API endpoints were unavailable, so its exact public content as of May 2014 is not independently pinned. The same log is reproduced in [neuroretransmit's later archive](https://github.com/neuroretransmit/cicada/blob/main/2013/007-fourth-onion/README.md); this reproduction is not a second contemporary witness.
4. Bounded exact-phrase web searches for BASE29 1033, DH 3301 with KOAN, 2757 1264, DATA 1067, and the exact filename, with a pre-May-2014 cutoff and then without, found no independent dated copy of the specific participant log. The earliest established archive appearance remains the 2024 commit documented in [#2534's extraction report](agent15-2013-clientlog-authenticated-next-response.md). A signed 2013 NEXT payload authenticates that payload, not the surrounding unsigned conversation or its publication date.

The command semantics were accessible to a capable 2014 solver; the exact numeric exchange cannot be used as a period-public key. The corroborating second log actually makes the proposed fixed five-stage program weaker: it contains three DH requests, with no separate DATA command, rather than a single fixed DH stage. #2557's missing-private-state result stands, and #2561 needs an independent original unit-to-command binding. No original plaintext recovered. Stop the bounded archive search.
