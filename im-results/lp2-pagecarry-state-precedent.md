# LP2 page-carry state: solved-page precedent, but no LP2 key selector

**Scope:** Director Issue #1391. This report separates a source-derived state-transition precedent from any claim about the unsolved LP2 cipher.

## Finding

Two solved Liber Primus sections provide a consistent creator precedent: a reversible key stream is continuous across physical page boundaries, rather than restarting merely because the page changes.

- **Completed-word edge:** the 515-rune WELCOME/WISDOM section is represented by two source page segments of 251 and 264 runes. The local transcription shows the first segment ending after a completed word. The independent Wulfic canonical test record documents one continuous DIVINITY stream over all 515 runes, not a page-local restart.
- **Open-word edge:** the 319-rune A KOAN section is represented by two source page segments of 226 and 93 runes. With the source key FIRFUMFERENFE and the documented F-interrupter condition (skip only when both the ciphertext rune and current key rune are F, without consuming the key), the last four runes of the first segment and first three of the second decrypt to **STOP | PED**. The word STOPPED therefore crosses the physical page edge. The key cursor is 224 after the first segment (phase 3 modulo 13). Resetting it at the page edge changes the second fragment to PNN and fails the word.

This is an empirical creator precedent from solved material, not an LP2-specific instruction. It supports treating a physical page boundary as layout rather than as an implicit cipher reset. It also shows the key is not reset at ordinary word boundaries in the solved sections. It does **not** establish that LP2 uses either LP1 key.

## Exact LP2 carry map

The first 55 text-bearing segments of resources/lp2-transcription.txt match the 55 nonempty pages in resources/liber-primus/lp2-corpus.json exactly: 12,956 rune positions. The rune-free table page 50 is omitted from the text-bearing sequence and restored in physical page numbering below.

There are 54 text-bearing page edges:
- 32 edges carry an unfinished word into the next page;
- 22 edges occur after a completed word;
- the 32 carried suffixes contain 83 rune positions in total.

## Source-native state-transition plant

The script sims/lp2_pagecarry_state_precedent_sft.cjs reproduces the page map, the LP1 STOPPED seam control, and a deterministic synthetic plant.

For the plant only, the original 12,956 LP2 rune indices are treated as known plaintext and encrypted with the solved LP1 FIRFUMFERENFE state machine. This is a mechanical control on the **actual LP2 page lengths and 32 carry positions**, not a proposed decryption of LP2.

| Decoder policy | Rune errors | Errors in 83 carried suffix runes |
|---|---:|---:|
| Continuous key state across pages | 0 | 0 |
| Reset at every page edge | 7,862 | 46 |
| Reset only after completed-word page edges | 6,771 | 35 |

The plant demonstrates that the competing page-reset policies have materially different, reproducible effects on the source's real page geometry. It does not show that the original LP2 ciphertext was generated by this key.

## Decision for LP2

The strongest source-derived default is: **do not reset a selected reversible key state at a physical page edge or ordinary word boundary; carry it continuously through the section, with only explicitly selected interrupters changing consumption.** The 32 open-word edges and 22 completed-word edges are both covered by the solved-page precedent.

However, this does not supply an LP2 key, key-generation rule, or source-selected cipher operation. The 2016 statement that words are the map does not itself specify a key reset rule. Existing repository exclusions of ordinary periodic keys and the p56 prime/totient clock remain in force. No original LP2 plaintext was recovered here, and the Issue #1391 threshold of at least 150 coherent original runes plus exact forward emission was **not** met.

**Conclusion:** close this branch as *missing LP2 key selector*, preserving the continuous-state precedent as a prior for a future independently selected mechanism. Do not continue tuning page-reset variants or reinterpret the 32 count as a cipher key.
