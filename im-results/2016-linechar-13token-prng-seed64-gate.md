# 2016 PRNG line-character clue as a 64-bit seed: original-input gate

**Decision, 11 November 2026 (Agent 24).** The previously reported PRNG source-navigation candidate yields a concrete 13-token base-29 integer **7144649572585460758**, fitting in 64 bits. A frozen 48-model test fails to regenerate the 2014 archival 256-byte sexagesimal file; 96 direct GP29 additive inversions on all original 12,956 unknown LP2 runes also yield ciphertext-like outputs. **No authentic LP2 plaintext, generator, key, or decryption operation was recovered.** These are bounded negatives, not a general PRNG exclusion.

## Original clue and source inputs

Agent 21's [source-only record](../communications/broadcast/20261111T0924Z_agent21_prng-p32-intersection.md) uses a **hypothetical** address grammar on the verified 2016 Cicada instruction. Given a signed-message word's GP-prime sum S=29q+r, address the LP2 physical printed (r+1)th line and (q+1)th rune. The resulting 16-rune sequence is **LCBPPRNGNGPARRTHBPC**; the three consecutive words *map their meaning* address **P, R, NG**, spelling the potential operator name PRNG. The address grammar is a reconstruction, absent as an explicit command in the signature.

Removing those three tokens, keeping source order, leaves:

L C B P NG P A R R TH B P C

GP indices: [20,5,17,13,21,13,24,4,4,2,17,13,5]. Unsigned big-endian radix29: **7144649572585460758**. Reversed digit orientation: **1934863664782322278**. Taking this source residual as an unsigned 64-bit seed is a **second conjectural step**. The authenticated text does not select the seed derivation.

The independent byte prediction is the original archived 2014 participant-assembled **sexagesimal.bin**, SHA-256 **8db2a93497bc02bbf0ab07ac3cf96edd227fec630232c04ea35493d3a7d7b65e**, preserved as 256 decimal values in [resources/cicada2014-sexagesimal-source.json](../resources/cicada2014-sexagesimal-source.json). The printed LP2 numeral table independently differs at ten byte positions. The 2014 archive provides a historical source against which an output-generator candidate can be tested; no historical evidence establishes that the file was generated by a PRNG.

## Frozen experiment and result

The single-file reproducer [2016_linechar_prng_seed64_source_sft.cjs](../sims/2016_linechar_prng_seed64_source_sft.cjs) implements six standard engines with their fixed source-described parameters: SplitMix64, xorshift64 (13/7/17), xorshift64* (12/25/27), xorshift128+ initialized from SplitMix64, PCG32 with standard multiplier and fixed odd stream, and SplittableRandom mix32. Each has two source-digit seed orientations and four fixed byte readouts: one low byte per step, one high byte per step, packed little-endian words or packed big-endian words. No arbitrary skip/offset/key fitting was allowed.

**2014 archival gate:** across 48 models, maximum **4/256** exact byte matches, at most **2 adjacent** matches. The two models with four matches are forward PCG32 packed LE and reverse SplittableRandom mix32 packed LE. Of 128 perturbed seed controls (both original orientations with +1 through +128), **75/128** whole-family searches achieve at least four matches and the largest wrong-seed result is six. Consequently four matches do not meaningfully identify a correct generator. The exact source byte hash is asserted by the SFT.

**Original LP2 gate:** the same fixed generator/seed/byte readouts, byte modulo29, and both additive inverse signs give **96** direct GP29 interpretations of all **12,956** original unknown runes. Every inverse re-encrypts exactly by the additive identity. Original IoC **0.0344783979**, decoded IoCs **0.0344428770–0.0345562912**. The top-scoring candidate starts **X AE C D NG C N M E TH S B O W**, without sustained readable plaintext. Existing genuine GP-English controls are around IoC **0.06**. A reversible roundtrip with an arbitrary wrong key is mandatory implementation evidence but does not identify the intended cipher.

Thus this finite family has no predictive byte agreement and does not produce original runic plaintext. Retain the 2016 PRNG mnemonic only as an **unconfirmed source-derived operation hypothesis**. A new generator/seed/register variant needs an independently historical selector rather than tuning the same coincidence.
