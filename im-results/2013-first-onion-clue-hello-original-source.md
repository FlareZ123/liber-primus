# First-onion CLUE and HELLO: dated sources, complete signed reply, and exact IRC witness

**Decision (18 November 2026).** The contemporary 7 January 2013 participant IRC HELLO hexdump is an exact **936-byte prefix** of the already preserved **996-byte complete PGP clearsigned HELLO object**. Its previously missing 60 bytes are only the ending of the signature armor and delimiter. The signed visible instructions already end inside the 936-byte witness: the second-onion address `xsxnaksict6egxkq.onion`, “Good luck,” and “3301.” There is no additional HELLO text, LP2 key, or decoding opcode in this recovered continuation. This is a **historical source reconstruction**, not any LP2 decryption.

## Independent source-bearing records

- The contemporary first-onion HELLO [Pastebin `uCTgE2KA`](https://pastebin.com/raw/uCTgE2KA) has a 3,560-byte hexadecimal display, SHA-256 `e1d9e42fd8314fe6db9e1ca8b3e9a0db8658f4cbc4d07fed7c8cc742a158dfce`, display creation **7 January 2013, 10:33:52 AM CDT**. Its decoded message is preserved as [`resources/historical/cicada2013-first-onion-hello.asc`](../resources/historical/cicada2013-first-onion-hello.asc), 996 bytes, Git blob `867f15cf3da05d75ff5b1450b571429c1419f656`; a complete copy was already in this repository before issue #1487.
- The separate 2013 first-onion CLUE [Pastebin `tbbZd5vy`](https://pastebin.com/raw/tbbZd5vy), displayed **8 January 2013, 02:42:47 AM CDT**, has a 2,189-byte response, SHA-256 `ad6fecfb70f5cae21fac629f75abc531a5e3b511968e6b842ae272fe1a1a5818`, beginning “Here is a clue,” followed by sixteen 65-byte hex lines and the printed instruction `Offset: 0, Skip: 0, Col: 65, Line: 16.` The HELLO dump similarly ends `Offset: 3301, Skip: 0, Col: 65, Line: 16.` Both first-hand Pastebin responses were recovered in [Windows source CI 43317744153](https://github.com/FlareZ123/liber-primus/actions/runs/43317744153).
- A *distinct*, contemporaneously timestamped participant [IRC log XQ9rJSad](https://pastebin.com/XQ9rJSad), pinned in the [2013 archive at commit `f0f03ed`](https://github.com/cicada-solvers/The-Complete-Cicada3301-Archive/blob/f0f03edcb029e94b519efcacf1bf2511353e17c2/2013/additional%20docs/logs/all%20cosmos%20posts%20from%207th%20on%20the%20761%20song%20-%20full%20log.txt), Git blob SHA-1 `2d865faeec179d6b5984643d8b2af7efa3269f73` (399,787 UTF-8 bytes; 5,179 lines), records `hello` hexdump lines 3669–3688. All complete pairs yield **936 bytes**, identical to offsets 0–935 of the complete archived message, with no mismatching byte. The IRC line ends inside the signature; this witness alone cannot verify that signature.

## Deterministic continuation and limitation

The exact remaining **60 bytes**, at offsets 936–995, are `uyO6\nZvybzp4s4SzRjkk9sMM6\n=WYVO\n-----END PGP SIGNATURE-----\n`. There is **no material after the signature terminator** in the 996-byte archived copy. This closes the proposed missing-HELLO-instruction lead from issue #1487: the first-onion step is a historical navigation to the second onion, whose “Patience is a virtue” page is independently described in the same 2013 chat. It is not a 2014 Liber Primus ciphertext operation.

The independent IRC prefix also contains *all six* nonempty all-space lines `[5,3,2,2,3,5]` in the full archive. Thus the earlier claim that there was **no independent contemporary witness for the spaces** is superseded; see the [reconciled whitespace study](2013-first-onion-hello-hex-whitespace-source-gate.md). PGP cleartext canonicalization does not sign trailing whitespace, so the match supports its presence in a period participant's copy without proving that Cicada intentionally selected its pattern.

The complete PGP file and public key are available under `resources/historical/` and `resources/control/`, respectively.
