# Plaintext-predecessor-selected repeat escape: exact inverse gates

## Decision

No unknown LP2 plaintext or authenticated key. A distinct reversible family permits a changing escape rune selected by the previous **plaintext** rune, rather than a fixed global escape or a ciphertext-predecessor row. Its repeat-mask-only receiver rejects every full-length contiguous window of three pinned source-native literary donors, including a relaxation to an arbitrary stationary predicate of adjacent plaintext pairs. The short opening and terminal survivors are all rejected when arbitrary period-8/13 rank bijections are granted. A separate full-book concentration theorem excludes every such period-8/13 rank-map receiver for the finite native donor histogram register, even without assuming the plaintext escape law is stationary. Finally the p15 source spiral, used directly as a period-16 rank-shift vector, has an exact relaxed original decoding upper bound below all held native controls.

The results narrow this architecture, rather than authenticating a replacement. An arbitrarily changing rank key, unfamiliar plaintext, different output ordering, other clock, or separate chapter maps are outside the corresponding exclusions. No source independently selects the predecessor-conditioned escape law.

## Mechanism and repeat-only inverse

For GP29 values P and C, let e_i=f(P_(i-1)) be an arbitrary secret 29→29 function. If P_i=e_i, emit C_i=C_(i-1); otherwise remove e_i from the canonical ordered GP29 plaintext alphabet, form rank x=P_i−[P_i>e_i], and apply any invertible 28-rank map before selecting one of the 28 ciphertext values unequal to C_(i-1). With f and the rank maps known, the inverse is causal and lossless. Physical-page first runes are unconstrained in the original tests; plants copy the first plaintext rune as a public IV. No printed word boundary is used.

For a proposed aligned plaintext, each repeated ciphertext edge forces f(P_(i-1))=P_i; every nonrepeat edge excludes that pair. Intersect the 29 exact row domains. The relaxed arbitrary-predicate lower bound is Σ_ab min(h_ab,n_ab−h_ab), where h is the count of observed repeats mapped to that plaintext pair and n its total eligible count. For the one-label-per-row law, relaxing to permit no escape on a row gives R−Σ_a max(0,max_b(2h_ab−n_ab)). Zero relaxed error is sufficient only if every remaining unforced row has an absent successor. A rolling pair histogram and sparse observed repeat mask exhaust all contiguous windows; physical-page seam edges are omitted.

Original full tape 12,956 runes, 86 repeated edges, 54 omitted internal page seams, 55 IV positions. Three source-native donors (Shakespeare, Emerson, Gibran) have 217,106 / 306,851 / 47,629 runes after Gutenberg-header removal and source-attested ING/IO handling. Across **532,721** full-length alignments, zero exact functions and zero arbitrary stationary pair predicates survive. Minimum arbitrary-predicate errors 80/81/81; one-per-row relaxed minima 80/81/81. This is a finite contiguous-reuse rejection, not a theorem excluding new plaintext. Seven of nine physical chapter scopes have zero exact candidate functions even with private chapter f. Opening p0–2 has 70/94/11 (=175) and terminal p54–55 has 5,362/7,208/984 (=13,554) survivors. The sole Emerson p3–7 arbitrary-predicate survivor violates the one-label-per-row condition.

## Arbitrary period-8/13 rank maps

For each of the 175+13,554 exact opening/terminal mask survivors, grant an arbitrary independent permutation of all 28 nonrepeat ranks for each phase. Two period lengths (authentic LP1 8/13), page-reset or carried scope clock, consume-all or hold-on-repeat, circular or sorted exclusion ranks give 16 frozen variants. On a nonrepeat edge, the plaintext label b can correspond only to rank b−1 or b, and the exact f-domain for its predecessor may remove one. Intersect inverse-rank domains for each observed output rank in each phase; enforce perfect matching per phase. This is a necessary relaxation of global f consistency, hence any failure is exact. All **219,664** candidate×variant cases fail; longest processed nonrepeat prefix 77 opening, 70 terminal. No expensive key fit is justified.

Three independent hidden permutation controls under matched book geometry have exact 12,956-rune replay, retain every true rank assignment, and force 218/224, 347/364, 336/364 individual rank-map entries. Other entries are not claimed recovered; controls do not establish an original cipher. Their repeat counts are 67/40/29.

### Stronger all-key concentration constraint

The deletion-rank map sends any single plaintext symbol to at most two possible ranks. Consequently, even if the escape varies arbitrarily per event and the secret plaintext deletion order is arbitrary per phase, the total plaintext count of that symbol is at most the sum of the two largest observed nonrepeat-rank counts in each phase, plus all repeat positions and all IVs. This bound does not need the donor's original sequence or f consistency. More generally for a fixed canonical deletion order and subset S, the possible ranks are the edges adjacent to S in the 29-vertex path; use that many largest counts per phase. A small path DP maximizes the donor count over all subsets with each neighborhood size. The original singleton gate already excludes all windows, so no full-subset original scan is needed.

For 16 frozen period/clock/rank variants on the entire original book, the all-key singleton caps range **1,274–1,374**. Every native donor window has an interior-symbol maximum at least 1,408/1,491/1,416 respectively, so all 532,721 windows are excluded by each variant (best-case gap 34/117/42). This also excludes any permutation of these window histograms under that receiver. It does not exclude every English passage, a secret changing output-rank register, long periods, or arbitrary chapter-private phase maps. The three planted hidden maps satisfy all subset capacity constraints.
