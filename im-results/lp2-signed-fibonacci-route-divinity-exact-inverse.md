The combination *route + historic key* is a motivated, conditional test: no signed source explicitly says to join them.

The tested exact cipher is `C = (P + K[phase]) mod 29` for every **non-F plaintext** rune, advancing the eight-step key phase; **plaintext F (GP index 0)** instead outputs ciphertext F and does not advance phase. The operation is fixed by the solved-LP1 original replay, not inferred from unknown-page English. Because the key has no GP-zero values, any nonzero ciphertext `C=K[phase]` would decode to plaintext F yet should have emitted literal ciphertext F. Such a state is **impossible**, not merely unlikely.

At each position the algorithm retains all reachable phases and counts every completion with integer arithmetic. There is **no** guessed English, phase optimization, or F-mask cutoff.
