# Sixteen floral-border pages do not share one ordinary GP29 page-local additive pad

**Decision (12 November 2026, Agent46).** LP2 physical pp40–55 are framed by one pixel-identical floral border on each of sixteen original 2400×3600 JPEGs. A human could hypothesize that a repeated ornamental frame denotes a reused encryption key. On all **15 rune-bearing pages** (p50 contains only the numerical table), the complete original GP29 ciphertext fails a **key-independent necessary equality test** for one shared page-position additive pad over independent English-like GP rune plaintexts, including arbitrary per-page Caesar offsets. This is a *bounded cipher-architecture negative*, and no original plaintext or historical key is recovered.

## Source-selected candidate and strongest objection

Independent evidence: both original 500-pixel side strips, including all ten five-ring ornaments and the left 13 / right 31 reading, are decoded-RGB byte-identical across physical **p40–55**; see [original raster template audit](lp2-floral-border-template-audit.md) and [amended 16-image SFT](../sims/p55_binary_ornaments.py). The frame therefore provides a natural **common page-local key hypothesis**, although the original never instructs a solver to regard the frame as cryptographic. Its strongest alternative is a reused decorative typesetting template with no encryption role.

Freeze all original page indices and zero-based rune positions. Let every original ciphertext page p in the frame obey

`C[p,i] = P[p,i] + K[i] + A[p] (mod 29)`,

where the **entire key K is arbitrary and hidden**, and every page offset A[p] may also be independently secret. For any two original pages p, q aligned at printed rune index i, `D[p,q,i] = (C[p,i]-C[q,i]) mod29 = (P[p,i]-P[q,i]+A[p]-A[q]) mod29`. Thus neither unknown K nor unknown individual Caesar offset can change the **largest** bin of the 29-way aligned difference histogram. We grant **every one of the 105 page pairs its own independently optimal shift**, a superset of all globally compatible A[p] assignments. This uses the original's 15 pages (p40–49,p51–55), retains actual page lengths, and ignores p50 correctly.

Every single one of **6,000** native-GP language-window controls had a **larger optimum shift match rate** than the original LP2 pages. For each separate author, the add-one empirical lower-tail upper bound from 0/2,000 is **1/2,001**, conditional on this preselected original floral-page set, statistic, GP transliteration and author model. These are independent window draws within an author, not 6,000 independent external books; overlapping source ranges and language representativeness limit interpretation. The original lies below each author's entire observed range without fitting cipher keys to the original.

The test uses the repo GP29 original-runic transliteration with `QU→CW, V→U, K→C, Z→S` in three frozen text controls, matching the existing shared-pad model family. Every comparison retains the authentic source 29 rune values and page-local position. Random window starts are generated by the standalone, seeded xorshift32, with **2,000 runs per author** and the same original page lengths. The script asserts the original **684/19,079** exact matches and **1,232/19,079** independently optimal per-pair matches. A 15-page *positive* genuine-GP plant encrypts every native plaintext symbol under a common unknown nonlinear additive pad and arbitrary independent page Caesar offsets, then exactly decrypts; the invariant survives the encryption **without knowing either secret**.

## Decision and what remains open

The repeated floral frame alone fails to imply a single reused positional GP29 additive pad. Under ordinary English-like, source-native GP29 plaintext, even **all-secret per-page constant offsets** cannot reconcile the original pairwise difference histogram with the three language controls. This is a direct obstruction to a commonly suggested key-reuse route, requiring no guessed key and no ciphertext-fitted phase.

The test **cannot** exclude different page-specific pads, within-page shifts, a shared key subjected to pagewise *different rune permutations*, feedback coupling, a non-GP text register, a transposition before/after the pad, or an original plaintext with an atypical distribution. Such mechanisms need an *independent original clue* choosing their extra complexity before another search. Further page phase optimization or retrospective sharing groups would discard the source-selected entire sixteen-page frame and should not follow without a separate cue.
