# Original 2014 Titanpad workpad-history acquisition: two exact identifiers

**Decision (14 November 2026): the earliest available direct references now locate the original workpad on 2 May and its distinct corrected-rune pad by 9 May 2014. No archival response, editor revision, or export carrying authentic May–August 2014 pad text was recovered. No unknown LP2 plaintext, key or final URL is established.** This is a bounded source-acquisition result, not a statement that no historical copy survives elsewhere. The 2016 workpad snapshots and their already solved p56 discussion are documented in [the first pad report](lp2-2014-may-unfiction-workpad-source-gate.md).

## Exact first-hand dated source roles

The [original May–August 2014 IRC corpus](../resources/external/2014-cicadasolvers-freenode-log-corpus.md) preserves a source-pinned Git blob for `#cicadasolvers.freenode.log` (18,487,233 bytes; Git SHA-1 `bdd277c14f94c34b5ae714cd00c238065beeed4e`). These **participant** statements distinguish two documents that later research sometimes merged:

- At **2 May 2014, 15:24**, `strange_tcyborg` proposes using Titanpad to transcribe the just-released runes. At **15:25** the same speaker posts `http://titanpad.com/vFCy7T5p0O` (source lines 163843–163845). This predates the previously cited 3 May forum message and dates the first workpad's use to the release day. This is a historical participant timestamp, not an independently authenticated database creation time.
- At **4 May, 17:40**, `Mothwing` directs others to the bottom of that pad for *page-by-page OutGuess results* (source lines 166881–166885). The original measurements are **not** present in the recovered 2016 state or this log line. This identifies a historical research section that may have been erased from the mutable pad.
- A channel topic set by `brotherBox` at **9 May, 10:07:39**, visible in the 10:19 session record (source lines 172375–172376), explicitly labels `vFCy7T5p0O` **“Numerical information on Runes”** and `hJ8pVQ5S43` **“Updated transcription.”** The updated-transcription URL is also posted by a participant at 17:26 and 17:32 (lines 172653 and 172655). This is first-hand evidence of separate purposes; neither link authenticates the correctness of its editable content.
- A [separately dated 16 January 2015 solver source](https://github.com/resvolver/c1cada/commit/42d33941f0f03223c01fe052c0ae91a7a4981eb5) credits the latter transcription pad in `guess_key_phrases.py`, and references a third word-frequency pad `dgqETedGby`. Its later Git copy cannot establish the text of a May 2014 revision. Prior independent [2015 transcription-lineage work](https://github.com/Dukotah/cicada3301/blob/master/corpus/B-liber-primus/REPORT-B.md) already addresses these source copies; no alternate plaintext is inferred here.

## Public exact-ID history test

The read-only [two-pad archive SFT](../sims/lp2_2014_titanpad_twoid_history_gate_sft.cjs), executed under [successful Windows Node 22 Actions run 43604619169](https://github.com/FlareZ123/liber-primus/actions/runs/43604619169), sent **19** source-bounded requests across just the two witnessed pad IDs and one unrelated 2014 positive-control host. It queried canonical paths, their revision/timeslider/export descendants, the Internet Archive CDX/closest endpoint, Arquivo.pt CDX, and two time-specified Common Crawl indexes. **Eight** requests returned HTTP 200. No tested pad response supplied a source-dated **2014 or 2015 archived content record**. The unrelated `publico.pt` positive control did return two dated April 2014 records.

**Availability qualification:** eleven requests produced service-level errors or non-200 responses, including Wayback 503, Common Crawl 504 and connection failures. Such results are missing coverage, not zero-capture proofs. The 2016 first-pad Wayback copies identified in the earlier report remain valid. The documentation of [Etherpad's timeslider and revision-specific export](https://docs.etherpad.org/faq.html) explains the proposed URL grammar; a link to a timeslider or a 2016 HTML shell is not itself the historical revision payload.

The independent [exact-pad IRC-context SFT](../sims/lp2_2014_irc_pad_revision_context_sft.cjs), [successful CI run 43604835047](https://github.com/FlareZ123/liber-primus/actions/runs/43604835047), re-fetched and authenticated the original May–August 2014 primary IRC file and `#33012014` secondary channel by their original Git blob SHA-1s. It found **195** mentions of either pad ID in the first channel, many repeated in channel topics/bot previews, and **zero** period participant messages matching the preselected conjunction of a Titanpad/Etherpad reference with a history, timeslider, revision, download or export instruction. The second channel has no direct matches under these same bounded patterns. This excludes only *those literal IRC descriptions* in the two authenticated logs.

## Mechanism decision

No published archived 2014 pad revision, access-recoverable historical Etherpad changeset, authentic unknown LP2 plaintext, source-chosen GP29 key, or p56 digest preimage emerged. The 2016 snapshot's p56 content and 2015 transcription copies provide context but no replacement for original unknown-page decryption. Retire further arbitrary archived endpoint variations or repeated 2016 replay. Reopen this route only on a **new exact source-dated archive capture, backup, original export, revision payload, or first-party cipher instruction**. An eventual original capture should be compared byte-for-byte against its stated historical date, then replay any cipher claim against untouched 2014 JPEG rune positions.
