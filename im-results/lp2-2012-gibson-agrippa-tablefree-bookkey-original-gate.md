# 2012 Gibson *Agrippa* original-book running-key test, with unknown rune table and skip drift

**16 November 2026, Agent42. Original-input decision:** The exact William Gibson *Agrippa* poem used by Cicada's **2012** book-code stage produces **no detector hit** on eight 729-rune unknown LP2 chapter windows under (1) the external phase23 unknown-alphabet running-key model, (2) that model with the solved-Liber-Primus native IO/ING rune spelling, and (3) a separate zero-key-tick plaintext-F bypass extension. The 2012 source and its original book-coordinate operation are genuine historical references, but **no Cicada clue says this poem is an LP2 running key**. The F-aware decoder's synthetic recovery is incomplete; these are *bounded detector negatives*, not mathematical impossibility proofs. Nothing in the unknown book was decrypted.

## Why this particular source is distinct

The historical source `neuroretransmit/cicada` commit `ade9a02889ef8acbc8cde8edbfd0a785c369f4c3`, file `2012/006-two-book-codes/books/agrippa.txt`, has Git blob SHA-1 **`673ba225d1277945f2d2e5056bf025db8e89bb92`**. The companion [2012 book-code instructions](https://github.com/neuroretransmit/cicada/blob/ade9a02889ef8acbc8cde8edbfd0a785c369f4c3/2012/006-two-book-codes/README.md) and [original decoder](https://github.com/neuroretransmit/cicada/blob/ade9a02889ef8acbc8cde8edbfd0a785c369f4c3/2012/006-two-book-codes/books/agrippa.py) specify one-based `line:character` extraction, starting at poem line 1 after five header lines. The period result is `sq6wmgv2zcsrix6t.onion`. The poem is by **William Gibson**, a different work from Heinrich Cornelius Agrippa's occult text.

The published 2026 [phase23 table-free book-key scanner](https://github.com/pnotisdev/cicada3301/blob/15200c67abee106913ba01ff504c5b6e88d16cc7/work/log/phase23_book_key_decoder.md) had screened several other Cicada-referenced books but not this exact Gibson source. The poem's historically demonstrated coordinate use selects a *book*, not the hypothesized GP29 cipher or skip policy. The strongest rival explanation is that Cicada used the book only for its already-completed 2012 address construction.

## Frozen exact original test

- Input is the repository's unchanged `resources/liber-primus/lp2-corpus.json`, SHA-256 `58588725a006432a50a1c8d852b881e5e844ba32073e729b42e0f78074b17338`. Eight **original 729-rune chapter-initial ciphertext windows** cover physical pp0–2, 3–7, 8–14, 15–22, 23–26, 27–32, 33–39 and 40–53. The short final pp54–55 chapter is not tested by this detector.
- Historical Gibson book text is fetched from that exact 2012 Git blob at runtime, SHA-verified and started at the first poem verse (`I hesitated`), omitting its five non-poem header lines. The copyrighted book is not committed or copied into outputs.
- Both source-to-GP29 spellings are separately tried: digraph runes (7,115 key runes inferred from the original-offset grid) and letters as individual runes (7,491 key runes). The 29 source-letter group shifts are integrated out by [the upstream, commit-pinned original phase23 beam](https://github.com/pnotisdev/cicada3301/blob/15200c67abee106913ba01ff504c5b6e88d16cc7/work/book_key_decoder.py), with eight initial pointer states, up to two skipped key symbols per output and 64 beam states. This is more flexible than a fixed GP29 Vigenère table.
- The original published one-sided **729-rune stage1 thresholds** remain frozen: digraph **−0.0112** and letters **−0.0417** nats/rune. The inherited `q=0.81` anti-repeat skip mechanism is hypothetical for LP2 and does not implement the literal-plaintext F bypass demonstrated on solved p56.
- The first [full 32-position-equivalent four-shard run](https://github.com/FlareZ123/liber-primus/actions/runs/43801532490) covered offsets `0,8,…` below `len(key)−3×729`. The [disjoint original suffix run](https://github.com/FlareZ123/liber-primus/actions/runs/43802052452) extended the search through offsets below `len(key)−729−128` (128 source runes reserved for plausible skip drift). Both read the source only once per job and use the same frozen alphabet model and thresholds.

## Follow-up: literal-F bypass is a different historical LP2 mechanism

Solved LP2 p56 demonstrably passes plaintext **F** through to ciphertext **F** **without advancing the key pointer**. The external phase23 model above has no zero-key-consumption transition. The independently authored [F-transparent table-free beam](../sims/lp2_ftransparent_bookkey_beam.py) adds exactly that transition and forbids encoding plaintext-F through the ordinary additive branch; for non-F runes it retains the explicitly *hypothetical* q=.81 anti-doublet skip law and the 29-way unknown source-letter shift table. This is a plausible cross-page test, though p56 does not establish that the same operation governs pp0–55.

The [F-aware original runner](../sims/lp2_gibson_ftransparent_stage1.py), [aggregator](../sims/lp2_gibson_ftransparent_aggregate.py) and [manual-only workflow](../.github/workflows/lp2-gibson-ftransparent-manual.yml) use the same exact Gibson text, original LP2 corpus, eight 729-rune windows and disjoint offset partitions. The fixed **zero nats/rune diagnostic gate** is deliberately a screening threshold, not a preregistered global false-positive significance bound for this *new* cipher. All three matched synthetic null types stay below zero.

## Author-original GP spelling: replace external IA with solved-page IO/ING

The externally borrowed phase23 GP transliterator assigns rune ᛡ to Latin `IA`. The source-native **solved LP1 and LP2 author spelling** instead associates this symbol with `IO`, and ᛝ with `ING`. This is a *real model distinction*: it changes rune counts and book-key pointer alignment for a public prose source, even if the underlying historical book is identical. Since the independently demonstrated author spelling is more plausible than an arbitrary external convention, it warrants a single **source-justified alternative**, not a speculative key sweep.

The [writer-GP converter](../sims/lp2_writer_gp_runes.py) applies original-document `IO/ING` along with the same established GP rune order and ASCII normalization; [the scanner](../sims/lp2_gibson_writergp_stage1.py) and [aggregator](../sims/lp2_gibson_writergp_aggregate.py) otherwise retain the exact source book, source-hash check, zero-offset stride-eight sweep, eight original 729-rune ciphertext windows, source-upstream 29-way unknown shift-table integration, q=.81 hypothetical skip law, and **the earlier predeclared phase23 thresholds**. Letter-by-letter spelling remains independently tested as a control. This test has **no literal plaintext-F bypass**; that orthogonal branch is reported above. No speculative key offsets are selected by output.

## Decision and reproducibility

Retire **the tested forward Gibson poem running key, both external IA and writer-native IO/ING input conventions, arbitrary source-letter shift table, q=.81 skip law and first-729-rune chapter starts**, including the explicitly weaker F-transparent detector, unless an independently authored source selects a changed operation or authentic plaintext. In particular, the source's historical 2012 address proves only its coordinate-book role. The independent F-aware original test above closes the earlier F-bypass omission at its own explicitly weaker calibration. Together the two screens still do not test alternate editions, reversed reading, high-entropy derived keys, a key starting deeper inside a chapter, or plaintext outside the chosen English model. No p56 preimage, unknown-page plaintext, creator key or destination was recovered.
