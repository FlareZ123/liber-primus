# Exact full-book q13 private plaintext-width cover attack

## Decision
Retire the canonical native plaintext Latin-width q13 clock for the frozen ordered native-like register, including true chapter-private keys. This is a finite-reference/necessary-condition exclusion, not a universal language theorem. No original plaintext recovered.

## Model and reference-only anchor cover
Same clock as [source crib experiment](lp2-q13-plainwidth-source-crib.md): literal F emits 0 and holds; non-F p emits c=(p+K[t]) mod29, advances by canonical Latin GP spelling width 1/2, consuming c=0 legal. Any arbitrary 13-symbol key, phase origin free. No printed word cuts assumed. The true nine illustrated chapter cuts are 0,729,1874,3603,5506,6527,7960,9640,12648,12956.

Use the exact donor and dictionary preparation of `sims/lp2_q8_latent_independent_phase_sft.cjs`, which differs slightly in donor body cropping from the histogram transport receiver. For every donor 12956-rune window start x, a selected whole-word occurrence [s,e) is usable if x<=s, e<=x+12956, and no chapter cut x+b lies strictly between s and e. Enumerate and union the permissible start intervals for each lexicon word with >=11 distinct active phases; greedy choose the maximum remaining-window coverage per 29^(13-cover) completions (tie: higher gain, then insertion order). The cover uses reference data and actual chapter lengths only, not original rune values. The original 57-word bank was frozen before correcting the p27 boundary from 6761 to 6527. Recomputed coverage under the actual cuts, without reselecting any word, confirms the resulting 57 words cover **every one of 532345 windows** (33879 Gibran,204151 Shakespeare,294315 Emerson), even when anchors crossing a physical chapter boundary are discarded. Thus all donor windows have an anchor wholly inside some chapter.

## Exact anchored search
All 732480 word placements wholly inside a chapter were enumerated. Repeated phase differences must agree and any anchor F must match ciphertext 0. 582402 consistent partial assignments induce 30874790 complete key/anchor cases (with multiplicity). For each partial key, build bitmask transitions with unknown slots allowed both consuming widths at every visit, even if this would require inconsistent values; a failed anchored forward/backward reach in this superset rejects all completions. This excludes 29936700 cases. The remaining 938090 complete assignments were explicitly tested with exact transitions. At phase t with observed c the legal actions are hold F if c=0, and consume p=(c-K[t]) mod29 if p!=0, advancing by width(p). Exact backwards and forwards phase-set propagation starts from the anchor's fixed phases; no score/beam/cap.

**73** anchored assignments survive their chapter, all in the final 308-rune chapter. **Zero** survive the full continuous book and zero survive a common key with independent chapter origins. Therefore shared-key models are exactly incompatible with any of the 57 anchors wholly in a chapter.

For the chapter-private case, score all 73 surviving anchors with exact max-sum DP over (next phase, previous plaintext), force the anchor and its origin, allow all legal F decisions and all starts. Train the same native nine-section bigram model as the public-width attack (unigram pseudocount .5, bigram backoff mass10). Every optimal path exactly replays. Maximum original score **-1418.1240520354013**; worst of all 570289 independent length308 donor windows is **-994.0381730117806** (Gibran min -926.040212893422; Shakespeare -994.0381730117806; Emerson -940.1699918064987). The best candidate happens to insert PLANTAGENET and is otherwise gibberish. No other chapter even admits an anchored legal path. This proves no reference full-book window, and no plaintext meeting both the bank-coverage condition and matched chapter language-floor condition, can be an original decryption under the specified chapter-private model. This does not exclude exotic plaintext lacking all 57 words, arbitrary within-chapter resets, alternative width conventions, or pre-encryption word reordering.

## Exact arbitrary intact-word transport extension

Allow any global word order, across chapter boundaries, and arbitrary independent chapter keys and starting phases. Each selected reference word must retain its internal rune order, remain contiguous, and belong entirely to one physical chapter. This does not require preservation of the donor chapter membership or word order. All 58 selected words are proved infeasible in the first eight original chapters; any occurrence therefore has to fit the single final chapter (one common cyclic key). Its 90 locally anchored assignments across the bank produce 76 distinct cyclic key classes.

For each terminal key class and each word ID, count distinct feasible original start positions, deduplicating key rotations and repeated paths. This is an **upper bound** on number of copies simultaneously realizable; ignore interval overlap and joint hold-history compatibility, which only enlarges the relaxed receiver. Independently sweep all 532,345 donor-window starts with exact interval events from occurrences of the 58 selected complete word types, tracking their counts (not merely set membership). Every window contains at least one selected word. First require a terminal key class that supports every selected word type; then require distinct-start capacity for every selected word multiplicity. No assignment for unselected words is required.

- Gibran 33,879: zero type-compatible windows.
- Emerson 294,315: zero type-compatible windows.
- Shakespeare 204,151: only 2,418 type-compatible windows in two exact intervals, [168741,170611) requiring two copies of ID34, and [192969,193517) requiring four copies of ID45. ID34 has one terminal key class and one start; ID45 has 19 classes, each with just one start. Thus zero multiplicity-compatible windows.

**All 532,345 donor windows are exactly excluded even after arbitrary intact-word transport**, with independent chapter-private keys. This uses no English-language score, no target ordering and no donor chapter histogram. It cannot exclude arbitrary rune-level transport that breaks the anchor words or allows a word to straddle a chapter reset, alternate spelling widths, other clocks, or words outside the fixed reference condition.
