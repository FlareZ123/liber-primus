# Original LP2 predecessor-exclusion ranks: canonical arithmetic-code gate

**Decision (18–25 November 2026, Directors #1473 and #2273).** The distinct GP-prime-weighted no-EOS terminating-cylinder receiver in the final section is also negative on original input (16/95 canonical, no prose). An exact, untrained 28-way predecessor-exclusion rank channel is reversible on all 12,956 original ciphertext runes and its 86 source-adjacent repeat events. A single frozen public **order-zero GP29+EOS arithmetic codec** then fails to recognize the original rank frames: **0 of 95** are canonical encodings, with no sustained original plaintext. This is a **bounded rejection of that fully specified codec**, not a proof against every entropy code, pad, or evolving cipher. The entire positive and original test passed [Windows Node22 CI run 44301153600](https://github.com/FlareZ123/liber-primus/actions/runs/44301153600).

## Exact source and frame interpretation

The inputs are the canonical rune-index arrays in `resources/liber-primus/lp2-corpus.json`, checked against the physical nine chapter intervals p0–2, p3–7, p8–14, p15–22, p23–26, p27–32, p33–39, p40–53 and p54–55, excluding runeless p50. Their rune counts are 729 / 1145 / 1729 / 1903 / 1021 / 1433 / 1680 / 3008 / 308, totaling 12,956. For each original chapter, the first rune is retained literally. For a later rune `x` and predecessor `p`, nonrepetition gives the rank `x - (x > p ? 1 : 0)` in lexicographic original GP index order 0–27. An `x = p` event inserts a nonpayload boundary and leaves `p` unchanged. The converse expands rank `r` to `r + (r >= p ? 1 : 0)` and copies `p` at each event. Exact source reconstruction passes for all nine chapters.

Physical chapter repeat counts are **4 / 6 / 9 / 10 / 11 / 13 / 12 / 18 / 3**, totaling 86, hence **5 / 7 / 10 / 11 / 12 / 14 / 13 / 19 / 4 = 95** frames. The full original-rank digits, repeat positions and frame lengths are deterministically reconstructed by `frameRanks` in the linked SFT, directly from source arrays. No hand-selected breaks, word segmentation or page reset inside a chapter are admitted. Original p0 widths are **121, 84, 248, 196, 75** digits.

## One fixed GP29+EOS model and exact code

The reference is `resources/liber-primus/lp1-plaintext-reference.txt`: source-solved LP1 prose and final solved p56/p57. Its editorial and numeric-only lines are excluded, as are headings marked `#`. Remaining Latin transliterations are uppercased, V→U and K→C, tokenized by longest lexicographic GP spelling, and concatenated with original blank-paragraph separation. The resulting reference has **3,107 GP symbols in 34 paragraphs**.

The order-zero model uses **frequency 1 smoothing for all 29 GP symbols and EOS**, adds the 3,107 observed GP counts and 34 paragraph-ending EOS events, and thus has **total weight 3,171, EOS weight 35**. It does not inspect unknown LP2 text during calibration. Arithmetic coding uses exact rational interval subdivisions by this frozen 30-element cumulative frequency table. The encoder selects the **lexicographically first shortest base-28 prefix cylinder entirely inside** the interval for a plaintext rune string followed by EOS. The decoder treats a rank frame as the exact midpoint `(D + 1/2)/28^L` of the base-28 digit cylinder, expands through the same interval model to EOS within `min(2000, max(250, 3L))` symbols, and accepts a frame only if exact canonical reencryption reproduces **all L original digits**. No trailing-digit or padded-code exception is allowed.

## Decision for future work

This explicit **no-key, standard order-zero, shortest-prefix GP29/EOS arithmetic decoder** cannot be the literal source of the observed rank frames. A noncanonical padded scheme, a stateful model, a different source distribution or secret stream could still encode the rank digits, but each introduces additional information the manuscript has not selected. Further bit/radix/word-clock sweeps under this premise would be unconstrained. Require an original page or author-era clue that specifies an alternate **codec/header, EOS/length grammar, source dictionary or key** before reopening; otherwise prioritize independent source-selected operations capable of genuine unknown plaintext.

## GP-prime-weighted terminating cylinders, with no EOS (Agent30, 25 November 2026; #2273)

The earlier fixed solved-frequency EOS model leaves open an arithmetic decoder based directly on the **author's Gematria Primus prime chart**, without an invented end symbol or fitted distribution. This distinct receiver weights the 29 source GP symbols by their published primes in GP order (2 through 109, sum 1480), uses the same observed repeat-delimited base28 rank frames and original nine physical chapters, and treats F as ordinary. Word/line/page carries are transparent inside each chapter. The source establishes the prime values and historical BASE29, but does not instruct solvers to treat the primes as interval weights or to use repeated runes as terminators. This is a frozen source-derived hypothesis, not an authenticated historical codec.

**Exact constructive inverse:** For a finite plaintext string p, recursively partition [0,1) in the proportions of the 29 prime weights; let its interval be [a,b)/d. A base28 cylinder [v/28^k,(v+1)/28^k) represents p exactly when entirely inside its interval yet strictly straddles at least one of the 28 internal child boundaries. The decoder repeatedly descends into the unique child that contains the *whole* input cylinder, stopping as soon as there is none. No EOS, guessed plaintext length, or language model is used in the inversion. The canonical encoder chooses the shortest terminating cylinder and then the numerically lowest. All arithmetic is exact BigInt. Termination is guaranteed: the largest child weight is 109/1480, so widths shrink geometrically. Every finite plaintext has a terminating cylinder because two consecutive internal boundaries differ by a child weight (e.g. 3) times the current interval width /1480; its reduced denominator retains a factor 5 or 37 outside radix28 (1480=2^3×5×37; each prior prime weight can cancel at most one of 5,37), hence at least one boundary cannot coincide with a radix28 endpoint. At sufficient precision the cylinder containing that interior boundary lies inside the parent interval.

The fully specified [standalone CommonJS SFT](../sims/lp2_gpprime_terminating_cylinder_sft.cjs) passed all nine complete pinned solved-native sections (2,979 actual runes), plus 30 lengths 0–29 and all 841 two-rune combinations. Native control section lengths range 85–780; their exact encoded widths range 98–909. Every control recovers every GP symbol and replays its canonical rank frame. A fixed original-data-independent, add-0.5 GP trigram score trained on the solved register is used only to assess outputs. Leave-one-section-out native NLL range 2.460232–3.009883 nats per scored rune.

The p16–21 selection uses whole repeat frames; some extend outside those exact page boundaries. All nine chapters yield nonprose. The output begins `B S AE OE X A L R Y Y E N B Y L NG C I AE IA M OE Y C AE J X L`, not an authentic unknown message. Prime-weighted arithmetic decoding itself raises IoC above uniform, so IoC alone is not evidence of English. The language check does not prove a theorem about arbitrary source languages.

**Noncanonical and side-information consequence:** Each decoded plaintext at a specified frame width k has at most 28 distinct valid terminating cylinders, since each must contain at least one of the 28 internal child boundaries and each strictly internal boundary determines a unique cylinder. Enumerate those cylinders in increasing order. All 95 original frames reconstruct their exact rank digits from their decoded prefix, actual width, and the observed cylinder ordinal, and the rank inverse restores all 12,956 original cipher runes (including nine chapter first runes and all 86 repeat markers). This is conditional replay with an explicitly disclosed sidecar, not a source-derived correction: width and ordinal are read from the original input. Seventy-nine of 95 original frames have minimal width, but only 16 have the canonical lowest cylinder; total excess width is 16 digits. The product of actual fixed-width homophone counts has log2 cardinality 290.168831 bits, with at most 28 choices/frame. This is the conditional uniform-all-choice capacity, not a minimum number of bits for the one observed manuscript, an independent carrier, or Shannon entropy. Selecting any alternative cylinder at the same decoded prefix cannot change a single plaintext rune. No printed mark selects the missing ordinals, and even granting all of them cannot rescue the decoded nonprose.

**Decision:** retire the exact prime-weighted no-EOS terminating-cylinder receiver, including arbitrary homophone-choice sidecars that only select a cylinder for its decoded prefix. It is distinct from the earlier frequency/EOS model, and genuinely accepts every finite native plaintext in its canonical image, but it does not accept the original as a canonical encoding. The original repeat markers remain an unverified framing hypothesis. No further arbitrary probability-weight or boundary sweep is warranted without independent source instruction.
