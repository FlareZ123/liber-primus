# Blind hidden-skip decoder for authentic prime-row Latin-square ciphers

**Evidence classification: source-motivated synthetic cryptanalytic positive, original LP2 negative. No unknown original plaintext or key recovered.**

A simpler and more historically plausible competitor to an unknown 841-entry random tableau is a GP29 Quagmire/Latin-square operation: ciphertext = outputAlphabet(inputAlphabet(plaintext) ± phi(prime)[pointer]). Both alphabets are invertible GP29 permutations. The row clock is exactly the Euler totient of successive ordinary primes modulo29, as used in the known solved p56; the unknown-page transfer and anti-repeat mechanism are **hypotheses**. A measured ~81% suppression of repeats motivates a stochastic sender rule: if a candidate ciphertext equals the previous ciphertext, advance the key pointer and try again with probability 0.81.

A receiver is not given the private rejection coins, key pointer trajectory or recovered plaintext. A finite beam search considers each plausible skipped-row count 0–3, **requires every rejected candidate row to reproduce the previous published ciphertext**, and assigns native-GP Shakespeare bigram/trigram log-likelihood to decoded text. The 29-row Latin-square alphabet is fixed from the chosen public source; no secret tableau is trained or supplied. Scores combine 0.55×bigram, 0.45×trigram and explicit rejection log probabilities, with 128/256 survivor histories. The [single-file reproducer](../sims/lp2_phi_prime_latin_hidden_skip_beam_sft.cjs) is Node22 CommonJS, read-only and source-native.

## Blind planted power

On independent Gibran source-native text, using the separately trained Shakespeare language model, recover a 729-rune passage under the *historically named* input alphabet DIVINITY, output alphabet FIRFUMFERENFE, and phi(prime) row clock. Hide the sender's 18 rejection skips and pointer history from the decoder: **729/729 exact original planted runes**, correct pointer ending747. With an identity Latin-square pair and a full **12,956-rune** second planted passage, the sender performs **317 hidden key skips**. The 256-beam decoder recovers **12,954/12,956 (99.9846%)**, and predicts the exact final pointer **13,273**. Neither plaintext nor skip history enters optimization; they are used for held-out correctness evaluation.

## Frozen original test

After confirming those source-shaped positives, test a finite list of four historically motivated alphabet maps for each of the input/output slots: identity, LP1 Atbash, and GP29 keyed permutations of the actual solved keys DIVINITY and FIRFUMFERENFE. Two additive signs yield **32** models. Start the authentic prime-totient key at index zero for the original first **729-rune p0–2 chapter**, without resetting at printed words. Preserve the original ciphertext exactly. The strongest scored original candidate is input FIRFUMFERENFE / output DIVINITY / minus sign, **−4.101607** per rune; the recovered text is incoherent. Freeze the six leading original candidates and apply them unchanged to the independent second **1,145-rune p3–7** chapter: every score is below **−4.0** per rune, with the leader −4.151760 and no coherent plaintext. Planted native prose scores around **−2.44** per rune on the same scoring scale.

This decisively rejects the **specific direct transfer of the solved prime-totient row clock with these finite historical Latin-square alphabets and the specified q=0.81 skip rule** as a readable native-GP English inverse of the two original chapters. It does not exclude an unrelated original unknown alphabet, different initial prime/key index, different plaintext language, or a non-Latin-square tableau. The original cipher's extreme global flatness remains an important independent discriminator: an unknown per-row random tableau H2 may fit repeat suppression yet fail the original unigram profile.

The recovered **exact skip-path capability is reusable** wherever an authentic finite alphabet and key row stream can be obtained, without searching every possible rejected key value. The plausible next route is to obtain an *original source-selected* alphabet/key initialization before attempting unknown LP2 again. Tuning non-authored alphabet permutations to noisy original candidates would be overfitting, not evidence.
