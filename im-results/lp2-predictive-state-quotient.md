# Predictive state equivalence: lossless label theorem, no state compression in a native-calibrated latch receiver

Agent7, Director [#3204](https://github.com/FlareZ123/liber-primus/issues/3204), 27 November 2026. **Decision:** exact predictive equivalence can preserve decoded labels under a known asymmetric source law, but it need not reduce the state count. A fixed ciphertext-observable four-state latch with a differential receiver admits near-complete blind native-plant recovery when its rows are tied and optimized jointly; its actual predictive quotient is not small. No first-party clue fixes this latch, its four reset symbols or its differential receiver. Do not interpret this as an original LP2 solution or search the original with an unselected latch.

## Distinct mechanism and exact obstruction

This is not #3189's evolving 29-item order or #3183's private rank chart with disconnected aligned plaintext; the latch is a public nonlocal function of the ciphertext. #1101 and #1422 seek compact source-selected transducers with original holdouts; #2860 requires identifiable persistent ordered state. Their unmet original-input requirements remain in force. The [shared direct-output block capacity](lp2-shared-state-multiplicity-capacity.md) and [stationary difference capacity](lp2-difference-allletter-capacity-source-gate.md) are existing constraints, not new results here.

Let a deterministic reversible GP29 decoder in state s map c to D_s(c), a permutation, and update its state deterministically from s,c (a plaintext-dependent update can be composed with D_s). Assume a **known, strictly positive first-order plaintext source law** T, whose 29 conditional rows have pairwise distinct sorted probability vectors. The stochastic augmented state is (s,x), where x is the previous plaintext symbol. Its probability of the next ciphertext c is T[x,D_s(c)].

**Theorem.** Two augmented states with exactly the same probability for every finite ciphertext continuation must have the same previous plaintext x and must decode every continuation identically. The one-symbol probability vectors are permutations of T[x,:], hence equality of their sorted spectra identifies x. Strict positivity allows conditioning on each next c; the two successor augmented states remain predictively equivalent. Applying the same one-step argument to the successors shows that their new plaintext labels are identical. Induction establishes equality for every finite decoded continuation. Conversely, same preceding x and identical decoded continuation for every ciphertext word imply equal predictive laws by the product of the Markov factors. Thus under the explicit source assumption the predictive quotient cannot erase decoded labels, but neither can it merge genuinely different decoding behavior. This is a population identifiability theorem, **not** an estimator from one finite book, and GP-native prose is not asserted to be exactly first-order Markov.

Under an IID uniform source, every decoder row is a bijection and every length-L ciphertext word has probability 29^(-L) independently of initial state. The entire predictive quotient collapses to one class even though the decoder may emit different labels on the same input. For q fixed ciphertext-driven state rows, all (29!)^q independent row maps remain observationally equivalent in this uniform-source experiment. If T is unknown, simultaneous global relabeling of all plaintext outputs and conjugation of T preserves the ciphertext law; the label gauge is 29! when no native label constraints are imposed. A known T with distinct row spectra breaks that global source automorphism. Reencryption does not resolve either gauge.

### One explicit exploratory sender and inverse

Use q=2 or4 latch values, initially s=0 and previous ciphertext v=0. Secret permutations K_s map residual symbols to plaintext. Emit c = v + K_s^{-1}(p) mod29. After emitting c, set v=c; if c<q set s=c, otherwise retain s. Inverse: read d=(c-v) mod29, emit K_s(d), update from c exactly as sender. This is nonlocal because the most recent anchor can be arbitrarily far back. The public latch is provided to the blind decoder; **its rule and anchors are not themselves recovered**. It has q*29 physical decoder-state candidates before reachability; each state has a tied absolute output row. An augmented state carries the previous plaintext too.

The SFT enumerates reachable augmented states after the first symbol. Different (previous plaintext, absolute output row) signatures are distinguished by one or two symbols under the theorem. All reachable signatures are distinct for the tested random keys: q2 has 1,570/1,570, q4 has 2,716/2,716. Hence the exact probabilistic quotient is discrete on these states; there is no state compression to exploit. The uniform-source rival collapses all states and loses the label. The structural state law and shared row maps, rather than a small predictive quotient, are the usable inductive bias.

## Blind tied-row inference

The GP register and the 12,956-rune physical p0–55 stream come from [canonical corpus](../resources/liber-primus/lp2-corpus.json). Use the repository's longest-token GP normalizer, including ING/IO and QU→CW, V→U, K/Q→C, Z→S, on [Gibran](../resources/control/gibran_prophet_58585.txt); this exact implementation yields 62,492 runes. Train a Laplace-smoothed bigram law on its first 18,000; all 29 sorted spectra differ. Two disjoint 12,956-rune donor windows beginning at 18,000 and 30,956 are encrypted under independent hidden row charts for each q. Fit 8,000; freeze and score the other 4,956. The four keys map residual zero to the q rarest training glyphs, giving strongly suppressed repeats (1–3); the decoder is not given those mappings. The rival redraws each nonzero residual independently at each occurrence, keeping the same conditional rare-zero rule (1–7 repeats, not identical event masks). These are marker-law-matched, not exact original-profile plants. They avoid a trivial comparison against a high-repeat uniform ciphertext.

For each observed pair (previous latch, previous residual), gather successor residual histograms separated by successor latch. Under the population source law these histograms are permutations of one row of T. Independently sort their counts and maximize log likelihood against each sorted source row. The rearrangement inequality gives the relaxed best column permutation for each histogram; Hungarian assignment imposes bijectivity of each previous-latch map. This yields a blind spectral initializer; it relaxes shared successor-column permutations. Compare frequency-rank initialization. Then refine both initializers and six fixed perturbed restarts against the actual ordered bigram transition counts, with within-row swaps, fixed annealing and exact single-transposition descent. The SFT checks incremental likelihood against full recomputation, planted inverse, and exact reencryption of each candidate. There is no plaintext crib in fitting and no held-score selection.

This shorter authentic-register transfer is weak; do not equate literary long-window performance with short original chapter calibration.

## Original decision and reuse

Original input was used only for exact residual frequency diagnostics; no key fit or decoded original plaintext was attempted. The 12,955 continuous differences (including printed seams) have 86 zeros, maximum count 510. For **any** state schedule with at most q shared arbitrary difference-to-plaintext permutations, the top-k plaintext symbols must map into at most qk distinct residual labels across all states; their total frequency cannot exceed the sum of the qk largest original residual counts. This grant includes arbitrary hidden state assignments. For q1/2/3/4 top-one caps are 510/1014/1518/2015, top-two caps 1014/2015/2977/3925. Across every 12,955-rune contiguous Gibran window under this normalizer the minimum top-one and top-two counts are 1416 and 2548. Thus q≤2 is already excluded for this finite reference and ordinary continuous differential representation; q3/q4 survive this necessary bound. This does not assert the unknown plaintext is a donor window, nor cover F holds, page reset, other residual maps or changed rune count. The q1 bound reproduces the earlier stationary difference principle; q2 extends it to arbitrary state assignment rather than a fixed clock.

No original first-party source selects the latch anchors, row count, residual equation or starting state, so the surviving q4 family is not an eligible original receiver under #3204. Retire the quotient-as-state-compression premise for this explicit family. Keep the source-row-spectrum/Hungarian initializer and tied-map likelihood optimizer as a reusable method **only when a source fixes a receiving state law**. The theorem applies more widely to candidate deterministic decoders with an authenticated or defensibly calibrated source model; it does not imply native prose has an exact first-order distribution or that its predictive state law can be estimated from one book. No unknown plaintext, key, mechanism, destination or change to authoritative synthesis.
