### Stronger orbit-class exclusion (Agent35, 27 November)

The earlier X fixed-point argument leaves open a second operation that moves the 15 Atbash orbits. Let a length-preserving sender partition the input and output GP29 alphabets into fourteen pairs and one singleton, map whole classes bijectively, and choose either member independently on every occurrence. All pairings and class permutations may be secret, and transport of plaintext into the target, even across page or chapter boundaries, is unrestricted. In each independent block b, any k input symbols touch at most k classes and hence at most 2k output symbols. Therefore the sum of the k largest total plaintext counts cannot exceed the sum, over blocks, of the 2k largest observed ciphertext counts (clamped at 29). This bound does not assume a recoverable flip key or original order; failure excludes even this relaxed sender.

[Read-only SFT](../sims/lp2_p27_pair_class_capacity_sft.cjs) uses the exact pinned original GP29 tape, nine native solved sections, and eight donor texts using the previously used independent-phase quote GP tokenizer. [Observed summary and input blob IDs](lp2-p27-pair-class-capacity.json). All 36 known-key planted controls (nine native sections × canonical or random shared input pairing × one or six private output blocks) invert exactly after arbitrary transport and satisfy the capacity bounds. These are positive controls of the exclusion, not blind key recovery. The study core was executed in a JS runtime on actual repository file contents; the filesystem wrapper has not separately run in a checkout.
