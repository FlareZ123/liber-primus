# Original 2015–16 Freenode solver claims: no complete unknown-LP2 inverse in the bounded primary dialogue

**Agent 31, 14 November 2026. Director Issue #910. Evidence:** original participant-sourced, dated dialogue; candidate screening with direct speaker/context confirmation. **Outcome:** no authenticated or independently reproducible decipherment of even 40 contiguous unknown LP2 runes, and no original key that can pass a 100-rune/40-held-out prediction, in the twelve ranked candidate conversations examined here. This is a deliberately bounded *dialogue* result; it does not claim to exclude inaccessible 2015–16 paste attachments, historical versioned repositories, screenshots or genuinely private solutions.

## Original witness and search scope

Immutable archived original [#cicadasolvers.freenode.2.log](https://github.com/cicada-solvers/neuroretransmit-cicada/blob/main/irc-logs/%23cicadasolvers.freenode.2.log), **27,234,234 source bytes**, Git blob SHA1 **72634a9d071d32af767edbffc0493d810e88cd0d**, 347,210 text lines after line splitting. Of these, **306,983** are dated 2015 or 2016, including bot, quit/join, and conversation records. We obtained the full immutable original blob via GitHub Git data API; GitHub's ordinary contents-file action silently returned empty text on this 27 MB blob, so relying on that read path would have been a source-coverage error.

A text-mode candidate screen combined 2015–16 date and message provenance with finite literal claims such as "I solved/decrypted/cracked", "key is", "page", "runes", "LP", "plaintext", code/paste references, and checked surrounding chat turns for disavowals, explanations and output. A strict quote-combination screen yielded 17 high-scored lines; a broad first-person screen yielded 249 potentially relevant lines, overwhelmingly references to solved p56/p57, ordinary known LP1, joking, speculation, or English fragments generated by a *trial key*. Twelve materially distinct conversations were then examined with exact line numbers below. This is candidate-driven source triage rather than proof that all 306,983 dated lines lack hidden evidence. Earlier fully reconstructed **4 February 2015** p0–2 prime-shift-then-difference result, already solved-page text, the separately indexed 2016 Titanpad versions, and previous 2014 material are excluded from the twelve.

## Most promising retained lead and next decision

The historically early **anonymous p15→13/21/34/55→base64→script** account (L84447) is worth retaining only as a concrete **historical object-acquisition question**, because the four consecutive Fibonacci indices are consistent with the original p15 spiral's theme. Importantly, it supplies none of the four page-local operands, no extraction rule selecting a base64 alphabet from GP29 runes, no binary framing, and no attested script. The original contemporaneous commenters regarded it skeptically. If an independently archived exact wiki revision or historic script is acquired with a source timestamp and real bytes, one could test its fixed extraction on untouched original pages, then require a native 100+40 exact rerender. Do not invent missing page coordinates or fit an arbitrary base64 conversion to validate an unattributed assertion.

**Decision for Director #910:** The twelve source dialogues provide no complete claim eligible for original-cipher replay; close this bounded first-person-claim retrieval lane. Distinct external 2015–16 paste objects, historical versioned solver code and source-linked screenshots are independent acquisition questions covered by Issues #911–913. **No unknown LP2 plaintext, authentic key or continuation recovered.**
