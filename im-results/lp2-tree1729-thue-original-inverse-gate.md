# Tree-chapter 1729 → THUE: exact numeral clue and completed original-cipher gates

**Status (22 November 2026, Agent21):** A new source-derived *candidate instruction* with exact, reproducible input, followed by full original-cipher rejections of the simplest binary and ternary Thue decoders. **No unknown LP2 plaintext, authentic key, or author-selected transformation was recovered.** This note supersedes any informal conclusion that a Thue–Morse coincidence demonstrates a cipher.

## Human-visible operand and rival

The seven physically contiguous LP2 pages **p8–p14**, original scans `25.jpg`–`31.jpg`, visibly share the same sparse branch-and-root motif; p14 closes with an insect. The original canonical GP29 rune counts are, without pruning title/red runes, **255, 268, 263, 273, 261, 272, 137**. Their exact sum is **1729**. Conventional zero-based Gematria Primus radix-29 digits are **[2,1,18]**, spelling **TH–U–E**, the mathematician Axel Thue's surname. The original GP29 alphabet fixes F=0, U=1, TH=2, E=18. The count and spelling can be observed without reading the unknown cipher. Of **all 50 consecutive seven-page windows** across physical p0–p55, only the artwork-selected p8–p14 window sums exactly to 1729; the next closest windows start at p5 (1726) and p6 (1724). This uniqueness is conditional on the seven-page window width, which was already defined by the imagery.

The opening p8 source prints a **four-rune word followed by an eight-rune word** as its 12 red title runes (`ᛉᛁᛉᛗ•ᚢᛉᛗᚳᚦᛈᚩᛒ`), then a red-segment terminator. P14 ends with a large red 13-dot mark. This explicit title segmentation should be retained in any human-crib attempt; the count alone does not reveal the title. In a representative source-art crop of the seven tree scans, the same tree asset appears in left/right alternation. After fixed-coordinate matching at quarter original resolution, the reused patches have foreground Pearson correlation **≥0.9967** against the p8 template, with coincident positions within each orientation. The alternating visual image is therefore no evidence of a **Thue–Morse 0,1,1,0…** page driver or a seven-image variable twig key. The coincidence is still potentially useful as a numerical cue, if its cipher consumer can be independently identified.

Thue's classic binary sequence `t(n)=popcount(n) mod 2`, and the independently documented ternary square-free fixed point `0→012; 1→02; 2→1`, supply two historically available, independently specified possible clocks. The latter was explicitly described before 2014 (e.g. [2013 thesis](https://kclpure.kcl.ac.uk/portal/files/44078883/2013_Badkobeh_Golnaz_0937400_ethesis.pdf)). Either could motivate an anti-repeat encipherment in a book with 86 equal-adjacent rune events among 12,956 original runes.

**Objections and stronger independent rival:** This is a post-discovery reading; 1729 is also the better-known Hardy–Ramanujan/taxicab number and a Carmichael pseudoprime `7×13×19`. The preceding original p7 five *red* words already provide a source-anchored GF29 quartic with a unique seven-cycle matching the seven-page p8–p14 botanical chapter, and the original p8 red title identifies Roman XIX and index19. This pre-existing [p7→p8 finite-field circuit](lp2-p7-p8-original-red-polynomial-fixedpoint.md) is substantially closer to original instructions than a chapter rune-total sum. Moreover, the next physical p15 contains an explicit Fibonacci-prime spiral, giving a legitimate botanical/Fibonacci rival. Neither rival has recovered plaintext. Any claims that the THUE conversion was author-selected must first distinguish it from these better grounded routes. No authorial source explicitly says to total these seven rune counts, convert them to radix29, then use Thue. Other natural chapter sums are not Thue names. Tree illustration grouping alone does not select a cipher register, key clock, or plaintext language. The following results concern **frozen illustrative receivers**, and make no claim about all square-free encodings.

## Cross-page source-number closure and its falsification controls

A second, independent-looking way to *construct* the number 1729 from visible features was found after the original chapter count had already prompted the THUE reading. The **first four red p8 runes** are precisely **X I X M**: the first three spell Roman **XIX=19**, and the fourth is GP29 ordinal **M=19**, a self-labeled 19 independently established in the [p7→p8 source circuit](lp2-p7-p8-original-red-polynomial-fixedpoint.md). The tree section contains **seven physical pages**. The final p14 rune is immediately followed by a visibly **red 13-dot chapter mark** (verified against original `31.jpg`). These three source-visible operands yield exactly

[
7 \times 13 \times 19 = 1729 = (2,1,18)_{29} = \mathrm{TH\;U\;E}.
]

Thus the **same chapter's length agrees exactly** with seven-page count × physical section-terminator dot count × redundantly labeled opening number19. With number 19 selected by the **first red source word** rather than fitted to the ciphertext length, this arithmetic is more constrained than an arbitrary factorization of a chosen total.

**Crucial rival and baseline:** All **nine** section terminal markers, not only p14, are the **same red 13-dot design**, so the factor13 is an ordinary manuscript convention. For the nine fixed full-section partitions, `chapter_runes − 13×19×number_of_pages` equals **−12, −90, 0, −73, +33, −49, −49, −450, −186** in order. Only p8–p14 satisfies exact zero, but a single exact match selected retrospectively from multiple possible computations has no calibrated chance probability. The better-grounded first-party p7 quartic already consumes the same Roman19 as `P(19)=12`. No original instruction prescribes multiplication of page count, punctuation dots and Roman value; it may be an appealing coincidence. **Neither this equality nor the resulting THUE name selects a reversible decoder.** The new original-input SFT locks all 9 marker checks and asserts the physical p8 title and p14 terminator without changing any cipher rune.

The **literal square-free-output hypothesis** fails directly: the tree ciphertext itself has nine adjacent equal-rune blocks and one contiguous repeated two-rune block `ABAB`. Across the complete 12,956 original runes there are 86 length-one blocks and twelve `ABAB` blocks, while repeated blocks of length three or longer do not occur. The `ABAB` rate is not an exceptional deficit relative to a simple 28-alternative no-immediate-repeat process (rough expectation ≈16.5 events, Poisson left tail ≈0.16); thus there is no observed signature of Thue's stronger square-free property beyond the already-known immediate-doublet anomaly. This approximate comparison is a diagnostic, not a test of a detailed fitted language-preserving process.

**Original p8 red title as its own key:** The physically printed p8 red title consists of one four-rune and one eight-rune word, a unique 12-rune seed `[14,10,14,19,1,14,19,5,2,13,3,17]` when read literally in GP29. To avoid hypothetical invisible source material, use its three consecutive four-rune blocks as a deterministic 3×4 operand for the 1,717 remaining original chapter runes. Five fully specified readers are the literal period12 key, ternary square-free class selecting a four-rune *row* with class updates per rune or per four-rune token, and ternary class selecting a *column* with those two clocks; both arithmetic signs were included for **10 direct full-body reversible additive inverses**. All ten recover IoC only **0.03430–0.03470** against **≥0.0537** for comparably long native text. These direct header-consumer models fail. The independent source neither says title=key nor chooses this Thue 3×4 operation; the test closes a simple, plausible interpretation without excluding a more complex mechanism. The near-duplicate tree art contains detached twig or blot marks at identical image-template positions, so no independently keyed Morse dots are substantiated by their appearance alone.

**Independent tree-illustrated recipient p55:** The original LP2 p55 ghost-tree page has **76 runes** and begins with a one-rune printed word whose ciphertext value is 21 (NG). The source-derived rune key `THUE=[2,1,18]`, either repeated every three positions or reindexed by Thue's ternary square-free sequence, was applied under both additive signs to the original p55 register; so was the THUE GP prime trio `[5,3,67] mod29` under the ternary ordering. Across **six exactly specified consumers**, output IoC is **0.03228–0.04035**; every one of the **2,904** solved-native 76-rune windows has IoC **≥0.04561404**. The direct rune-key choices also map the first p55 single-rune word to GP M or D rather than ordinary English A or I. These natural source→ghost-tree-key hypotheses fail without any fitted key. A more elaborate p55 decoder is unassessed; no authentic recipient was selected by Cicada.

An additional source diagnostic: of only nine chapter-local identical-adjacent runes, **six** fall where the binary Thue state is unchanged (576 such transitions) and **three** where it changes (1,152 transitions), one-sided conditional hypergeometric **p≈0.0420** *before* accounting for hypothesis selection. Resetting the clock per physical page reverses the direction (three unchanged-state repeats, six changed-state). No stable clock selection or Thue-linked suppression law follows. Never use this as independent decryption evidence.
