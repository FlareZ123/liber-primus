The naturally selected layouts are (a) columns of the 201 chronological quintets and (b) five consecutive 201-rune stretches. For five 201-rune lanes \(C_{a,j}\), let \(h_{ab}(d)\) count positions where \(C_{a,j}-C_{b,j}\equiv d\pmod{29}\). Any shared unknown additive pad \(K_j\) cancels exactly. ## Additional period five-unit operation: exact ITA2 letter-code obstruction

A distinct pre-2014 five-input alphabet is **International Telegraph Alphabet No. 2 (ITA2, often called Baudot)**, specified by [ITU-T S.1](https://www.itu.int/rec/T-REC-S.1/en). Its five-bit **letters** state assigns 26 codes to letters; exactly six code values are nonletters: 0 (null), 2 (line feed), 4 (space), 8 (carriage return), 27 (FIGS) and 31 (LTRS). The five source dots and 201 intact quintets make this an affordable historically real competitor to Bacon, although **the artifact never names ITA2 or supplies a rune-to-bit key**.

For a fixed but *entirely unknown* binary bit attached to each of the 29 GP rune identities, a quintet is a letter precisely when it avoids all six nonletter patterns. Each of the original 201 quintets contributes six forbidden-pattern SAT clauses, simplified when repeated runes would have to carry contradictory bit values. There are **1,121 distinct valid exclusion clauses**, with **85 internally impossible patterns** removed. Exhaustive Boolean unit propagation and branching proves the original **unsatisfiable** after 303 search nodes (151 branches, 152 conflicts). Thus **every possible stationary GP29-rune→bit map forces at least one nonletter ITA2 symbol among the 201 outputs**. Reversing bit order preserves the set of six excluded codes, so both printed and mirrored within-quintet orientations obey the same proof. A separately planted 201-letter native-GP phrase encodes and decodes exactly through the declared ITA2 table under a fixed 29-rune bit mask; its SAT instance is satisfiable.

**Stronger exact original result with SPACE permitted and FIGS permitted.** Keeping ITA2's actual SPACE code **4** as legitimate reduces the forbidden set to **{0, 2, 8, 27, 31}**. On the same original 201 quintets, all 29-bit rune assignments are again **unsatisfiable**, this time with **944** distinct clauses (335 exhaustive SAT nodes, 167 branches, 168 conflicts). Thus **there is no stationary rune-bit key producing a 201-character ITA2 stream composed solely of letters and ordinary spaces**, in either bit direction. A further generous variant allows FIGS code 27 as well, forbidding only **{0, 2, 8, 31}**; it too is **unsatisfiable** (767 clauses, 519 nodes). Under that variant, every key necessarily emits at least one of NUL, LF, CR or LTRS. The forbidden sets are invariant under five-bit reversal; all results apply to both quintet bit orientations. As a positive control, a separately encoded **201-character native-English phrase including spaces** decodes exactly under a fixed planted rune-bit mask and passes the corresponding SAT check. These are **all-secret key-independent exact exclusions of simple printable teleprinter text**, without any guessed English model. Genuine stateful ITA2 may contain carriage returns, line feeds and letter-shift controls and is not excluded.

Independent source-typographic capacity check: after the 16-rune heading, pp23–26 print **220 nonempty rune words** over the same 1,005 ciphertext runes. There are **219 word-separating boundaries** with offsets modulo five distributed **[41, 47, 44, 47, 40]**. Hence **178/219 separators fall inside a frozen five-rune group**, and 201 one-character outputs cannot supply one nonempty output character for every one of the 220 printed word spans. This decisively excludes **only** a five-to-one character decoder that also promises to preserve the *printed* 220-word segmentation; these could instead be deliberate ciphertext formatting.

**Decision:** both a literal uninterrupted ITA2 *letters-only* stream and a *letters-plus-spaces* original stream under a stationary rune bit map are exactly excluded. An even broader alphabet that also grants FIGS requires at least one of NUL, LF, CR or LTRS; original printed word structure independently obstructs a naive segmentation-preserving five-to-one reading. **A complete ITA2 stream with actual control codes and stateful shifts, varying bit keys, added encryption layers and differently packed reading remain open.** No historically sourced key or complete invertible five-input original-cipher readout has emerged. Do not extend to arbitrary bit maps or fit free five-input tables without another original authorial selector.

## Five-dot Baconian hypothesis: exhaustive all-secret key search

A human solver encountering five black dots and a source-delimited **201×5** body might try a Bacon cipher: assign each of the **29 original GP rune identities** an unknown fixed 0/1 value, read each consecutive quintet as a five-bit integer, and interpret that number as an alphabetic character. That creates a concrete, potentially plaintext-producing operation with only **29 secret bits**, much smaller than a free 201-position pad. Crucially, the *entire admissible keyspace can be enumerated exactly* by rejecting the forbidden letter codes **before** using an English score. Both printed quintet order and a literal mirrored quintet (suggested, though not selected, by the bilateral page decorations) are source-natural. Both original and reversed 201-group order are scored.

### Modern A=0 through Z=25 (26-character) readout

For a source quintet \((g_0,g_1,g_2,g_3,g_4)\), let \(x[g]\in\{0,1\}\) be the one permanent unknown bit for that rune. The decoded code is \(16x[g_0]+8x[g_1]+4x[g_2]+2x[g_3]+x[g_4]\). The code is invalid under literal A=0,...,Z=25 exactly when the first **two** bits and either the **third or fourth** bit are all one. Consequently, each of the 201 groups yields the two forbidden triples \(\{g_0,g_1,g_2\}\) and \(\{g_0,g_1,g_3\}\), interpreted as bitmask hyperedges (including naturally collapsed two-rune constraints when symbols repeat). The original source has **375 distinct forbidden hyperedges** in printed quintet orientation and **385** in mirrored orientation.

Rather than fit a few arbitrary rune-to-bit mappings, the [complete original-source CJS SFT](../sims/lp2_p23_26_bacon_exhaustive_sft.cjs) recursively enumerates every 29-bit assignment that avoids **all** forbidden hyperedges. Search-tree pruning is exact because a completed all-one forbidden edge can never be repaired by assigning additional bits. It counts and scores every surviving key without an omitted heuristic branch:

| Printed five-symbol groups | **90,836** | 10 | 181,672 |

The exhaustive output-readout uses a normalized alphabetic **quadgram model trained from the pinned Gibran, Emerson, and Shakespeare control texts**, excluding a 201-letter mid-book holdout from each. The three untouched native-English 201-letter holdouts score **−1827.994**, **−1836.508**, and **−1848.795** under the same model. The best original outputs remain visibly nonlinguistic; the highest-scoring mirrored readout begins `UETFDAKSEADAQYSQAEADBESAQGAUBJUISABDHIQADIEZFAEACARESAKQYU...`.
