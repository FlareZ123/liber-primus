## Independent source and operation

The original combined LP1/LP2 75-JPEG source is **byte-verified** against the repository's concatenated SHA-256, `cdda41395a52761be5d00c52ec4a2c1c769f9a9f756974a7ec62d4bbf4156dc1`. Physical LP2 p0–p57 are the archive's 17.jpg–74.jpg. Read-only reproducibility is in [sims/lp2_exact_illustration_atlas_sft.py](../sims/lp2_exact_illustration_atlas_sft.py), with Pillow/NumPy; it accepts the repository JPEG directory or the custodian ZIP. It locks the image size at 2400×3600, scans each of the 58 LP2 originals as nonoverlapping 96×96 grayscale tiles, retains tiles with ≥60 pixels below gray190, and hashes exact source pixels. This is a **same-grid exact-copy detector**; it cannot rule out shifted, rescaled, partially overlapping or artistically redrawn motifs.

**Full-corpus tile graph:** 20,321 ink-bearing tile instances; 587 distinct 96-pixel tile patterns shared by at least two physical pages. Selected exact-copy edges, counted as tile patterns, are p1–p2 **84**, p4–p5 **102**, p9–p11 **50**, p10–p12 **57**, p24–p26 **63**, p34–p35 **21**, and p40–p55 **169**. All pairs in the seven visually obvious groups below are supported by source-pixel comparisons. At this footprint only one cross-chapter pair has ≥3 exact matching tile patterns outside the p40–p55 cohort: **p27/p54, three adjacent-geometry samples of the shared vertical stem in two *different* oversized red initials**. Those strips are ordinary font geometry at the same page coordinates, not an unseen inscription or a second cipher.

## Layer boundaries and residuals

Seven groups were tested for **whole-rectangle exact 24-bit RGB identity**, eliminating false matches driven only by white paper: p1–p2 large left cross (**787,500** RGB pixels per comparison); p4–p7 both marginal scrolls (**2,030,000**); p9/11/13 right saplings (**1,265,000**); p10/12/14 left saplings (**1,265,000**); p24/26 paired insect/wings (**1,792,000**); p34–p39 two-line cuneiform heading (**231,000**); and p40–p55 left/right floral frames (**2,530,000**). Every pixel in every listed rectangle matches its group reference exactly. Thus changing prose/red inscriptions, numerical table and terminal art are separate foreground content in those source windows; the common decorations themselves do **not** encode an evolving per-page graphic stream within the specified rectangles.

The remaining p25 inset looks different from p24/p26 under literal subtraction but gives, under one retrospectively registered **(−1,−1) source-pixel** shift, threshold-200 ink intersection-over-union **0.899780** (left) and **0.924671** (right), versus same-position **0.795795/0.815035**. This is strongly consistent with the same illustrated motif being re-rasterized or displaced slightly. It is not a detected additional glyph; no operation or bit value is justified by one selected subpixel phase. The known p33 two-line cuneiform footer is repositioned as the p34–39 top caption. A fixed source crop of p33 at x1021:1399,y3136:3448 against p34 x1021:1399,y242:554 gives a retrospective RGB normalized correlation near **0.96956**. The two-line inscription itself is already recognized in historical Cicada research (numbers 1033/3301); image reuse does not select an LP2 key.

## Decision and limits

**No novel author-visible residual instruction, key text or reversible decoder emerged** from the fixed-origin exact-copy atlas or the named registered decorations. The p40–p55 surround is a literal static canvas; pages p24 and p26 also reuse the precise same wings, and p25's apparent exception largely follows one-pixel placement. The source-constrained hypothesis that these known repeated pictures carry a visibly changing per-page overlay fails for the exact regions above. This does not rule out p32/p55's already studied nonexact tree relationship, non-grid translations, a tiny image detail below tile size, an external historical plate, or a signed instruction that consumes known motifs. No unconstrained threshold/LSB/OutGuess sweep or GP29 key screen was conducted. The next causal gate is a **source-selected action** that turns a particular original art correspondence into a typed rune order, key or operation before scoring unknown ciphertext.
