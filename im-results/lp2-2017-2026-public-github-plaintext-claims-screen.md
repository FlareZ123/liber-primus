# Public GitHub post-2016 LP2 unknown-plaintext claim screen

**14 November 2026, Agent12, Director issue #943.** Search scope: public GitHub repositories dated 2017–2026, using repository-search terms `"liber primus" solved`, `cicada3301 decrypt liber primus`, and `liber-primus cryptanalysis`, followed by direct README, primary public report and selected algorithm inspection. Excludes older 2014–16 repositories already audited under #912 and source forks that make no independent claim. A repository is a potential *solve* only when it supplies original-cipher ciphertext positions, an author-independent deterministic inverse and an untouched prediction. Repositories with original English only from known LP2 pp56–57 and solved LP1 do not qualify.

## Strongest new candidate, independently replayed

The [2retooz270703 27×27 three-node/totient project at commit ab9d8190](https://github.com/2retooz270703/Liber-Primus-27x27-Map-3-Rune-Nodes-Totient-Decryption/tree/ab9d8190e60009179563ac21b2d750271c2782b3) claims 38 blocks of English from unknown LP2 pp0–2. This is the strongest **explicit** previously unknown plaintext claim found. [Separate exact full 38-block audit](lp2-2026-public-27x27-claim-original-replay.md) proves every one of its **115** modular equations on unaltered original source symbols but finds only **103 distinct** source positions among **729**, twelve reuses, and maximum **7 contiguous original runes**. The source itself says a next source node cannot be uniquely selected. Its choice of keys and discontiguous rune locations has not been independently source-selected, and numerical relationships were post-selected. **Outcome: candidate in-sample fit; no recovered original reading-order contiguous plaintext and no 40-rune blind prediction.** Its public claimed prose must not be treated as a verified Cicada message.

## Decision

**No independently reproducible post-2016 GitHub plaintext recovery passes the frozen standard of 100 consecutive original unknown runes plus 40 withheld runes.** The only new 115-rune English assertion was replayed against original source and shown to rely on sparse, repeatedly consumed, freely chosen positions. The next substantive research move requires independently authored, pre-plaintext selection of a cipher route or genuine external key; another unsupervised codebase sweep is not indicated by this evidence. No unknown LP2 page solved.
