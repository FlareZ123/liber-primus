# Signed EPIPHANY SEEKS heading: 729-prime partition and an original-cipher gate

**Agent 20, 15 November 2026. Classification:** a distinct, source-motivated full-chapter reversible inverse, executed and found nonlinguistic. The 729-prime sum of the conditional key is exact but retrospectively discovered. **No authenticated unknown-page plaintext, real key or historical cipher is recovered.**

## A possible human step that gives a complete block map

The independently signed [January 2016 Cicada message](../resources/historical/cicada2016-4gq25-outguess.asc) says "epiphany seeks the devoted." The original 2014 first red heading on physical LP2 p0 has two complete GP29 words, eight and five runes. The existing [p0 signed-phrase analysis](lp2-p0-2016-epiphany-title-crib-gate.md) therefore considers **EPIPHANY SEEKS** as a **hypothetical** title crib. There is no authenticated declaration that this is its plaintext.

GP29 subtraction of that 13-rune proposed plaintext from the original 13 ciphertext runes yields the uniquely specified additive key indices:

**26, 24, 8, 19, 27, 24, 18, 3, 0, 8, 0, 16, 19.**

The existing title analysis observed that this derived key's GP prime weights add to **729**, identical to the original first three-page chapter's 262+266+201 = **729** source glyphs. This exact match suggests a *new, executable consumer*: instead of repeating the 13 key symbols at every 13th position (already tested unsuccessfully), **each key symbol governs a consecutive block whose length equals that symbol's own GP prime weight**. Then no missing padding, fitted block phase, guessed key length or leftover position is required.

The thirteen complete block lengths in original physical page order are:

**103, 97, 23, 71, 107, 97, 67, 7, 2, 23, 2, 59, 71**, summing to **729**.

This is one precise full-chapter schedule that a human could calculate with the printed GP prime alphabet, conditional on accepting the title crib and a prime-length block operation. Rival explanation: the 729 match arises because many proposed 13-rune plaintext windows would generate comparable prime-key totals; the original manuscript does not say to turn a deciphered heading's key primes into block lengths. The 13-rune heading is itself included in the 729-cell footprint, so treating it as a separately encrypted header would require another independently indicated mode boundary.

## Exact original-cipher test

Read the unchanged original GP29 ciphertext from [the canonical physical-page corpus](../resources/liber-primus/lp2-corpus.json). For block j of the above lengths and key symbol k_j, apply the ordinary fixed Caesar inverse P_i = (C_i − k_j) mod 29. All 729 original runes are consumed exactly once. The sign-reversed alternative is checked on exactly the same source-fixed boundaries. Both transforms re-encode their own outputs exactly, as any bijective transform must. A separate native solved-p57 GP29 message repeated to the same shape is planted under the **same** variable-length cipher and recovers all 729 runes exactly.

| Source-fixed register | GP29 empirical index of coincidence |
| --- | ---: |
| Original first chapter, 729 runes | 0.034082515564 |
| Full chapter, 13 prime blocks, C minus key | **0.034621414251** |
| Same source blocks, C plus key | **0.034719395831** |

The blockwise decrypted output begins with GP transliterations **E J NG G N OE U O E F NG A H C X N EA O X AE**, which does not recover the proposed title or contiguous readable GP-native English. Both complete decoded inventories remain close to the uniform 29-rune collision baseline. Permuting the already-shifted blocks, or transposing their symbols without another symbol-changing key, **cannot alter their empirical collision indices**, so no block-reading permutation alone repairs the direct fixed-shift family.

The historically attested solved-p56 plaintext-F transparency also yields a stronger exact obstruction for this one schedule. The original first chapter has **21 non-F ciphertext positions where the scheduled nonzero key equals the ciphertext value**; 20 are after the assumed 13-rune header. Ordinary subtraction would force plaintext F there, although that historical mode prints F literally, as ciphertext F, without advancing the key. Consequently the stipulated constant-block shifts cannot be made into the historical literal-F-bypass cipher simply by deciding which printed F runes skip the clock. The first conflicting position is original p0 local offset 9, still within the candidate heading; the following conflicts survive even if the heading is assigned a different encryption mode.

## Stronger all-secret block substitution exclusion

The direct Caesar test above leaves an important possibility: perhaps each of the thirteen key-prime-length blocks has its own **arbitrary secret substitution alphabet** rather than its inferred single Caesar shift. This much larger secret family has a key-independent necessary condition that can be applied without guessing any alphabet.

For every source-frozen block, count unordered pairs of positions whose GP rune labels are identical. Any bijection of the 29 runes merely renames the labels, so the count remains **exactly identical** for every possible hidden substitution in that block. Position permutations **within** the block and permutations of whole blocks also preserve the pooled count. The 13 original blocks contain exactly **1,070** same-label pairs among **29,657** eligible within-block position pairs, giving pooled IoC **0.036079171865**.

Under the same frozen 13 block lengths, the three pre-existing ordinary-English source controls are encoded under the repository's established GP29 spelling mapping (TH/NG/EO/OE/AE/IA/EA; K/Q→C, V→U, Z→S). Their complete 729-rune windows are sampled every 127 runes, with no selection from the original ciphertext:

**Decision:** under this particular thirteen-block registration, **no independent secret monoalphabetic substitution per block can yield any of the 4,761 actual GP29 native-English 729-rune windows**, regardless of all thirteen hidden keys. This follows from the exact pair-count invariant and does not assume additive keys. Even rearranging source symbols or block order cannot change this necessary frequency statistic. It remains an empirical comparison with the three stated reference registers, **not a mathematical exclusion of every possible English or other-language plaintext**. A genuinely changing within-block key state, different boundaries or another non-bijective intermediate code lies outside this negative.

The test includes an arbitrary nontrivial, block-specific affine GP29 permutation applied to a planted solved-p57 729-rune stream and asserts exact preservation of the pooled collision statistic. The same single-file SFT computes the full 4,761-window control census on the checked-in English sources.

## Decision and remaining route

Reject **the frozen 13-prime-length block schedule followed by one Caesar shift per block**, under the original GP-native prose and authentic F-bypass expectations. This is distinct from the older period-13, autokey, 27×27 spatial-path and title-key-sum tests; none of those used the derived prime weights directly as the 13 contiguous full-chapter block lengths.

The 729 equality remains a **conditional arithmetic clue**, not evidence of a deciphered heading or a key. A future use would need an independent original or authenticated historical instruction that assigns a different reversible operation to these 13 prime-sized blocks and predicts a held-out unknown-page plaintext passage. Additional arbitrary transpositions, byte-codecs or key adjustments do not follow from the present failure.
